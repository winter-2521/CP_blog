#数学 #畳み込み #FFT #NTT

ライブラリ：[convolution.hpp](https://github.com/winter-2521/cp-library/blob/main/math/convolution.hpp)

## 1. 概要

2 つの列 $a = (a_0, \dots, a_{n-1})$、$b = (b_0, \dots, b_{m-1})$ の **畳み込み**

$$
c_k = \sum_{i + j = k} a_i b_j
$$

は、多項式 $A(x) = \sum a_i x^i$、$B(x) = \sum b_j x^j$ の積 $C(x) = A(x)B(x)$ の係数です。素朴には $O(nm)$ ですが、**高速フーリエ変換（FFT）** の考え方で $O(N \log N)$（$N = n + m$）になります。競技プログラミングでは、浮動小数点の誤差がない **数論変換（NTT）** を mod 998244353 で使うのが定番です。

>[!問題] 問題 1：Convolution（Library Checker）
>長さ $N$ と $M$ の列 $a, b$ の畳み込みを $998244353$ で割った余りで求めてください。（$N, M \le 5 \times 10^5$）

## 2. 前提知識

- 多項式の積
- mod 素数での累乗・逆元

## 3. 素朴な方法

全ての $(i, j)$ について $a_i b_j$ を $c_{i+j}$ に足すと $O(nm)$。$n = m = 5 \times 10^5$ では $2.5 \times 10^{11}$ です。

## 4. 値で表すと積は簡単

$C(x) = A(x)B(x)$ は次数 $N - 1$ 未満なので、$N$ 個の点 $x_0, \dots, x_{N-1}$ での値で決まります。

1. $A, B$ を $N$ 個の点で **評価** する。
2. 各点で値を掛ける：$C(x_k) = A(x_k) B(x_k)$。
3. $C$ の値から係数を **復元**（補間）する。

2. は $O(N)$ ですが、1. と 3. を素朴にやると $O(N^2)$ です。**点を 1 の $N$ 乗根に選ぶ** と、1. と 3. が $O(N \log N)$ になります。

## 5. FFT：1 の累乗根で評価する

### 5.1. 半分に分ける

$N$ を 2 冪とし、$\omega$ を「1 の原始 $N$ 乗根」（$\omega^N = 1$、それより小さい乗では 1 にならない）とします。$A$ を偶数次と奇数次に分けると

$$
A(x) = A_{\text{偶}}(x^2) + x \cdot A_{\text{奇}}(x^2)
$$

で、$x = \omega^k$ と $x = \omega^{k + N/2} = -\omega^k$ では $x^2$ が同じです。よって $A_{\text{偶}}, A_{\text{奇}}$ を $\omega^2$（1 の $N/2$ 乗根）の累乗で評価した値から

$$
A(\omega^k) = E_k + \omega^k O_k, \qquad A(\omega^{k + N/2}) = E_k - \omega^k O_k
$$

と 2 つずつ求まります（**バタフライ演算**）。半分の大きさの問題 2 つ + $O(N)$ なので $O(N \log N)$ です。

### 5.2. 逆変換

値 $C(\omega^k)$ から係数に戻すのは、$\omega$ の代わりに $\omega^{-1}$ で同じ変換をして $N$ で割るだけです（変換行列 $(\omega^{jk})$ の逆行列が $\frac{1}{N}(\omega^{-jk})$ のため）。

## 6. NTT：mod 素数の世界の 1 の累乗根

複素数の $\omega = e^{2\pi i/N}$ を使うと誤差が出ます。そこで mod $p$ の世界で $\omega^N \equiv 1$ となる $\omega$ を使います。$p = 998244353 = 119 \cdot 2^{23} + 1$ は $p - 1$ が $2^{23}$ で割り切れ、原始根 $g = 3$（$g$ の累乗で $1, \dots, p-1$ が全部出る）を使って

$$
\omega = g^{(p-1)/N}
$$

が 1 の原始 $N$ 乗根になります（$N \le 2^{23}$）。

### 6.1. 例で追う

$a = (1, 2, 3)$、$b = (4, 5)$ の畳み込み（答えは $(4, 13, 22, 15)$）を $N = 4$ で計算します。$\omega = 3^{(p-1)/4} = 911660635$ で、$\omega^2 \equiv -1$ です（複素数の $i$ にあたります）。

| 点 | $1$ | $\omega$ | $\omega^2 = -1$ | $\omega^3$ |
| --- | --- | --- | --- | --- |
| $A = 1 + 2x + 3x^2$ | 6 | 825076915 | 2 | 173167434 |
| $B = 4 + 5x$ | 9 | 565325767 | $-1$ | 432918594 |
| $C = AB$ | 54 | 173167418 | $-2$ | 825076899 |

例えば $A(-1) = 1 - 2 + 3 = 2$、$B(-1) = 4 - 5 = -1$ です。$C$ の値を $\omega^{-1}$ で逆変換して 4 で割ると $(4, 13, 22, 15)$ に戻ります（ライブラリの出力と一致）。

## 7. 実装

### 7.1. 非再帰のバタフライ

再帰の代わりに、添字をビット反転した位置に並べ替えてから、長さ 2, 4, 8, … のブロックごとにバタフライをします。

```cpp
// rt[k + j] = (2k 乗根)^j を長さに応じて伸ばして使い回す
for (int i = 1, j = 0; i < n; i++) {           // ビット反転の並べ替え
    int bit = n >> 1;
    for (; j & bit; bit >>= 1) j ^= bit;
    j ^= bit;
    if (i < j) swap(a[i], a[j]);
}
for (int k = 1; k < n; k *= 2)
    for (int i = 0; i < n; i += 2 * k)
        for (int j = 0; j < k; j++) {
            mint z = rt[j + k] * a[i + j + k];
            a[i + j + k] = a[i + j] - z;
            a[i + j] += z;
        }
if (inverse) reverse(a.begin() + 1, a.end());   // ω^{-1} での変換と同じ並び
```

逆変換は「同じ変換をして、1 番目以降を逆順にする」で $\omega^{-1}$ での変換になります（$\omega^{-k} = \omega^{N-k}$ のため）。

### 7.2. 整数のまま畳み込む

答えが mod を超える整数のとき（例えば組の個数）は、**複数の素数で NTT して中国剰余定理** で復元します。

- `convolve_ll`：3 つの素数で、`long long` に収まる任意の整数（負も可）。
- `convolve_small`：2 つの素数（998244353, 754974721）で、非負かつ $7.5 \times 10^{17}$ 未満の結果。変換の回数が 2/3 で済みます。

2 つの素数 $p_1, p_2$ での余り $r_1, r_2$ から、$v = r_1 + p_1 \cdot ((r_2 - r_1) p_1^{-1} \bmod p_2)$ で $0 \le v < p_1 p_2$ の値が決まります。

## 8. 正しさ・計算量

- **正しさ**：5.1 節の分割と、5.2 節の逆変換の式によります。
- **計算量**：変換 3 回（$a$, $b$, 逆変換）で $O(N \log N)$。短い列では素朴な方法の方が速いので、片方が 40 以下なら素朴に計算しています。

## 10. まとめ

- 畳み込み = 多項式の積。値で表せば積は各点の掛け算。
- 1 の $N$ 乗根で評価すると、偶奇に分ける分割統治で評価・補間が $O(N \log N)$（FFT）。
- mod 998244353 では $\omega = 3^{(p-1)/N}$ が 1 の $N$ 乗根になり、誤差のない NTT ができる。大きな整数は複数の素数 + 中国剰余定理。
