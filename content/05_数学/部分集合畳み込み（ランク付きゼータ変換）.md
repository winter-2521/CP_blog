#数学 #bitDP #ゼータ変換 #畳み込み

ライブラリ：[subset_convolution.hpp](https://github.com/winter-2521/cp-library/blob/main/math/subset_convolution.hpp)

## 1. 概要

長さ $2^n$ の列 $f, g$（添字は $n$ 要素の集合の部分集合）について

$$
h(S) = \sum_{T \subseteq S} f(T)\, g(S \setminus T)
$$

を **部分集合畳み込み**（subset convolution）と呼びます。「$S$ を重ならない 2 つに分けて、片方に $f$、もう片方に $g$」を全ての分け方で足したものです。素朴には $O(3^n)$ ですが、**ランク付きゼータ変換** を使うと $O(n^2 2^n)$ になります。

## 2. 前提知識

- bit DP（部分集合を整数で表す）
- **ゼータ変換**：$\hat f(S) = \sum_{T \subseteq S} f(T)$ を、1 bit ずつ足し込んで $O(n 2^n)$ で求める方法。逆変換（メビウス変換）は引き算にするだけ。

## 3. 素朴な方法

全ての $S$ について部分集合 $T$ を列挙すると、組 $(T, S)$ の数は $3^n$（各要素が「$T$ に入る / $S \setminus T$ に入る / $S$ に入らない」）なので $O(3^n)$ です。$n = 20$ で $3.5 \times 10^9$ と重くなります。

## 4. ゼータ変換だけではだめな理由

「和集合の畳み込み」$h'(S) = \sum_{A \cup B = S} f(A) g(B)$ なら、ゼータ変換すると $\hat{h'}(S) = \hat f(S)\, \hat g(S)$（各点の積）になり $O(n 2^n)$ です。しかし部分集合畳み込みは $A$ と $B$ が **重ならない**（$A \cap B = \emptyset$）ものだけを数えたいので、これでは重なりのある組まで混ざってしまいます。

ここで「$A \cup B = S$ かつ $|A| + |B| = |S|$」⇔「$A, B$ が重ならず和が $S$」に注目します。大きさを別の変数で管理すればよいのです。

## 5. ランク付きゼータ変換

### 5.1. 定義

$$
\hat f(S)[d] = \sum_{T \subseteq S,\ |T| = d} f(T)
$$

と、大きさ $d$ ごとにゼータ変換します（$S$ ごとに $d$ についての多項式 $\hat f(S)(t) = \sum_d \hat f(S)[d]\, t^d$ と見ます）。すると

$$
\hat f(S)(t) \cdot \hat g(S)(t) = \sum_{A, B \subseteq S} f(A) g(B)\, t^{|A| + |B|}
$$

で、これを $d$ ごとにメビウス変換で戻すと「$A \cup B = S'$ で $|A| + |B| = d$」の和になります。$d = |S'|$ の係数だけ取り出せば、重ならない組だけが残ります。

### 5.2. 手順

1. $f, g$ をランク付きゼータ変換する（$d$ ごとのゼータ変換、$O(n^2 2^n)$）。
2. 各 $S$ で多項式の積を取る（$O(n^2)$ が $2^n$ 個）。
3. $d$ ごとにメビウス変換し、$h(S) = (\text{結果})(S)[|S|]$ を取り出す。

## 6. 例で追う

$n = 2$、$f = (1, 2, 3, 4)$、$g = (5, 6, 7, 8)$（添字は ∅, {0}, {1}, {0,1} の順）とします。

**ランク付きゼータ変換。**

| $S$ | ∅ | {0} | {1} | {0,1} |
| --- | --- | --- | --- | --- |
| $\hat f(S)$ | $1$ | $1 + 2t$ | $1 + 3t$ | $1 + 5t + 4t^2$ |
| $\hat g(S)$ | $5$ | $5 + 6t$ | $5 + 7t$ | $5 + 13t + 8t^2$ |

（例えば $\hat f(\{0,1\})$ の $t^1$ の係数は $f(\{0\}) + f(\{1\}) = 2 + 3 = 5$。）

**各点の積**（$t^2$ までで十分）：

| $S$ | ∅ | {0} | {1} | {0,1} |
| --- | --- | --- | --- | --- |
| 積 | $5$ | $5 + 16t + 12t^2$ | $5 + 22t + 21t^2$ | $5 + 38t + 93t^2$ |

**メビウス変換して $t^{|S|}$ を取り出す。** 例えば $S = \{0, 1\}$ では $t^2$ の係数を包除で

$$
93 - 12 - 21 + 0 = 60
$$

と戻します。同様に $h = (5, 16, 22, 60)$ です（ライブラリの出力と一致）。確かめると $h(\{0,1\}) = f(\emptyset)g(\{0,1\}) + f(\{0\})g(\{1\}) + f(\{1\})g(\{0\}) + f(\{0,1\})g(\emptyset) = 8 + 14 + 18 + 20 = 60$ です。

## 7. 実装と定数倍の改善

```cpp
// ランク付きゼータ変換．R[S][d] は d <= |S| でしか 0 でない
for (int i = 0; i < n; i++)
    for (int s = 0; s < N; s++)
        if (s >> i & 1) {
            mint *t = &R[s * W], *u = &R[(s ^ (1 << i)) * W];
            for (int d = 0; d < popcount(s); d++) t[d] += u[d];
        }
```

ライブラリでは次の 3 つで定数倍を軽くしています。

- **ゼータ変換**：$\hat f(S)[d]$ は $d \le |S|$ でしか 0 でないので、その範囲だけ足す。
- **積**：最後に使うのは $d \ge |S|$ の段だけ（$h(S)$ は部分集合 $T$ の $d = |S| \ge |T|$ の段からしか作られない）で、積は $2|S|$ 次まで。$d \in [|S|, 2|S|]$ だけ計算する。積和は剰余を取らずに 64 bit で足し、まとめて 1 回だけ割る。
- **メビウス変換**：各 $S$ で $d \ge |S|$ の段だけ計算する。

## 8. 正しさ・計算量

- **正しさ**：5.1 節のとおり、$t^{|S|}$ の係数は「重ならず和が $S$」の組だけの和です。
- **計算量**：変換 2 回と逆変換 1 回が $O(n^2 2^n)$、各点の積が $O(n^2 2^n)$ です。

## 9. 問題

【問題 1】長さ $2^n$ の $f, g$ の部分集合畳み込みを求めてください（Library Checker の Subset Convolution、$n \le 20$）。
（ヒント：`subset_convolution(f, g)` そのものです。）

【問題 2】$n \le 20$ 頂点のグラフで、頂点全体を「2 つの重ならない独立集合」に分ける方法の数を、全ての頂点部分集合 $S$ について求めてください。
（ヒント：$f(T) = [T \text{ は独立集合}]$ として $f$ と $f$ の部分集合畳み込みです。）

## 10. まとめ

- 部分集合畳み込みは「重ならない 2 つに分ける」畳み込み。素朴には $O(3^n)$。
- 大きさ $d$ ごとにゼータ変換すると、各点で $d$ についての多項式の積になり、$t^{|S|}$ の係数に重ならない組だけが残る。$O(n^2 2^n)$。
- 0 になる段・使わない段を飛ばし、積和をまとめて割ると定数倍が軽くなる。
