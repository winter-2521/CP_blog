#数学 #mod

ライブラリ：[modint.hpp](https://github.com/winter-2521/cp-library/blob/main/math/modint.hpp)

## 何ができるアルゴリズムか？

法 $M$ での四則演算を、`%` を毎回書かずに普通の数のように書ける型。法がコンパイル時定数の `ModInt<M>`（`ModInt998244353` など）。ACL の `static_modint` と同じインターフェース（`val()`, `mod()`, `pow()`, `inv()`, `raw()`）なので、ACL の modint と混ぜて使える。

## 計算量

| 操作 | 計算量 |
| --- | --- |
| $+, -, \times$ | $O(1)$ |
| 逆元・割り算 | $O(\log M)$ |
| $x^n$ | $O(\log n)$ |

## 具体例で理解する

### 持っているもの

$0 \le v < M$ の整数 $v$ を 1 つだけ（$M$ は法）。演算のたびに $[0, M)$ に収まるように直す。

### 各演算の手順

- **足し算**：$v_1 + v_2$ は $2M$ 未満なので、$M$ 以上なら $M$ を引くだけ（`%` 不要）。
- **引き算**：$v_1 + (M - v_2)$ を計算して、$M$ 以上なら $M$ を引く。
- **掛け算**：$v_1 v_2 < M^2$ を 64 bit で計算して $\bmod M$。
- **割り算**：逆元（下）を掛ける。

```cpp
using mint = ModInt998244353;
mint a = 500000000, b = 600000000;
mint c = a + b;   // 1100000000 - 998244353 = 101755647
mint d = a * b;   // (500000000 × 600000000) mod 998244353
```

### 逆元（割り算）の例

$\bmod 7$ で $\frac{1}{3}$ は「3 を掛けると 1 になる数」。$3 \times 5 = 15 = 2 \times 7 + 1$ なので $\frac{1}{3} \equiv 5$。

**拡張ユークリッドの互除法** で求める：$3x + 7y = 1$ となる整数 $x$ を探す。

- $7 = 2 \times 3 + 1$ → $1 = 7 - 2 \times 3$
- よって $x = -2$、$-2 \equiv 5 \pmod 7$。

一般には互除法（$\gcd(a, M)$ を求める割り算の繰り返し）を逆にたどって $x$ を作る。$O(\log M)$ 回。

フェルマーの小定理で $3^{7-2} = 243 = 34 \times 7 + 5 \equiv 5$ としても求まるが、これは $M$ が素数のときだけ。互除法なら $M$ が素数でなくても $\gcd(a, M) = 1$ なら使える。

## 証明・仕組み

### 足し算・引き算は分岐で

$0 \le a, b < M$ なら $a + b < 2M$ なので、`%` の代わりに「$M$ 以上なら $M$ を引く」で済む。引き算は $a + (M - b)$ にして同様に。

### 掛け算：法が定数なら `%` は速い

$a b < M^2 < 2^{62}$ なので 64 bit で掛けて `%`。$M$ がコンパイル時定数だと、コンパイラが割り算を「逆数の掛け算 + シフト」に置き換える（Barrett reduction 相当）ので、実行時に割り算命令は出ない。法が実行時に決まる場合は Barrett / Montgomery を自前で書く必要がある。

### 逆元：拡張ユークリッドの互除法

$a x + M y = \gcd(a, M) = 1$ となる $x$ を互除法で求めれば $x \equiv a^{-1}$。$M$ が素数でなくても $\gcd(a, M) = 1$ なら使える（フェルマーの小定理 $a^{M-2}$ は $M$ が素数のときだけ）。計算量は互除法の回数 $O(\log M)$。

### 冪

繰り返し二乗法。負の指数は逆元の冪にする。

## 例題・類題

- 「答えを $998244353$ で割った余りを出力せよ」の問題全般。
- [[逆元が存在しない数で割り算をmod計算する]]：$\gcd(a, M) \ne 1$ のときの扱い。
