#データ構造 #セグ木

ライブラリ：[dual_segment_tree.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/dual_segment_tree.hpp)

## 何ができるアルゴリズムか？

区間に作用させて、**一点の値を取得する** だけなら、遅延セグ木より軽い双対セグ木で $O(\log n)$。作用は非可換でもよい（区間 1 次関数など）。

>[!問題] Range Affine Point Get (Library Checker)
>`0 l r b c`：$i \in [l, r)$ について $a_i \gets b a_i + c$、`1 i`：$a_i$ を出力。$N, Q \le 5 \times 10^5$

## 計算量

区間作用・一点取得とも $O(\log n)$。

## 具体例で理解する

### 各ノードが持っているもの

| 名前 | 意味 |
| --- | --- |
| `lz` | 「担当区間の全要素にかかった作用」（複数かかったら合成したもの）。はじめは何もしない作用（加算なら 0） |

**値は持たない**。[[遅延セグ木まとめ]] から `sum` を取り除き、`lazy` だけを残したものと考えてよい。位置 $i$ に今までにかかった作用は、葉 $i$ から根までの `lz` を全部合成すれば分かる。

### 手順

- **区間作用** $[l, r)$ に $f$：（非可換のときは先に、分解に使うノードの祖先を根から順に push）区間を $O(\log n)$ 個のノードに分解し、各ノードの `lz` に $f$ を合成する。
- **一点取得** $i$：葉 $i$ から根まで登りながら、`lz` を「古い順」に合成する。
- **push(v)**：v の `lz` を 2 つの子の `lz` に合成し、v の `lz` を空にする。

### 例：区間加算・一点取得

長さ 4 の配列（はじめ全て 0）に

1. $[0, 3)$ に $+3$ → ノード $[0,2)$ と $[2,3)$ の `lz` に $+3$
2. $[1, 4)$ に $+5$ → ノード $[1,2)$ と $[2,4)$ の `lz` に $+5$

```
              [0,4): lz=0
       [0,2): lz=+3       [2,4): lz=+5
   [0,1):0  [1,2):+5  [2,3):+3  [3,4):0
```

$a_2$：葉 $[2,3)$ から根まで登りながら `lz` を足す：$3 + 5 + 0 = 8$。実際 $a_2$ には両方かかっているので正しい。$a_1$：$5 + 3 + 0 = 8$。$a_0$：$0 + 3 + 0 = 3$。

### 非可換だと「順番」が問題になる例

作用が「区間を $x$ にする（代入）」だとする。

1. $[0, 4)$ を 7 にする → 根の `lz` に「$=7$」
2. $[2, 3)$ を 2 にする → 葉 $[2,3)$ の `lz` に「$=2$」

$a_2$ は 2 であるべき。葉から根へ「下が古い・上が新しい」と思って合成すると「$=2$ → $=7$」で 7 になってしまう。実際は根の作用の方が **古い**。

そこで 2 の操作の前に、**葉 $[2,3)$ の祖先を根から順に push** する：根の「$=7$」を $[0,2)$ と $[2,4)$ へ、$[2,4)$ の「$=7$」を葉 $[2,3)$ と $[3,4)$ へ。そのあと葉 $[2,3)$ に「$=2$」を合成すると、葉には「$=7$ → $=2$」と正しい順で積まれ、祖先の `lz` は空。

この push を毎回すると「上のノードにある作用ほど新しい」が常に成り立つので、一点取得は葉から根へ合成すれば正しい。加算のように順番を変えても結果が同じなら push は不要だが、このライブラリは常に push して非可換にも対応している。

## 証明・仕組み

セグ木の各ノードに「そのノードの区間全体にかかった作用（の合成）」だけを持つ（値は持たない）。

- **区間作用**：区間を $O(\log n)$ 個のノードに分解し、そのノードの作用に $f$ を合成する。
- **一点取得**：葉から根までのノードの作用を全て合成すれば、その位置にかかった作用の全体になる。

### 非可換のときの注意

作用が可換（加算など）なら、これだけで正しい。非可換だと **順番** が問題になる。位置 $i$ にかかった作用は時系列順に合成したいが、葉から根へのノードの作用は「上のノードが新しい」とは限らない（古い作用が根に、新しい作用が葉に近いノードにかかっていることがある）。

そこで区間作用の前に、**分解に使うノードの祖先の作用を子に下ろしておく**（遅延セグ木の push と同じ）。すると作用をかけるノードの祖先は全て空になるので、「祖先の作用は子孫の作用より新しい」が常に成り立つ。一点取得では葉から根に向かって「古い → 新しい」の順に合成すればよい。

push は境界の 2 本の経路だけなので $O(\log n)$。

### 遅延セグ木との違い

遅延セグ木は区間積を取るために各ノードに値も持ち、作用を値に反映する `mapping` が必要。双対セグ木は値を持たないので、作用のモノイドだけ書けばよい。区間積が要らないなら双対セグ木の方が速くて書きやすい。
