#データ構造 #2次元 #いもす法 #ウェーブレット行列

ライブラリ：[rectangle_add_point_get.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/rectangle_add_point_get.hpp)、[static_rectangle_add_rectangle_sum.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/static_rectangle_add_rectangle_sum.hpp)

## 1. 概要

本記事では、座標が $10^9$ まであるような（配列にできないほど広い）平面について、

- 長方形 $[l, r) \times [d, u)$ の全マスに $w$ を足す
- 1 マスの値を求める / 長方形の中の値の和を求める

を処理する方法を解説します。2 次元いもす法を、配列を作らずに「重み付きの点」でやるのがアイデアです。

>[!問題] 問題 1：Rectangle Add Point Get（Library Checker）
>長方形加算と一点取得を混ぜて $Q$ 回処理してください。（$N, Q \le 10^5$、座標 $\le 10^9$）

>[!問題] 問題 2：Static Rectangle Add Rectangle Sum（Library Checker）
>先に $N$ 回の長方形加算をし、その後 $Q$ 回の長方形和（mod 998244353）を答えてください。（$N, Q \le 2 \times 10^5$、座標 $\le 10^9$）

## 2. 前提知識

- 2 次元いもす法（2 次元の差分と累積和）
- 長方形の中の点の重みの和：[[長方形の中の点の重みの和（Rectangle Sum）]]
- 1 次元で区間加算・区間和を BIT 2 本で行う方法（あると 6 節が分かりやすい）

## 3. 素朴な方法：2 次元いもす法

座標が小さければ、長方形 $[l, r) \times [d, u)$ に $w$ を足すのは、差分の表 $D$ の 4 隅に書き込むだけです。

$$D[l][d] \mathrel{+}= w,\quad D[l][u] \mathrel{-}= w,\quad D[r][d] \mathrel{-}= w,\quad D[r][u] \mathrel{+}= w$$

全部書き込んでから $D$ の 2 次元累積和を取ると、各マスの値になります。

**例**：$[1, 3) \times [1, 3)$ に 5 を足す（図は下が $y = 0$）。

```
D（書き込み）              累積和を取ると
y=3   .   -5    .   +5      y=3   0   0   0   0
y=2   .    .    .    .      y=2   0   5   5   0
y=1   .   +5    .   -5      y=1   0   5   5   0
y=0   .    .    .    .      y=0   0   0   0   0
     x=0  x=1  x=2  x=3          x=0 x=1 x=2 x=3
```

しかし座標が $10^9$ だと表 $D$ が作れません。また、加算と取得が交互に来ると、毎回累積和を取り直すことになります。

## 4. 4 隅を「重み付きの点」として持つ

$D$ のうち 0 でないのは 4 隅だけなので、**4 隅を重み付きの点として持てば十分** です。マス $(x, y)$ の値は「$D$ の $(x, y)$ までの 2 次元累積和」なので、

> マス $(x, y)$ の値 ＝ $x' \le x$ かつ $y' \le y$ の点の重みの和

です。これは「長方形の中の点の重みの和」そのものです。

**例**：$[1, 3) \times [1, 3)$ に 5 → 点 $(1,1,+5)$, $(1,3,-5)$, $(3,1,-5)$, $(3,3,+5)$。

| マス | $x' \le x, y' \le y$ の点 | 値 |
| --- | --- | --- |
| $(2, 2)$ | $(1,1,+5)$ | 5 |
| $(3, 2)$ | $(1,1,+5)$, $(3,1,-5)$ | 0（長方形の外） |
| $(2, 3)$ | $(1,1,+5)$, $(1,3,-5)$ | 0（長方形の外） |

## 5. 問題 1：長方形加算・一点取得

加算と取得が交互に来るので、点の **追加** ができる長方形和（`DynamicRectangleSum`、二進カウンタで静的なものを組み合わせたもの）を使います。

- **add(l, d, r, u, w)**：4 点 $(l, d, +w)$, $(l, u, -w)$, $(r, d, -w)$, $(r, u, +w)$ を追加。
- **get(x, y)**：$x' \le x$ かつ $y' \le y$ の重みの和、つまり長方形 $[-\infty, x + 1) \times [-\infty, y + 1)$ の和。

```cpp
void add(X l, X d, X r, X u, W w) {
    rs.add(l, d, w), rs.add(l, u, -w), rs.add(r, d, -w), rs.add(r, u, w);
}
W get(X x, X y) const {
    X lo = numeric_limits<X>::lowest();
    return rs.sum_rect(lo, lo, x + 1, y + 1);
}
```

加算ならし $O(\log^2 n)$、取得 $O(\log^2 n)$ です。

## 6. 問題 2：長方形加算の後の長方形和

### 6.1. 遅い方法

長方形の和を「マスの値の和」として計算すると、マスが $10^{18}$ 個もあるので無理です。

### 6.2. 1 次元で考える

まず 1 次元で考えます。位置 $p$ に重み $c$ の点がある（$x \ge p$ の全位置に $c$ を足す）とき、累積和 $S(X) = \sum_{x < X} a_x$ への寄与は、$p < X$ なら

$$c \times (\text{$[p, X)$ に入る位置の数}) = c\,(X - p) = X \cdot c - c\,p$$

です。よって $S(X) = X \sum c - \sum c\,p$（和は $p < X$ の点について）で、「$c$ の和」と「$cp$ の和」が分かれば求まります（BIT 2 本で区間加算・区間和をする方法と同じです）。

### 6.3. 2 次元にする

2 次元でも同じです。左下の累積和 $S(X, Y) = \sum_{x < X,\ y < Y} A_{xy}$ への、点 $(p, q, c)$ の寄与は（$p < X,\ q < Y$ なら）

$$c\,(X - p)(Y - q) = XY \cdot c - X \cdot cq - Y \cdot cp + cpq$$

です。よって

$$S(X, Y) = XY \sum c \;-\; X \sum cq \;-\; Y \sum cp \;+\; \sum cpq$$

（和は $p < X,\ q < Y$ の点について）。$X, Y$ を外に出せたので、**4 種類の重み $c,\ cp,\ cq,\ cpq$ の組について「$p < X,\ q < Y$ の点の重みの和」** が分かれば求まります。4 つの重みを組にした型を重みとして、長方形和の構造に 1 回聞けばよいです。

長方形の和は $S(r, u) - S(l, u) - S(r, d) + S(l, d)$ です。

### 6.4. 例で追う

$[1, 3) \times [1, 3)$ に 5 を足した後で考えます。点は $(1,1,+5)$, $(1,3,-5)$, $(3,1,-5)$, $(3,3,+5)$ です。

**$S(3, 3)$**（$x < 3, y < 3$ の和。正解は $5 \times 4 = 20$）：$p < 3, q < 3$ の点は $(1, 1, +5)$ だけ。

| $\sum c$ | $\sum cp$ | $\sum cq$ | $\sum cpq$ |
| --- | --- | --- | --- |
| 5 | 5 | 5 | 5 |

$$S(3, 3) = 3 \cdot 3 \cdot 5 - 3 \cdot 5 - 3 \cdot 5 + 5 = 45 - 15 - 15 + 5 = 20$$

**$S(4, 2)$**（$x < 4, y < 2$ の和。正解は $y = 1$ の行の $x = 1, 2$ で 10）：点は $(1, 1, +5)$ と $(3, 1, -5)$。

| $\sum c$ | $\sum cp$ | $\sum cq$ | $\sum cpq$ |
| --- | --- | --- | --- |
| $5 - 5 = 0$ | $5 - 15 = -10$ | $5 - 5 = 0$ | $5 - 15 = -10$ |

$$S(4, 2) = 4 \cdot 2 \cdot 0 - 4 \cdot 0 - 2 \cdot (-10) + (-10) = 20 - 10 = 10$$

### 6.5. 実装

```cpp
// 4 隅の点 (p, q, c) を，重み (c, cp, cq, cpq) で登録する
void add_corner(X p, X q, T c) {
    xs.push_back(p), ys.push_back(q);
    T tp(p), tq(q);
    ws.emplace_back(c, c * tp, c * tq, c * tp * tq);
}
// x < X, y < Y の和
T prefix(X x, X y) const {
    X lo = numeric_limits<X>::lowest();
    Quad q = rs.sum_rect(lo, lo, x, y);       // 4 つの重みの和を一度に求める
    T tx(x), ty(y);
    return tx * ty * q.c - tx * q.cq - ty * q.cp + q.cpq;
}
```

座標の積 $XY$ や $cpq$ は $10^{27}$ にもなるので、mod を取る型（modint）で計算します。構築 $O(n \log n)$、クエリ $O(\log n)$ です。

## 7. 正しさ

- 4 隅は、「$x \ge l, y \ge d$ の全マスに $+w$」から「$x \ge l, y \ge u$」と「$x \ge r, y \ge d$」を引き、引きすぎた「$x \ge r, y \ge u$」を足し戻したもの（包除原理）です。
- 6.3 の式は、各隅の点が $S(X, Y)$ の範囲で足しているマスの数を数えただけです。

## 9. まとめ

- 2 次元いもす法の差分表は 4 隅以外 0 なので、4 隅を重み付きの点として持てば、広い平面でも扱える。
- 一点の値は「左下の点の重みの和」。
- 長方形の和は、累積和を $X, Y$ の多項式に展開し、重み $(c, cp, cq, cpq)$ の左下の和で求める。
