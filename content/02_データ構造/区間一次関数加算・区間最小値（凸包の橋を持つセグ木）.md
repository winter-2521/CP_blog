## 1. 概要

本記事では、整数列 $a_0, \ldots, a_{n-1}$ に対して

- 区間 $[l, r)$ の各 $i$ に $b \cdot i + c$ を足す（**位置 $i$ によって足す量が違う**）
- 区間 $[l, r)$ の最小値を求める

をそれぞれ $O(\log^2 n)$ で処理するデータ構造を解説します。セグメント木の各ノードに「点 $(i, a_i)$ の下側凸包」を、**2 点（橋）だけ** で持たせるのがアイデアです。

>[!問題] 問題 1：Range Linear Add Range Min（Library Checker）
>長さ $N$ の整数列に「$i \in [l, r)$ について $a_i \gets a_i + b i + c$」「$\min_{i \in [l, r)} a_i$ を出力」を $Q$ 回処理してください。（$N, Q \le 10^5$）

## 2. 前提知識

- 遅延セグメント木：[[遅延セグ木まとめ]]
- 下側凸包（点の集合を下から包む折れ線）と、外積による「点が直線の上か下か」の判定

## 3. 素朴な方法と、遅延セグ木が使えない理由

愚直に足して愚直に最小値を取ると 1 回 $O(n)$ で、$10^{10}$ 回の計算になり間に合いません。

区間に **同じ値** $c$ を足すだけなら、遅延セグメント木で解けます。区間の最小値も $c$ 増えるだけだからです。しかし $b i + c$ では **位置によって足す量が違う** ので、「区間の最小値」だけ持っていても、足した後の最小値が分かりません。例えば $a = [0, 1]$ に $b = -2$ を足す（$a_i \gets a_i - 2i$）と $[0, -1]$ になり、最小値を取る位置が 0 から 1 に変わります。

## 4. 点 $(i, a_i)$ と下側凸包

各要素を平面上の点 $(i, a_i)$ とみます。次の 2 つが鍵です。

**(1) 最小値を取るのは下側凸包の頂点だけ**
点の集合を下から包む折れ線（下側凸包）の頂点にない点は、両隣の頂点を結ぶ線より上にあるので、どちらかの頂点以上の値です。また、下側凸包の辺の傾きは左から右へ増えていくので、**傾きが負から正（0 以上）に変わるところの頂点** が最小値です。

**(2) 全点に 1 次関数 $b i + c$ を足しても、凸包の形は変わらない**
3 点 $p, q, r$ について「$q$ が線分 $pr$ より下にあるか」は外積 $(q - p) \times (r - p)$ の符号で決まります。全点に $bx + c$ を足すと $y$ 座標の差は $b \times (x$ 座標の差$)$ だけ変わり、

$$(x_q - x_p)\{(y_r - y_p) + b(x_r - x_p)\} - (x_r - x_p)\{(y_q - y_p) + b(x_q - x_p)\}$$

で $b$ の項が打ち消し合います。よって、どの点が頂点かは変わりません（値は変わります）。

**例**：$a = [2, 0, 1, 3]$、点は $(0,2), (1,0), (2,1), (3,3)$。下側凸包は 4 点すべてを通り、辺の傾きは $-2, 1, 2$。傾きが負から正に変わる頂点 $(1, 0)$ が最小値 0 です。

## 5. 遅い方法：各ノードに凸包を丸ごと持つ

セグメント木の各ノードに、担当区間の点の下側凸包（頂点のリスト）を持たせてみます。

- **区間全体に足す**：(2) より形は変わらないので、遅延で「足す 1 次関数」を記録すればよい。
- **区間の一部だけに足す**：区間にまたがるノードの凸包は **形が変わります**（例は 7.4 節）。作り直すには子の凸包を合わせて $O(\text{区間の長さ})$ かかり、根では $O(n)$ です。

これでは愚直と変わりません。

## 6. 凸包を「橋」だけで表す

左の子の凸包と右の子の凸包を合わせた親の凸包は、

> 左の子の凸包の左側の部分 ＋ **左右をつなぐ 1 本の辺（橋）** ＋ 右の子の凸包の右側の部分

になります。橋は「左の子の点 $s$ と右の子の点 $t$ を結んだ線で、全ての点がその線より上（または線上）にあるもの」、つまり左右の凸包の **下側の共通接線** です。

そこで各ノードには **橋の両端 $s, t$ だけ** を持たせます。凸包のどの部分も、根から橋をたどって降りれば分かります。

### 6.1. 持っているもの

| 名前 | 意味 |
| --- | --- |
| `lx`, `ly` | 橋の左端 $s$ の位置と値（葉なら自分自身） |
| `rx`, `ry` | 橋の右端 $t$ の位置と値（葉なら自分自身） |
| `lb`, `lc` | 子にまだ伝えていない「$b i + c$ を足す」（遅延） |

`ly`, `ry` は **このノードの遅延まで反映済み** の値です。子に書いてある値には、その上のノードの遅延がまだ足されていません。そのため、子孫の点の本当の値は「書いてある値 +（途中のノードの遅延の $b$ の合計）× 位置 +（$c$ の合計）」で計算します。

**例**：$a = [2, 0, 1, 3]$（ライブラリで実際に出力した値）

```
              node1 [0,4): 橋 (1,0)-(2,1)
             /                          \
   node2 [0,2): 橋 (0,2)-(1,0)     node3 [2,4): 橋 (2,1)-(3,3)
      /        \                       /         \
  (0,2)       (1,0)                 (2,1)       (3,3)
```

根の凸包 $(0,2) \to (1,0) \to (2,1) \to (3,3)$ のうち、根の橋 $(1,0)$-$(2,1)$ は左右の子をつなぐ辺です。

### 6.2. ノードの最小値

根から次のように降ります。

- 橋の傾きが **負**（右端の方が低い）→ 最小値は橋の右側 → 右の子へ
- そうでなければ → 左の子へ
- 葉に着いたら、その値（途中の遅延を足したもの）

例（根）：橋 $(1,0)$-$(2,1)$ の傾きは $+1$ → 左の子 node2。node2 の橋 $(0,2)$-$(1,0)$ の傾きは $-2$ → 右へ → 葉 $(1, 0)$。最小値 **0** です。

区間 $[l, r)$ の最小値は、普通のセグメント木のように区間を $O(\log n)$ 個のノードに分け、それぞれで上の方法（$O(\log n)$）を使い、その最小を取ります。合計 $O(\log^2 n)$ です。

## 7. 1 次関数の加算

### 7.1. 区間全体に足すノード

ノードの区間が更新区間に完全に含まれるなら、(2) より橋は変わらないので、端点の値と遅延に足すだけです。

- `ly += b * lx + c`、`ry += b * rx + c`、`lb += b`、`lc += c`

**例：add(0, 4, b = −1, c = 0)**（$a = [2, -1, -1, 0]$）

根だけが書き換わります。

```
node1: 橋 (1,-1)-(2,-1)  遅延 b=-1     ← node2, node3 はまだ古い値のまま
```

最小値：根の橋の傾きは 0（負でない）→ 左の子 node2。node2 に書いてある橋 $(0,2)$-$(1,0)$ に根の遅延 $-1 \cdot i$ を足すと $(0,2)$-$(1,-1)$、傾き $-3$ → 右へ → 葉 $(1, 0 - 1)$ = **−1**。実際の最小値 $\min(2, -1, -1, 0) = -1$ と一致します。

### 7.2. 区間の一部に足すノード

一部だけ重なるノードでは、遅延を子に伝え（push）、子に再帰し、戻ってきたら **子から橋を計算し直します**（pull）。

**例：続けて add(2, 4, b = −3, c = 0)**（$a = [2, -1, -7, -9]$）

1. 根は一部だけ重なるので、根の遅延（$b = -1$）を子に伝えます。node2 の橋は $(0,2)$-$(1,0)$ → $(0,2)$-$(1,-1)$、node3 の橋は $(2,1)$-$(3,3)$ → $(2,-1)$-$(3,0)$ になり、それぞれ遅延 $b = -1$ を持ちます。
2. node3 $[2, 4)$ は完全に含まれるので、$b = -3$ を足して橋 $(2,-7)$-$(3,-9)$、遅延 $b = -4$。
3. 根の橋を子から計算し直します。点は $(0,2), (1,-1), (2,-7), (3,-9)$。下側凸包は $(0,2) \to (2,-7) \to (3,-9)$ になり、$(1, -1)$ は $(0,2)$ と $(2,-7)$ を結ぶ線より上なので **頂点でなくなりました**。橋は $(0,2)$-$(2,-7)$ です。

このように、一部に足すと凸包の形（橋）が変わります。この「橋の計算し直し」をどう速くするかが本題です。

## 8. 橋の計算：遅い方法（$O(\log^2 n)$）

### 8.1. 接線探し

右の子の凸包の **外（左側）** にある点 $q$ から、右の凸包に下側の接線を引いたときの接点（$q$ から見た傾きが最小の点）は、右の子から 1 本降りれば見つかります。

- 各ノードで、橋の左端への傾きと右端への傾きを比べる。右端への傾きの方が小さければ右の子へ、そうでなければ左の子へ。

凸包の上で「$q$ からの傾き」は谷が 1 つの形（減ってから増える）なので、これで谷底（接点）に着きます。$O(\log n)$ です。

### 8.2. 橋の左端を二分探索

左の子から降りて、橋の左端 $s$ を探します。今いるノード $u$ の橋（左の凸包の辺）を $(a_1, a_2)$ とします。

1. $a_2$ から右の凸包への接点 $t'$ を、接線探しで求める。
2. 傾き$(a_1 \to a_2)$ $\le$ 傾き$(a_2 \to t')$ なら、$s$ は $a_2$ 以降（$u$ の右の子）。そうでなければ $a_1$ 以前（左の子）。

葉に着いたらそれが $s$ です。最後に $s$ からの接点を求めて $t$ とします。

**例（7.2 の根の計算し直し）**：$u$ = node2、辺 $a_1 = (0, 2)$, $a_2 = (1, -1)$（傾き $-3$）。$a_2$ から右の凸包 $\{(2,-7), (3,-9)\}$ への傾きは $-6, -4$ なので接点は $(2,-7)$、傾き $-6$。$-3 \le -6$ ではないので左の子 → $s = (0, 2)$。$(0,2)$ からの傾きは $-4.5, -3.67$ なので $t = (2, -7)$。橋 $(0,2)$-$(2,-7)$ です。

### 8.3. なぜ遅いか

左の子を降りる各段で、右の子の深さぶんの接線探しをするので、1 ノードの橋の計算に $O(\log^2 n)$ かかります。更新 1 回で計算し直すノードは $O(\log n)$ 個なので、更新は $O(\log^3 n)$ です。手元の最大ケースで 1.5 秒かかりました。

## 9. 高速化：左右を同時に降りる（$O(\log n)$）

接線探しを毎回最初からやり直すのが無駄です。左の子の辺 $(a_1, a_2)$ と右の子の辺 $(b_1, b_2)$ を **同時に** 見て、どちらか一方を半分に絞ることができます（Overmars と van Leeuwen による方法）。

### 9.1. 判定の方法

左の辺を延ばした直線を $L_a$、右の辺を延ばした直線を $L_b$ とし、左右の境目の $x$ 座標を $m'$（左の子の最後の位置と右の子の最初の位置のちょうど間、例えば $1.5$）とします。$L_a$ と $L_b$ の **$x = m'$ での高さ** を比べると、次の表のように一方を絞れます。

| 傾きの関係 | $L_a(m') > L_b(m')$ | $L_a(m') < L_b(m')$ |
| --- | --- | --- |
| 左の辺の傾き > 右の辺の傾き | $s$ は $a_1$ 以前（左側を左の子へ） | $t$ は $b_2$ 以降（右側を右の子へ） |
| 左の辺の傾き ≤ 右の辺の傾き | $t$ は $b_1$ 以前（右側を左の子へ） | $s$ は $a_2$ 以降（左側を右の子へ） |

（等しいときはどちらに進んでもよいです。）毎回どちらかが 1 段降りるので、$O(\log n)$ 回で片方が葉に着きます。葉に着いたら、もう片方は接線探し 1 回で決まります。

### 9.2. 例で追う

7.2 の根の計算し直しです。左の辺 $(0,2)$-$(1,-1)$（傾き $-3$）、右の辺 $(2,-7)$-$(3,-9)$（傾き $-2$）、境目 $m' = 1.5$。

- $L_a(1.5) = 2 - 3 \times 1.5 = -2.5$
- $L_b(1.5) = -7 - 2 \times (1.5 - 2) = -6$

左の傾き $-3 \le$ 右の傾き $-2$ で、$L_a(m') > L_b(m')$ なので、表より「$t$ は $b_1$ 以前」→ 右側を左の子（葉 $(2, -7)$）へ。右が葉になったので $t = (2, -7)$ と決まり、左は $t$ からの接線探しで $s = (0, 2)$。橋 $(0,2)$-$(2,-7)$ で、遅い方法と同じ結果です。

### 9.3. 表が正しい理由

橋の傾きを $\sigma$ とすると、凸包の性質から

- $s$ が $a_1$ 以前 ⇔ 左の辺の傾き $\alpha \ge \sigma$、$s$ が $a_2$ 以降 ⇔ $\alpha \le \sigma$
- $t$ が $b_1$ 以前 ⇔ 右の辺の傾き $\beta \ge \sigma$、$t$ が $b_2$ 以降 ⇔ $\beta \le \sigma$

です。$\alpha > \beta$ の場合、$\sigma$ の位置で 3 通りに分かれます。

| 場合 | $\sigma$ の範囲 | $s$ | $t$ |
| --- | --- | --- | --- |
| (i) | $\sigma < \beta$ | $a_1$ 以前 | $b_1$ 以前 |
| (ii) | $\beta \le \sigma \le \alpha$ | $a_1$ 以前 | $b_2$ 以降 |
| (iii) | $\sigma > \alpha$ | $a_2$ 以降 | $b_2$ 以降 |

(i) のとき：橋の直線 $\ell$ は $a_1, a_2$ の下を通り、傾きが $\alpha$ より小さいので、$a_1$ より右では $L_a$ より真に下です。また $t$（$L_b$ 以上にある点）を通り、傾きが $\beta$ より小さいので、$t$ より左では $L_b$ 以上です。境目 $m'$ はこの両方の範囲に入るので、$L_b(m') \le \ell(m') < L_a(m')$ です。同様に (iii) のときは $L_a(m') < L_b(m')$ です。

したがって、$L_a(m') < L_b(m')$ なら (i) ではなく、(ii) か (iii) のどちらでも「$t$ は $b_2$ 以降」です。$L_a(m') > L_b(m')$ なら (iii) ではなく「$s$ は $a_1$ 以前」です。$\alpha \le \beta$ の場合も同様に場合分けすると表の通りになります。

### 9.4. 実装

```cpp
while (ur - ul > 1 && wr - wl > 1) {        // u: 左の子側，w: 右の子側の今いるノード
    // a1, a2: u の橋の両端，b1, b2: w の橋の両端 (途中の遅延を足した値)
    W cmp = dya * dxb - dyb * dxa;          // 傾きの差 α - β の符号
    // 2 * dxa * dxb * (La(m') - Lb(m'))，m' = m - 1/2 を整数で計算
    W dlt = dxb * (2 * a1y * dxa + dya * (2 * m - 1 - 2 * a1x))
          - dxa * (2 * b1y * dxb + dyb * (2 * m - 1 - 2 * b1x));
    bool go_u, right;
    if (cmp > 0) go_u = dlt >= 0, right = !go_u;   // u を左へ / w を右へ
    else go_u = dlt <= 0, right = go_u;            // u を右へ / w を左へ
    ...                                            // 選んだ側を 1 段降りる
}
```

境目 $m' = m - \tfrac12$ が整数でないので、両辺に $2 \times$（両辺の $x$ の差）を掛けて整数で比べます。値は $10^{12}$ 程度、$x$ の差は $10^5$ 程度なので積は $10^{22}$ を超えることがあり、`__int128` で計算しています。

この高速化で、橋の計算は 1 ノード $O(\log n)$、更新は $O(\log^2 n)$ になり、手元の最大ケースは 1.5 秒 → 0.5 秒になりました。

## 10. 問題

【問題 1】Range Linear Add Range Min は、`LinearAddMinSegmentTree<long long>` の `add(l, r, b, c)` と `min(l, r)` で解けます。

【問題 2】長さ $N$ の数列に「区間 $[l, r)$ に等差数列 $c, c + b, c + 2b, \ldots$ を足す」「区間最大値」を処理してください。
（ヒント：$a_{l+k} \mathrel{+}= bk + c$ は $a_i \mathrel{+}= b i + (c - bl)$ です。最大値は全体を $-1$ 倍して最小値を求めればよく、ライブラリでは `LinearAddMinSegmentTree<long long, true>` で直接扱えます。）

## 11. まとめ

- 区間の最小値を取るのは点 $(i, a_i)$ の下側凸包の頂点だけで、1 次関数を足しても凸包の形は変わらない。
- 各ノードに「左右の子の凸包をつなぐ橋」だけを持てば、最小値は橋の傾きの符号を見て 1 本降りるだけで求まる。
- 一部に足したときの橋の計算し直しは、接線探しを繰り返すと $O(\log^2 n)$、左右を同時に降りる方法なら $O(\log n)$。
