## 何ができるアルゴリズムか？

整数列 $a_0, \ldots, a_{n-1}$ に対して、

- 区間 $[l, r)$ の各 $i$ に $b \cdot i + c$ を足す（**位置 $i$ によって足す量が違う**）
- 区間 $[l, r)$ の最小値（最大値）

を、それぞれ $O(\log^2 n)$ で処理する。

>[!問題] Range Linear Add Range Min (Library Checker)
>長さ $N$ の数列に「$i \in [l, r)$ について $a_i \gets a_i + b i + c$」「$\min_{i \in [l, r)} a_i$ を出力」を $Q$ 回処理せよ。$N, Q \le 10^5$

## 計算量

更新・最小値ともに $O(\log^2 n)$。構築 $O(n \log n)$。

## 具体例で理解する

### まず遅い方法と、遅延セグ木が使えない理由

愚直にやると 1 回 $O(n)$ で、$10^{10}$ 回になって間に合わない。

区間加算・区間最小値なら遅延セグ木で解ける（区間の全要素に同じ $c$ を足せば最小値も $c$ 増えるだけ）。しかし $b i + c$ だと **位置によって足す量が違う** ので、「区間の最小値」だけ持っていても足した後の最小値が分からない（$b > 0$ なら左の方が有利になり、最小値を取る位置が変わる）。

### アイデア：点 $(i, a_i)$ の下側凸包

各要素を平面上の点 $(i, a_i)$ と見る。すると

- **区間の最小値を取りうるのは、その区間の点の「下側凸包」の頂点だけ**。（凸包の内側・上側にある点は、両隣の頂点を結ぶ線より上にあるので、どちらかの頂点より大きいか等しい。）
- **全点に 1 次関数 $b i + c$ を足しても、凸包の形（どの点が頂点か）は変わらない**。平面を「$y$ 方向にずらしながら傾ける」変形なので、直線は直線に移り、点が線の上か下かという関係も変わらない。

さらに、下側凸包の上で最小値を探すのは簡単：凸包の辺の傾きは左から右へ増えていくので、**傾きが負から正に変わるところの頂点** が最小値。

そこでセグ木の各ノードに、担当区間の点の下側凸包を持てば、1 次関数の加算は「凸包の頂点の値を足すだけ」で済みそうに見える。

### 遅い方法 1：各ノードに凸包を丸ごと持つ

各ノードに凸包の頂点のリストを持つ。区間全体に足す更新は遅延で済むが、区間の **一部だけ** に足すと、その区間にまたがるノードの凸包は形が変わる（点が凸包から外れたり、内側の点が頂点になったりする）。作り直すには子の凸包を合わせて $O(\text{区間の長さ})$ かかり、根では $O(n)$。これでは愚直と変わらない。

### アイデア：凸包を「橋」だけで表す

左の子の凸包と右の子の凸包を合わせて親の凸包を作るとき、親の凸包は

> 左の凸包の左側の部分 ＋ **左右をつなぐ 1 本の辺（橋）** ＋ 右の凸包の右側の部分

になる。橋は「左の凸包の頂点 $s$ と右の凸包の頂点 $t$ を結んだ線で、全ての点がその線より上にあるもの」（左右の凸包の共通接線）。

なので各ノードには **橋の両端 $s, t$ だけ** を持てばよい。凸包のどの部分も、根から橋をたどって降りれば復元できる。

### 持っているもの

| 名前 | 意味 |
| --- | --- |
| `lx`, `ly` | 橋の左端 $s$ の位置と値（葉なら自分自身） |
| `rx`, `ry` | 橋の右端 $t$ の位置と値（葉なら自分自身） |
| `lb`, `lc` | 子にまだ伝えていない「$b i + c$ を足す」（遅延） |

値 `ly`, `ry` は **このノードの遅延まで反映済み** の値。子の値には、その上の遅延をまだ足していない。なので子の点の本当の値は「子に書いてある値 + （途中のノードの遅延を全部足した $b$）× 位置 + （同じく $c$）」で計算する。

例：$a = [2, 0, 1, 3]$（点 $(0,2), (1,0), (2,1), (3,3)$）

```
              node1 [0,4): 橋 (1,0)-(2,1)
             /                         \
   node2 [0,2): 橋 (0,2)-(1,0)    node3 [2,4): 橋 (2,1)-(3,3)
      /        \                      /         \
  (0,2)       (1,0)                (2,1)       (3,3)
```

根の凸包は (0,2) → (1,0) → (2,1) → (3,3)。根の橋 (1,0)-(2,1) がその真ん中の辺になっている。

### 最小値の求め方

ノードの最小値は、根から次のように 1 本降りれば求まる。

- 橋の傾きが **負**（右端の方が低い）→ 最小値は橋の右側 → 右の子へ。
- そうでなければ → 左の子へ。
- 葉に着いたらその値（途中の遅延を足したもの）。

例（根）：橋 (1,0)-(2,1) の傾きは $+1$ → 左の子 node2 へ。node2 の橋 (0,2)-(1,0) の傾きは $-2$ → 右へ → 葉 (1,0)。最小値 **0**。

区間 $[l, r)$ の最小値は、普通のセグ木のように区間を $O(\log n)$ 個のノードに分け、それぞれで上の方法（$O(\log n)$）を使って最小を取る。

### 1 次関数を足す（区間全体に足すノード）

ノードの区間が更新区間に完全に含まれるなら、橋の端点の値に足して、遅延に記録するだけ：

- `ly += b * lx + c`、`ry += b * rx + c`、`lb += b`、`lc += c`

**例：add(0, 4, b = −1, c = 0)**（$a = [2, -1, -1, 0]$）。根だけ書き換わる：

```
node1: 橋 (1,-1)-(2,-1)  遅延 b=-1    ← node2, node3 はまだ古い値のまま
```

最小値：根の橋の傾きは 0（負でない）→ 左の子 node2。node2 に書いてある橋 (0,2)-(1,0) に根の遅延 $-1 \cdot i$ を足すと (0,2)-(1,−1)、傾き $-3$ → 右へ → 葉 (1, 0 − 1) = **−1**。実際の最小値 $\min(2, -1, -1, 0) = -1$ ✓。

### 区間の一部に足すと橋が変わる

**例：続けて add(2, 4, b = −3, c = 0)**（$a = [2, -1, -7, -9]$）

1. 根は一部だけ含まれるので、根の遅延（$b = -1$）を子に伝える（push）。node2 の橋は (0,2)-(1,0) → (0,2)-(1,−1)、node3 の橋は (2,1)-(3,3) → (2,−1)-(3,0) になり、それぞれ遅延 $b = -1$ を持つ。
2. node3 $[2,4)$ は完全に含まれるので、$b = -3$ を足して橋 (2,−7)-(3,−9)、遅延 $b = -4$。
3. 根の橋を **子から計算し直す**。点は $(0,2), (1,-1), (2,-7), (3,-9)$。下側凸包は $(0,2) \to (2,-7) \to (3,-9)$ になり（$(1,-1)$ は $(0,2)$ と $(2,-7)$ を結ぶ線より上なので頂点でなくなった）、橋は **(0,2)-(2,−7)**。

この「橋の計算し直し」をどう速くやるかが問題。

### 遅い方法 2：接線を探しながら左を二分探索（$O(\log^2 n)$ / 回）

**接線探し**：右の子の凸包の外（左側）にある点 $q$ から、右の凸包に引いた下側の接線の接点（$q$ から見た傾きが最小の点）は、右の子から 1 本降りれば見つかる。各ノードで橋の両端への傾きを比べ、右端への傾きの方が小さければ右の子へ、そうでなければ左の子へ。凸包の上で「$q$ からの傾き」は谷が 1 つの形（減ってから増える）なので、これで正しく谷底に着く。$O(\log n)$。

**橋の左端 $s$ を探す**：左の子から降りる。今いるノード $u$ の橋（左の凸包の辺）を $(a_1, a_2)$ とする。

1. $a_2$ から右の凸包への接点 $t'$ を、上の接線探しで求める。
2. 傾き $(a_1 \to a_2) \le$ 傾き $(a_2 \to t')$ なら、$s$ は $a_2$ 以降（$u$ の右の子）。そうでなければ $a_1$ 以前（左の子）。

葉に着いたらそれが $s$。最後に $s$ からの接点を求めて $t$。

例（根の計算し直し）：$u$ = node2、辺 $a_1 = (0, 2)$, $a_2 = (1, -1)$（傾き $-3$）。$a_2$ から右の凸包 $\{(2,-7), (3,-9)\}$ への傾きは $-6$, $-4$ なので接点は $(2,-7)$、傾き $-6$。$-3 \le -6$ ではないので左の子 → $s = (0, 2)$。$(0,2)$ からの傾きは $-4.5$, $-3.67$ なので $t = (2, -7)$。橋 (0,2)-(2,−7) ✓。

左の子の深さぶん降りる各ステップで、右の子の深さぶんの接線探しをするので、1 ノードの橋の計算に $O(\log^2 n)$。更新で計算し直すノードは $O(\log n)$ 個あるので、更新 1 回 $O(\log^3 n)$。手元の最大ケースで 1.5 秒かかった。

### 高速化：左右の子を同時に降りる（Overmars–van Leeuwen、$O(\log n)$）

接線探しを毎回やり直すのが無駄。左の子の辺 $(a_1, a_2)$ と右の子の辺 $(b_1, b_2)$ を **同時に** 見て、どちらか一方を半分に絞ることができる。

左の辺を延ばした直線を $L_a$、右の辺を延ばした直線を $L_b$、左右の境目を $x = m'$（左の子の最後の位置と右の子の最初の位置のちょうど間）とする。$L_a$ と $L_b$ の **$x = m'$ での高さ** を比べる。

| 傾きの関係 | $L_a(m') > L_b(m')$ のとき | $L_a(m') < L_b(m')$ のとき |
| --- | --- | --- |
| 左の辺の傾き > 右の辺の傾き | $s$ は $a_1$ 以前（左を左へ） | $t$ は $b_2$ 以降（右を右へ） |
| 左の辺の傾き ≤ 右の辺の傾き | $t$ は $b_1$ 以前（右を左へ） | $s$ は $a_2$ 以降（左を右へ） |

（等しいときはどちらに進んでもよい。）毎回どちらかが 1 段降りるので、$O(\log n)$ 回で片方が葉に着く。葉に着いたら、もう片方は接線探し 1 回で決まる。

例（同じ根の計算し直し）：左の辺 $(0,2)$-$(1,-1)$（傾き $-3$）、右の辺 $(2,-7)$-$(3,-9)$（傾き $-2$）。境目は $m' = 1.5$。

- $L_a(1.5) = 2 - 3 \times 1.5 = -2.5$
- $L_b(1.5) = -7 - 2 \times (1.5 - 2) = -6$

左の傾き $-3 \le$ 右の傾き $-2$ で、$L_a(m') > L_b(m')$ → 表より「$t$ は $b_1$ 以前」→ 右を左の子（葉 $(2,-7)$）へ。右が葉になったので $t = (2,-7)$、左は $t$ からの接線探しで $s = (0,2)$。橋 (0,2)-(2,−7) ✓（遅い方法と同じ結果）。

1 ノードの橋の計算が $O(\log n)$ になり、更新 1 回 $O(\log^2 n)$。手元の最大ケースで 1.5 秒 → 0.5 秒になった。

## 証明・仕組み

### 凸包の形が 1 次関数の加算で変わらない理由

点 $p, q, r$（$x$ 座標の順）について「$q$ が線分 $pr$ より下にある」は、外積 $(q - p) \times (r - p)$ の符号で決まる。全点に $b x + c$ を足すと $y$ 座標の差は $b \times$（$x$ 座標の差）だけ変わり、外積は

$$(x_q - x_p)\{(y_r - y_p) + b(x_r - x_p)\} - (x_r - x_p)\{(y_q - y_p) + b(x_q - x_p)\}$$

で $b$ の項が打ち消し合うので、変わらない。よって頂点も橋も変わらない。

### 橋だけで最小値が求まる理由

ノード $v$ の凸包は「左の子の凸包の $s$ まで」＋ 橋 ＋「右の子の凸包の $t$ から」。橋の傾きが負なら、凸包の辺の傾きは左から増えていくので、$s$ までの辺は全て傾きが負で、最小値は $t$ 以降（右の子の凸包の中）にある。右の子の凸包の最小値は右の子全体の最小値と一致する（右の子の凸包で $t$ より左の部分は親の凸包より上にあり、最小値になりえない）ので、右の子で同じことを繰り返せばよい。

### 同時に降りる方法の正しさ

橋の傾きを $\sigma$ とする。凸包の性質から

- $s$ が $a_1$ 以前 $\iff$ 左の辺の傾き $\alpha \ge \sigma$、$s$ が $a_2$ 以降 $\iff \alpha \le \sigma$
- $t$ が $b_1$ 以前 $\iff$ 右の辺の傾き $\beta \ge \sigma$、$t$ が $b_2$ 以降 $\iff \beta \le \sigma$

$\alpha > \beta$ の場合、$\sigma$ の位置で 3 通り：(i) $\sigma < \beta$（$s \le a_1$ かつ $t \le b_1$）、(ii) $\beta \le \sigma \le \alpha$（$s \le a_1$ かつ $t \ge b_2$）、(iii) $\sigma > \alpha$（$s \ge a_2$ かつ $t \ge b_2$）。

(i) のとき、橋の直線 $\ell$ は $a_1, a_2$ の下を通り傾きが $\alpha$ より小さいので、$a_1$ より右では $L_a$ より真に下。また $t$（$L_b$ の上にある）を通り傾きが $\beta$ より小さいので、$t$ より左では $L_b$ 以上。境目 $m'$ はこの両方の範囲に入るので $L_b(m') \le \ell(m') < L_a(m')$。同様に (iii) のときは $L_a(m') < L_b(m')$。

よって $L_a(m') < L_b(m')$ なら (i) ではない → (ii) か (iii) → どちらでも $t \ge b_2$。$L_a(m') > L_b(m')$ なら (iii) ではない → $s \le a_1$。等しければ (ii) で、どちらも成り立つ。$\alpha \le \beta$ の場合も同様に場合分けすると表のとおりになる。

境目を整数でない $m' = m - \frac12$ に取るので、比べるときは両辺に $2 \times$（両辺の $x$ の差）を掛けて整数で計算する（値が大きくなるので `__int128` を使う）。

### 計算量

- 最小値：区間を $O(\log n)$ 個のノードに分け、それぞれ $O(\log n)$ で降りる → $O(\log^2 n)$。
- 更新：遅延を押し込む・橋を計算し直すノードが $O(\log n)$ 個、1 個 $O(\log n)$ → $O(\log^2 n)$。

- **区間に等差数列を足す・区間最大値**：最大値版（`LinearAddMinSegmentTree<long long, true>`）を使う。左端からの距離で足したい（$a_{l+k} \mathrel{+}= b k + c$）ときは $c$ を $c - b l$ にすればよい。
- **点の集合の凸包を動的に保つ**：橋だけを持つ木は、点の追加・削除がある凸包（Overmars–van Leeuwen の動的凸包）と同じ考え方。
