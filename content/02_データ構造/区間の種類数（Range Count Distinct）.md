#データ構造 #区間クエリ #ウェーブレット行列 #BIT

ライブラリ：[static_range_count_distinct.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/static_range_count_distinct.hpp)

## 何ができるアルゴリズムか？

静的な数列 $a$ について「$a_l, \ldots, a_{r-1}$ に何種類の値があるか」を $O(\log n)$ で答える。クエリを先読みしなくてよい（オンライン）。

>[!問題] Static Range Count Distinct (Library Checker)
>長さ $N$ の数列に「$a_l, \ldots, a_{r-1}$ の種類数」を $Q$ 回答えよ。$N, Q \le 5 \times 10^5$

## 計算量

構築 $O(n \log n)$、クエリ $O(\log n)$。

## 具体例で理解する

例：$a = [3, 1, 3, 2, 3, 1]$（位置 0〜5）

### まず遅い方法

区間の値を集合（`set` やハッシュ）に入れて大きさを見る。1 回 $O(r - l)$ で、最悪 $2.5 \times 10^{11}$ 回。

### アイデア：各値は「区間の中で一番左の出現」だけ数える

区間の中に同じ値が何個あっても、**一番左のもの** だけ数えれば種類数になる。位置 $i$ が「区間 $[l, r)$ の中で $a_i$ の一番左の出現」かどうかは、

> $\mathrm{prev}_i$ ＝ $i$ より前で $a_i$ と同じ値が最後に出てくる位置（なければ $-1$）

を使うと、「$\mathrm{prev}_i < l$」（$a_i$ と同じ値が区間内の $i$ より左にない）と同じ。よって

$$\text{種類数} = \#\{\, i \in [l, r) : \mathrm{prev}_i < l \,\}$$

| 位置 $i$ | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| $a_i$ | 3 | 1 | 3 | 2 | 3 | 1 |
| $\mathrm{prev}_i$ | −1 | −1 | 0 | −1 | 2 | 1 |

例：$[1, 5)$（中身 1, 3, 2, 3）では $\mathrm{prev}_1..\mathrm{prev}_4 = -1, 0, -1, 2$ のうち 1 未満は $-1, 0, -1$ の 3 個 → **3 種類**（1, 3, 2）。位置 4 の 3 は $\mathrm{prev}_4 = 2 \ge 1$ なので数えない（区間内の左に同じ 3 がある）。

これは「$\mathrm{prev}$ の列の区間 $[l, r)$ の中で、値が $l$ 未満のものの個数」なので、長方形の中の点を数える問題（点 $(i, \mathrm{prev}_i)$ のうち $l \le i < r$ かつ $\mathrm{prev}_i < l$ のもの）になった。

### 方法 1（オフライン）：右端でソートして BIT

クエリを先に全部読んでよいなら、クエリを右端 $r$ の小さい順に処理し、$i = 0, 1, \ldots$ と右に進みながら「各値の **最後の出現位置** にだけ 1 を立てた BIT」を更新する（$a_i$ が来たら $\mathrm{prev}_i$ の 1 を消して $i$ に 1 を立てる）。右端が $r$ のときの $[l, r)$ の和が答え。$O((n + q) \log n)$。

ただしクエリを全部先に読まないといけない。

### 方法 2（オンライン、このライブラリ）：ウェーブレット行列

$\mathrm{prev}$ の列でウェーブレット行列（[[ウェーブレット行列]]）を作っておけば、「区間 $[l, r)$ の中で値が $l$ 未満のものの個数」は `count_lt(l, r, l)` 1 回、$O(\log n)$ で求まる。クエリごとにすぐ答えられる。

### 持っているもの

| 名前 | 意味 |
| --- | --- |
| `wm` | $\mathrm{prev}$ の列のウェーブレット行列 |

$\mathrm{prev}$ は、位置を「値の昇順、同じ値なら位置の昇順」に並べ、隣り合う 2 つが同じ値なら前の位置を後ろの $\mathrm{prev}$ にする、で $O(n \log n)$ で作れる。

### 例で追う

**count(1, 5)**：`wm.count_lt(1, 5, 1)` ＝ $\mathrm{prev}_1..\mathrm{prev}_4 = [-1, 0, -1, 2]$ の中の 1 未満の個数 = **3**。

**count(3, 6)**（中身 2, 3, 1）：$\mathrm{prev}_3..\mathrm{prev}_5 = [-1, 2, 1]$ の中の 3 未満の個数 = **3**。位置 4 の 3 は $\mathrm{prev}_4 = 2$ だが、位置 2 は区間の外（$2 < 3$）なので、区間内では一番左として数える。

## 証明・仕組み

区間 $[l, r)$ に出てくる各値 $v$ について、$v$ の区間内の出現位置を $i_1 < i_2 < \cdots$ とすると、

- $i_1$：$i_1$ より前の $v$ の出現は全て $l$ より前なので $\mathrm{prev}_{i_1} < l$。数える。
- $i_2, i_3, \ldots$：$\mathrm{prev}_{i_k} = i_{k-1} \ge l$。数えない。

よって各値がちょうど 1 回ずつ数えられる。

## 例題・類題

- [Static Range Count Distinct (Library Checker)](https://judge.yosupo.jp/problem/static_range_count_distinct)
- [ABC174 F - Range Set Query](https://atcoder.jp/contests/abc174/tasks/abc174_f)：同じ問題（$N, Q \le 5 \times 10^5$）。
- **「一番左の出現だけ数える」→ prev を使って長方形の点の数に直す** は、区間の種類数の重み付き版（種類ごとの重みの和）などにもそのまま使える（BIT に 1 ではなく重みを立てる）。
