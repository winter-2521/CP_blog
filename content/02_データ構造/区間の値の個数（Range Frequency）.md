#データ構造 #区間クエリ #二分探索

ライブラリ：[static_range_frequency.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/static_range_frequency.hpp)、[dynamic_range_frequency.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/dynamic_range_frequency.hpp)

## 何ができるアルゴリズムか？

数列 $a$ について「$a_l, a_{l+1}, \ldots, a_{r-1}$ の中に値 $x$ が何個あるか」を $O(\log n)$ で答える。値の書き換え（一点更新）があっても $O(\log n)$ でできる。

>[!問題] Static Range Frequency (Library Checker)
>長さ $N$ の数列に「$a_l, \ldots, a_{r-1}$ の中の $x$ の個数」を $Q$ 回答えよ。$N, Q \le 5 \times 10^5$、$a_i, x \le 10^9$

>[!問題] Point Set Range Frequency (Library Checker)
>上の問題に「$a_k \gets v$」の更新が加わる。$N, Q \le 2 \times 10^5$

## 計算量

| | 構築 | 更新 | クエリ |
| --- | --- | --- | --- |
| 静的（`StaticRangeFrequency`） | $O(n \log n)$ | なし | $O(\log n)$ |
| 一点更新あり（`DynamicRangeFrequency`） | $O(n \log n)$ | $O(\log n)$ | $O(\log n)$ |

## 具体例で理解する

例：$a = [3, 1, 3, 2, 3, 1]$（位置 0〜5）

### まず遅い方法

区間を左から右まで見て、$x$ と等しいものを数える。1 回 $O(r - l)$ で、$N, Q = 5 \times 10^5$ だと最悪 $2.5 \times 10^{11}$ 回で間に合わない。

「値ごとに累積和を作る」（$c_x[i]$ = 先頭 $i$ 個の中の $x$ の個数）と 1 回 $O(1)$ になるが、値の種類 × $n$ の表になり、種類が多いとメモリが足りない。

### アイデア：値ごとに「出てくる位置のリスト」を作る

値 $x$ が出てくる位置を小さい順に並べたリストを作る。$[l, r)$ の中の $x$ の個数は、「リストの中で $l$ 以上 $r$ 未満のものの個数」なので、**リストの上で二分探索 2 回** で求まる。リストの長さの合計は $n$ なのでメモリも $O(n)$。

### 持っているもの（静的）

| 名前 | 意味 |
| --- | --- |
| `vals` | 出てくる値の種類（昇順） |
| `pos` | 位置を「値の昇順、同じ値なら位置の昇順」に並べたもの |
| `start` | 値 `vals[k]` の位置は `pos[start[k]]` 〜 `pos[start[k+1] - 1]` |

例の場合：

```
vals  = [1, 2, 3]
pos   = [1, 5 | 3 | 0, 2, 4]     ← 1 の位置 / 2 の位置 / 3 の位置
start = [0, 2, 3, 6]
```

### 操作の手順：count(l, r, x)

1. `vals` を二分探索して $x$ の番号 $k$ を求める（なければ 0 個）。
2. `pos[start[k] .. start[k+1])`（$x$ の位置のリスト）の中で、「$r$ 以上の最初の場所」と「$l$ 以上の最初の場所」を二分探索で求め、差を答える。

### 例で追う

**count(1, 5, 3)**（$a_1, \ldots, a_4 = 1, 3, 2, 3$ の中の 3 の個数）：

1. `vals` の中で 3 は $k = 2$。3 の位置のリストは `pos[3..6)` = $[0, 2, 4]$。
2. 5 以上の最初の場所：$[0, 2, 4]$ の 3 番目（末尾の外）。1 以上の最初の場所：1 番目（値 2）。差 $3 - 1 = $ **2**。

### 値の書き換えがあるとき

リストを配列で持っていると、書き換えのたびにリストへの挿入・削除で $O(n)$ かかる。そこで「(値, 位置) の組」を全部まとめて **順序付き集合**（[[順序付き集合（ブロックAVL木）]]）に入れる。組は「値で比べて、同じなら位置で比べる」ので、集合の中では例と同じ順に並ぶ：

```
(1,1) (1,5) (2,3) (3,0) (3,2) (3,4)
```

- **count(l, r, x)**：$(x, l)$ 以上 $(x, r)$ 未満の組の個数 ＝「$(x, r)$ 未満の個数」−「$(x, l)$ 未満の個数」。順序付き集合は「ある値未満の要素の個数」を $O(\log n)$ で数えられる。
- **set(i, v)**：組 $(a_i, i)$ を削除し、$(v, i)$ を挿入する。

例：set(1, 3) で $a = [3, 3, 3, 2, 3, 1]$ にすると、$(1, 1)$ を消して $(3, 1)$ を入れる。count(0, 3, 3) は「$(3, 3)$ 未満」の 5 個 −「$(3, 0)$ 未満」の 2 個 = **3**。

## 証明・仕組み

- 位置のリストはソートされているので、「$l$ 以上の最初の場所」から「$r$ 以上の最初の場所」の手前までが、ちょうど位置が $[l, r)$ に入る $x$ の出現。
- 順序付き集合版も同じで、$(x, l) \le (y, i) < (x, r)$ となる組は「$y = x$ かつ $l \le i < r$」と同じ（辞書式順序）。
