#データ構造 #ウェーブレット行列 #2次元 #二進カウンタ

ライブラリ：[static_rectangle_sum.hpp](https://github.com/winter-2521/cp-library/blob/main/data_structure/static_rectangle_sum.hpp)

## 1. 概要

本記事では、平面上の重み付きの点について、「$l \le x < r$ かつ $d \le y < u$ を満たす点の重みの和」に答える方法を解説します。

- 点が固定の場合（`StaticRectangleSum`）：**重み付きウェーブレット行列** で、1 回 $O(\log n)$。
- 点の追加がある場合（`DynamicRectangleSum`）：**二進カウンタ** で静的なものを組み合わせ、追加ならし $O(\log^2 n)$・和 $O(\log^2 n)$。

どちらもクエリを先読みしなくてよい（オンライン）方法です。

>[!問題] 問題 1：Rectangle Sum（Library Checker）
>$N$ 個の重み付きの点に対して、長方形の中の重みの和を $Q$ 回答えてください。（$N, Q \le 2 \times 10^5$、座標・重み $\le 10^9$）

>[!問題] 問題 2：Point Add Rectangle Sum（Library Checker）
>問題 1 に「点 $(x, y)$ に重み $w$ の点を追加」が加わります。（$N, Q \le 10^5$）

## 2. 前提知識

- ウェーブレット行列（特に「区間の中で値が $v$ 未満のものの個数」）：[[ウェーブレット行列]]、[AtCoder アルゴリズム講座 - Wavelet Matrix 基礎](https://info.atcoder.jp/entry/algorithm_lectures/wavelet_matrix_basic)
- 座標圧縮、二分探索

## 3. 素朴な方法

- **全部見る**：1 回 $O(n)$、全体 $O(nq) = 4 \times 10^{10}$ で間に合いません。
- **2 次元累積和**：座標が $10^9$ まであるので表が作れません。座標圧縮しても $n \times n$ の表で $4 \times 10^{10}$ マスです。
- **オフラインの平面走査**：長方形の和を「$x < r$ の部分 − $x < l$ の部分」に分け、$x$ の小さい順に点を BIT（$y$ で添字）に入れながら、各クエリの $x$ の位置で $[d, u)$ の和を取ります。$O((n + q) \log n)$ で速いですが、クエリを全部先に読む必要があります。

## 4. $x$ でソートして、$y$ の列にウェーブレット行列

点を **$x$ の小さい順** に並べると、「$l \le x < r$」は並べた列の **連続した区間** $[i_l, i_r)$ になります（$x$ の列の二分探索で求まります）。あとは、

> 列の区間 $[i_l, i_r)$ の中で、$y$ が $[d, u)$ に入る点の重みの和

が分かればよく、これは「区間の中で値が $v$ 未満のものの **個数**」（ウェーブレット行列の基本操作）を、**重みの和** に変えたものです。

### 4.1. 例

4 点 $(5, 2)$, $(1, 3)$, $(3, 0)$, $(7, 1)$、重みは順に 10, 20, 30, 40 とします。$x$ でソートし、$y$ を座標圧縮した番号にします（$y$ は $0, 1, 2, 3$ なので番号もそのまま）。

| $x$ の順 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| $x$ | 1 | 3 | 5 | 7 |
| $y$ の番号 | 3 | 0 | 2 | 1 |
| 重み | 20 | 30 | 10 | 40 |

## 5. 重み付きウェーブレット行列

### 5.1. ウェーブレット行列の復習

$y$ の番号を $L$ ビットの 2 進数とみて、上のビットから段ごとに処理します。段 $h$ では、その段の列の各値の第 $h$ ビットを並べたビット列 $B_h$ を持ち、次の段の列は「第 $h$ ビットが 0 のもの → 1 のもの」の順に（元の順番を保って）並べ替えたものです。$z_h$ は $B_h$ の 0 の個数です。

段 $h$ で見ている区間 $[l, r)$ の中で、第 $h$ ビットが

- **0** のものは、次の段で $[\,l - \mathrm{rank}_h(l),\ r - \mathrm{rank}_h(r)\,)$ に
- **1** のものは、次の段で $[\,z_h + \mathrm{rank}_h(l),\ z_h + \mathrm{rank}_h(r)\,)$ に

まとまって並びます（$\mathrm{rank}_h(i)$ は $B_h$ の先頭 $i$ 個の中の 1 の個数）。

### 5.2. 重みの累積和を足す

各段で、**振り分けた後の列** の重みの累積和 `sum[h]` を持ちます。

| 名前 | 意味 |
| --- | --- |
| $B_h$, $z_h$ | ウェーブレット行列のビット列と 0 の個数 |
| `sum[h][i]` | 段 $h$ で振り分けた後の列の、先頭 $i$ 個の重みの和 |

すると「段 $h$ の区間のうち第 $h$ ビットが 0 のものの重みの和」は、振り分けた後の区間 $[l_0, r_0)$ について `sum[h][r0] - sum[h][l0]` で $O(1)$ です。

### 5.3. 例の各段（ライブラリで出力したもの）

$y$ の番号は 2 ビットです。

- **段 1**（上のビット）：列の番号 $[3, 0, 2, 1]$ → $B_1 = 1\,0\,1\,0$、$z_1 = 2$。振り分けた後の列は「0 の側 $[0, 1]$ → 1 の側 $[3, 2]$」、重みは $[30, 40, 20, 10]$ なので `sum[1]` = $[0, 30, 70, 90, 100]$。
- **段 0**：列の番号 $[0, 1, 3, 2]$ → $B_0 = 0\,1\,1\,0$、$z_0 = 2$。振り分けた後は「$[0, 2]$ → $[1, 3]$」、重み $[30, 10, 40, 20]$ なので `sum[0]` = $[0, 30, 40, 80, 100]$。

### 5.4. $v$ 未満の重みの和

**prefix(l, r, v)**（$x$ の順で $[l, r)$ 番目の点のうち、$y$ の番号が $v$ 未満のものの重みの和）は、上の段から順に次のようにします。

1. 区間 $[l, r)$ の中で第 $h$ ビットが 0 のものは、振り分けた後の $[l_0, r_0)$ にある。
2. $v$ の第 $h$ ビットが **1** なら：0 の側の点は（ここまでのビットが $v$ と同じで、このビットが小さいので）**全部 $v$ 未満**。`sum[h][r0] - sum[h][l0]` を答えに足す。区間を 1 の側へ移す。
3. **0** なら：区間を 0 の側 $[l_0, r_0)$ へ移すだけ。

**sum_rect(l, d, r, u)** は、$x$ を二分探索して $[i_l, i_r)$、$y$ を二分探索して番号 $[y_d, y_u)$ にし、`prefix(i_l, i_r, y_u) - prefix(i_l, i_r, y_d)` です。

### 5.5. 例で追う：sum_rect(2, 1, 8, 3)

$2 \le x < 8$、$1 \le y < 3$ の点は $(5, 2)$ と $(7, 1)$ なので、答えは $10 + 40 = 50$ です。

$x$ の区間は $[1, 4)$（$x = 3, 5, 7$）、$y$ の番号は $[1, 3)$ です。

**prefix(1, 4, 3)**（$v = 3 = 11_{(2)}$）：

| 段 | 区間 | 区間内のビット | $v$ のビット | 足す | 次の区間 |
| --- | --- | --- | --- | --- | --- |
| 1 | $[1, 4)$ | $0\,1\,0$ | 1 | 0 の側 $[1 - 1,\ 4 - 2) = [0, 2)$ の和 = `sum[1][2] - sum[1][0]` = 70 | 1 の側 $[2 + 1,\ 2 + 2) = [3, 4)$ |
| 0 | $[3, 4)$ | $0$ | 1 | 0 の側 $[3 - 2,\ 4 - 2) = [1, 2)$ の和 = `sum[0][2] - sum[0][1]` = 10 | — |

合計 80（番号 0, 1, 2 の点：重み 30, 40, 10）。

**prefix(1, 4, 1)**（$v = 1 = 01_{(2)}$）：

| 段 | 区間 | 区間内のビット | $v$ のビット | 足す | 次の区間 |
| --- | --- | --- | --- | --- | --- |
| 1 | $[1, 4)$ | $0\,1\,0$ | 0 | — | 0 の側 $[0, 2)$ |
| 0 | $[0, 2)$ | $0\,1$ | 1 | 0 の側 $[0, 1)$ の和 = `sum[0][1] - sum[0][0]` = 30 | — |

合計 30（番号 0 の点）。

答えは $80 - 30 = $ **50** です。

### 5.6. 実装

```cpp
W prefix_from(int l, int r, int v, int h0) const {
    W res(0);
    for (int h = h0; h >= 0; h--) {
        int l1 = bv[h].rank1(l), r1 = bv[h].rank1(r);
        int l0 = l - l1, r0 = r - r1;            // 0 の側の区間
        if (v >> h & 1) {
            res += sum[h][r0] - sum[h][l0];      // 0 の側は全部 v 未満
            l = zeros[h] + l1, r = zeros[h] + r1; // 1 の側へ
        } else {
            l = l0, r = r0;                      // 0 の側へ
        }
    }
    return res;
}
```

ライブラリでは、2 つの prefix が上の段で同じ側に進む間（$y_d$ と $y_u$ のビットが等しい間）はまとめて 1 回だけ降りるようにしています。

## 6. 点の追加：二進カウンタ

### 6.1. 遅い方法

ウェーブレット行列は作り直さないと点を追加できません。追加のたびに全部作り直すと、1 回 $O(n \log n)$ かかります。

### 6.2. 大きさが 2 冪のかたまりに分ける

点を「大きさ $1, 2, 4, 8, \ldots$ のかたまり」に分け、かたまりごとに静的なもの（重み付きウェーブレット行列）を作ります。

- **和**：全部のかたまりの和を足します。かたまりは高々 $\log_2 n + 1$ 個なので $O(\log^2 n)$。
- **追加**：大きさ 1 のかたまりを作り、**同じ大きさのかたまりがあれば併合** して作り直します。2 進数の足し算の繰り上がりと同じです。

ライブラリで 5 個追加したときのかたまりの大きさは次の通りです。

| 追加した個数 | かたまりの大きさ | 2 進数 |
| --- | --- | --- |
| 1 | 1 | 1 |
| 2 | 2 | 10 |
| 3 | 2, 1 | 11 |
| 4 | 4 | 100 |
| 5 | 4, 1 | 101 |

### 6.3. 計算量

1 つの点が作り直しに巻き込まれるたびに、その点のいるかたまりの大きさは 2 倍以上になるので、巻き込まれるのは $\log_2 n$ 回までです。作り直しのコストは点 1 個あたり $O(\log n)$ なので、追加はならし $O(\log^2 n)$ です。

## 7. 問題

【問題 1】Rectangle Sum は `StaticRectangleSum<int, long long>` の `sum_rect(l, d, r, u)` で、【問題 2】Point Add Rectangle Sum は `DynamicRectangleSum<int, long long>` の `add(x, y, w)` と `sum_rect` で解けます。

【問題 3】点の重みを後から変更（$w_i \gets w$）できるようにしてください。
（ヒント：同じ座標に、差分 $w - w_i$ の重みの点を追加すればよいです。）

## 8. まとめ

- 点を $x$ でソートすると、$x$ の範囲は列の区間になる。$y$ の範囲は、ウェーブレット行列で「$v$ 未満」を 2 回求めて差を取る。
- 重みの和は、各段で振り分けた後の列の重みの累積和を持てば、「0 の側の重みの和」が $O(1)$ で分かる。
- 追加ができない静的な構造は、二進カウンタで「大きさ 2 冪のかたまり」に分けると、ならし $O(\log)$ 倍の遅さで追加できるようになる。
