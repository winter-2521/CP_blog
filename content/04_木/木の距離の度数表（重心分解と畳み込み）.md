#木 #重心分解 #畳み込み #FFT

ライブラリ：[frequency_table_of_tree_distance.hpp](https://github.com/winter-2521/cp-library/blob/main/tree/frequency_table_of_tree_distance.hpp)

## 1. 概要

木の全ての頂点の組について距離を数え、「距離 $d$ の組がいくつあるか」の表を作ります。**重心分解** で「重心を通る組」に分け、重心からの深さの度数を **畳み込む** と、$O(n \log^2 n)$ で求まります。

>[!問題] 問題 1：Frequency Table of Tree Distance（Library Checker）
>$N$ 頂点の木で、距離（辺の本数）が $i$ の頂点の組 $\{u, v\}$ の個数 $x_i$ を $i = 1, \dots, N-1$ について求めてください。（$N \le 2 \times 10^5$）

## 2. 前提知識

- 木の重心（取り除くと各部分の大きさが $n/2$ 以下になる頂点）
- [[畳み込み（NTT）]]

## 3. 素朴な方法

全ての頂点から BFS すれば $O(n^2)$ で、$n = 2 \times 10^5$ では $4 \times 10^{10}$ となり間に合いません。

## 4. 重心分解

### 4.1. 重心を通る組に分ける

木の重心 $c$ を 1 つ選ぶと、全ての組 $\{u, v\}$ は

- $c$ を通る（$u$ と $v$ が $c$ の別々の子の部分木にある、またはどちらかが $c$）
- $c$ を通らない（同じ子の部分木の中）

のどちらかです。$c$ を通る組を数えたら $c$ を取り除き、残りの各部分木で同じことを再帰的に行います。重心で分けると部分木の大きさが半分以下になるので、再帰の深さは $O(\log n)$、各深さで扱う頂点の合計は $n$ です。

### 4.2. $c$ を通る組を数える

$c$ を通る組の距離は「$c$ からの深さの和」です。子の部分木ごとに深さの度数 $C_i[d]$（深さ $d$ の頂点の数）を作り、

$$
(\text{距離 } d \text{ の組}) = \sum_{i < j} (C_i * C_j)[d] + (c \text{ と各頂点の組})
$$

です（$*$ は畳み込み）。$c$ 自身を「深さ 0 が 1 個」の度数 $[1]$ として扱えば、まとめて

- それまでの度数の和 $A$（最初は $[1]$）と、次の子の度数 $C$ を畳み込んで足す
- $A \mathrel{+}= C$

を子ごとに繰り返せば数えられます。

### 4.3. 浅い順に畳み込む

$A$ と $C$ の畳み込みは長さ $|A| + |C|$ の FFT で $O((|A| + |C|) \log n)$ です。子を **深さの浅い順** に処理すると $|A| \le |C|$ なので、1 回 $O(|C| \log n)$、各重心で $O(\text{成分の大きさ} \times \log n)$ になります。全体 $O(n \log^2 n)$ です。

素朴に「全体の度数 $D$ を自分自身と畳み込み、各子の $C_i$ の 2 乗を引いて 2 で割る」方法もありますが、畳み込みの回数が増えて約 2.5 倍遅くなりました。

### 4.4. 例で追う

8 頂点、辺 0–1, 1–2, 2–3, 1–4, 4–7, 1–5, 2–6 の木です。

**重心 1**（成分の大きさ 8）。子の部分木の深さの度数（深さ 0, 1, 2, …）：

| 子 | 0 | 5 | 2（{2, 3, 6}） | 4（{4, 7}） |
| --- | --- | --- | --- | --- |
| 度数 $C$ | [0, 1] | [0, 1] | [0, 1, 2] | [0, 1, 1] |

| 処理 | $A$ | $A * C$ | 足される組（距離 1, 2, 3, 4） |
| --- | --- | --- | --- |
| 子 0 | [1] | [0, 1] | 1, 0, 0, 0 |
| 子 5 | [1, 1] | [0, 1, 1] | 1, 1, 0, 0 |
| 子 2 | [1, 2] | [0, 1, 4, 4] | 1, 4, 4, 0 |
| 子 4 | [1, 3, 2] | [0, 1, 4, 5, 2] | 1, 4, 5, 2 |

重心 1 を通る組は距離 1: 4, 2: 9, 3: 9, 4: 2。

**残りの成分**：{4, 7}（重心 4）で距離 1 が 1 組、{2, 3, 6}（重心 2）で距離 1 が 2 組・距離 2 が 1 組、{0}, {5} は組なし。

合計は距離 1: 7, 2: 10, 3: 9, 4: 2 で、ライブラリの出力 `7 10 9 2 0 0 0` と一致します。

### 4.5. 畳み込みの精度

組の数は最大 $n^2/2 = 2 \times 10^{10}$ 程度で、998244353 では割り切れてしまいます。そこで 2 つの素数（998244353 と 754974721）で NTT し、中国剰余定理で $7.5 \times 10^{17}$ 未満の値を正確に復元します（`convolve_small`）。

## 5. 実装

```cpp
// 重心 c について，子の部分木ごとの深さの度数 cnts を作ったあと
sort(cnts.begin(), cnts.end(), [](const auto &x, const auto &y) { return x.size() < y.size(); });
vector<long long> acc{1};                      // c 自身 (深さ 0)
for (auto &cnt : cnts) {
    auto pr = convolve_small(acc, cnt);
    for (int d = 1; d < (int)pr.size(); d++) res[d] += pr[d];
    if (acc.size() < cnt.size()) acc.resize(cnt.size(), 0);
    for (size_t d = 0; d < cnt.size(); d++) acc[d] += cnt[d];
}
removed[c] = 1;                                 // c を取り除いて各成分へ
```

重心の探し方：成分を BFS して部分木の大きさを求め、根から「大きさが成分の半分を超える子」へ進めなくなるまで下ります。再帰の代わりにスタックで成分を管理しています。

## 6. 正しさ・計算量

- **正しさ**：各組は、それを通る最初の重心でちょうど 1 回数えられます。
- **計算量**：重心分解の深さ $O(\log n)$、各深さで畳み込みの合計 $O(n \log n)$ なので $O(n \log^2 n)$。

## 8. まとめ

- 重心で「重心を通る組」と「各部分木の中の組」に分け、再帰する（深さ $O(\log n)$）。
- 重心を通る組は、子の深さの度数を浅い順に畳み込んで数える。
- 個数が大きいので 2 つの素数の NTT + 中国剰余定理で正確に。全体 $O(n \log^2 n)$。
