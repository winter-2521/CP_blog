## 1. 概要

無向グラフの **独立集合**（どの 2 頂点も辺で結ばれていない頂点集合）のうち最大のものを求めます。一般には NP 困難ですが、$n \le 40$ 程度なら **分枝限定法** で十分速く解けます。頂点集合を 64 bit 整数で持ち、

- 次数 0, 1 の頂点は無条件に取る
- 次数 3 以上の頂点で「取る / 取らない」に分岐する
- 見込みのない枝は打ち切る

ことで、$O(1.381^n)$ 程度になります。

>[!問題] 問題 1：Maximum Independent Set（Library Checker）
>$N$ 頂点 $M$ 辺の単純無向グラフの最大独立集合を 1 つ出力してください。（$N \le 40$）

## 2. 前提知識

- bit 全探索、bit 演算（`popcount`, `ctz`）
- 再帰

## 3. 素朴な方法

$2^n$ 通りの頂点集合を全て試すと $O(2^n \cdot n)$ です。$n = 40$ では $2^{40} \approx 10^{12}$ で間に合いません。

半分全列挙（前半 20 頂点と後半 20 頂点に分ける）で $O(2^{n/2} n)$ にする方法もありますが、ここでは「グラフの形を見て枝を減らす」分枝の方法を説明します。

## 4. 分枝の工夫

残っている頂点集合を `rem`（64 bit）、各頂点の隣接を `nb[v]`（64 bit）で持ちます。$v$ の残りの次数は `popcount(nb[v] & rem)` です。

### 4.1. 次数 0, 1 の頂点は取ってよい

- 次数 0 の頂点 $v$ は、取っても誰とも衝突しないので取ります。
- 次数 1 の頂点 $v$（隣は $u$ だけ）は、最適解が $u$ を使っていても、$u$ を $v$ に替えれば同じ大きさの独立集合になります（$v$ の隣は $u$ しかない）。だから $v$ を取り、$u$ を消してよいです。

### 4.2. 次数最大の頂点で分岐

それ以外のときは、次数最大の頂点 $v$ について

- **取る**：$v$ と隣を全部消す（頂点が $1 + \deg v$ 個減る）
- **取らない**：$v$ だけ消す（1 個減る）

に分岐します。次数が 3 以上なら $T(n) \le T(n - 1) + T(n - 4)$ で、$T(n) = O(1.381^n)$ です。次数が全て 2 以下（道と閉路の集まり）になれば、4.1 節の規則と 1 回の分岐ですぐ終わります。

### 4.3. 打ち切り

「今取った数 + 残りの頂点数」が今までの最良以下なら、その先を調べても更新できないので打ち切ります。

## 5. 例で追う

7 頂点、辺 0–1, 0–2, 0–3, 0–4, 1–2, 2–3, 3–4, 4–1, 4–5, 5–6, 6–2, 1–5 のグラフです（頂点 0 は 1〜4 とつながり、1, 2, 3, 4 は閉路、5, 6 がぶら下がっています）。

| 深さ | 残り | 動作 |
| --- | --- | --- |
| 0 | {0,…,6} | 次数 0, 1 の頂点はない。次数最大は 0（次数 4）→ 分岐 |
| 1 | 0 を取る：{5, 6} | 5 は次数 1 → 取る（6 を消す）。2 個 → **最良 2** |
| 1 | 0 を取らない：{1,…,6} | 次数最大は 1（次数 3：2, 4, 5）→ 分岐 |
| 2 | 1 を取る：{3, 6} | 3, 6 とも次数 0 → 取る。3 個 → **最良 3** |
| 2 | 1 を取らない：{2,…,6} | 次数最大は 2（次数 2）→ 分岐 |
| 3 | 2 を取る：{4, 5} | 4 は次数 1 → 取る（5 を消す）。2 個、残り 0 → 3 以下なので打ち切り |
| 3 | 2 を取らない：{3,…,6} | 3 は次数 1 → 取る（4 を消す）、5 は次数 1 → 取る。2 個 → 打ち切り |

答えは {1, 3, 6}（大きさ 3）で、ライブラリの出力と一致します。$2^7 = 128$ 通りではなく、7 回の再帰で済んでいます。

## 6. 実装

```cpp
auto rec = [&](auto self, u64 rem, u64 cur, int cnt) -> void {
    // 次数 0, 1 の頂点を取れるだけ取る
    while (true) {
        bool changed = false;
        for (u64 r = rem; r;) {
            int v = __builtin_ctzll(r);
            r &= r - 1;
            if (!(rem >> v & 1)) continue;             // 途中で消えた
            if (__builtin_popcountll(nb[v] & rem) <= 1) {
                cur |= 1ULL << v, cnt++;
                rem &= ~(nb[v] | 1ULL << v);
                changed = true;
            }
        }
        if (!changed) break;
    }
    if (cnt + __builtin_popcountll(rem) <= best_cnt) return;   // 打ち切り
    if (!rem) { best = cur, best_cnt = cnt; return; }
    int v = 次数最大の頂点;
    self(self, rem & ~(nb[v] | 1ULL << v), cur | 1ULL << v, cnt + 1);   // 取る
    self(self, rem & ~(1ULL << v), cur, cnt);                           // 取らない
};
```

「取る」を先に調べると、早いうちに大きな解が見つかり、打ち切りがよく効きます。

## 7. 正しさ・計算量

- **正しさ**：4.1 節の規則は最適解の大きさを変えず、分岐は全ての場合を尽くし、打ち切りは更新できない枝だけを捨てます。
- **計算量**：分岐は次数 3 以上の頂点でしか起きないので $T(n) \le T(n-1) + T(n-4) + O(n)$、$O(1.381^n \cdot n)$。$n = 40$ で $1.381^{40} \approx 4 \times 10^5$ です。

## 9. まとめ

- 頂点集合を 64 bit で持ち、次数 0, 1 の頂点は無条件に取る。
- 次数最大の頂点で「取る / 取らない」に分岐すると $T(n) \le T(n-1) + T(n-4)$ で $O(1.381^n)$。
- 「今の数 + 残りの頂点数 ≤ 最良」なら打ち切る。
