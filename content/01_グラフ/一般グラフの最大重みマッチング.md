## 1. 概要

本記事では、重み付き無向グラフ（二部とは限らない）で、端点を共有しない辺の集合のうち **重みの和が最大** のものを求める方法を解説します。

これは [[一般グラフの最大マッチング（Edmondsの花）]] の「花の縮約」と、[[割当問題（Hungarian法）]] の「ポテンシャル（双対変数）」を組み合わせた **Edmonds の主双対法** で解けます。素朴に実装すると $O(n^4)$、各頂点への「最も近い辺」を覚えておくと $O(n^3)$ です。

>[!問題] 問題 1：General Weighted Matching（Library Checker）
>$N$ 頂点 $M$ 辺の重み付き無向グラフで、重みの和が最大のマッチングを 1 つ出力してください。（$N \le 500$、$M \le N(N-1)/2$、重みは $1$ 以上 $10^6$ 以下）

## 2. 前提知識

- [[一般グラフの最大マッチング（Edmondsの花）]]（交互木、花の縮約）
- [[割当問題（Hungarian法）]]（ポテンシャルと被約費用、タイトな辺）

本記事は長く、全ての細部（花の展開の手順など）の証明までは追いません。「何を持っていて、何が起きたら何をするか」が分かることを目標にします。

## 3. 素朴な方法

### 3.1. bit DP

$n \le 20$ 程度なら、「まだ使っていない頂点の集合」を状態にして、最小番号の頂点を「使わない」か「誰かと組む」かで分ける bit DP で $O(2^n n)$ です。$n = 500$ では使えません。

### 3.2. 二部グラフなら

二部グラフなら、重みの符号を反転して（足りない分は重み 0 の辺で補って）[[割当問題（Hungarian法）]] で解けます。Hungarian 法の核心は

- 頂点にポテンシャルを持ち、「ポテンシャルの和 ≥ 辺の重み」を保つ
- 等号の辺（タイトな辺）だけで増加路を探し、見つからなければポテンシャルを動かして新しいタイトな辺を作る

でした。一般グラフでは奇閉路があるので、ここに花の縮約を組み合わせます。花にもポテンシャルを持たせる必要があります。

## 4. 双対変数と最適性の条件

### 4.1. 持つもの

| 対象 | 変数 | 条件 |
| --- | --- | --- |
| 頂点 $v$ | $y_v$ | $y_v \ge 0$ |
| 花（奇数個の頂点の集合）$B$ | $z_B$ | $z_B \ge 0$ |
| 辺 $e = (u, v)$ | — | $y_u + y_v + \sum_{B \ni u, v} z_B \ge w_e$ |

最後の式の左辺から $w_e$ を引いたものを辺の **余裕（slack）** と呼び、0 の辺を **タイト** と呼びます。

### 4.2. 最適性の条件

次の 3 つが全部成り立てば、そのマッチング $M$ は重み最大です。

1. $M$ の辺は全てタイト。
2. $y_v > 0$ の頂点はマッチしている。
3. $z_B > 0$ の花 $B$ は、中で $\lfloor |B| / 2 \rfloor$ 本の辺がマッチしている（いっぱい）。

理由（概略）：どんなマッチング $M'$ でも、各辺の重みを「両端の $y$ ＋ 両端を含む花の $z$」で上から抑えて足すと、各頂点は高々 1 回、各花は高々 $\lfloor |B|/2 \rfloor$ 回しか数えられないので

$$
w(M') \le \sum_v y_v + \sum_B \left\lfloor \frac{|B|}{2} \right\rfloor z_B
$$

です。1〜3 が成り立つと $M$ では等号になるので、$M$ が最大です（線形計画の双対定理）。

### 4.3. ラベル $\ell$

ライブラリでは割り算を避けるため $\ell_v = 2 y_v$、$\ell_B = 2 z_B$ を持ちます（**ラベル**）。辺の余裕は $\ell_u + \ell_v - 2 w_e$（花の中の辺は、花がほどけるまで見ないので花のラベルは足さない）。

## 5. アルゴリズム

### 5.1. 初期状態

マッチングは空、全ての頂点のラベルを $\ell_v = W$（重みの最大値）、花はなし。全ての辺で $\ell_u + \ell_v = 2W \ge 2w_e$ なので条件を満たします。

全ての頂点のラベルは「空いている頂点どうしでいつも等しい」ことが保たれ、それが 0 になったら条件 2 も満たされて終わりです。

### 5.2. 1 フェーズ

空いている頂点全てを根として **交互森**（交互木の集まり）を、**タイトな辺だけで** 伸ばします。頂点（または花）の状態は

- **外側（S = 0）**：根、または内側の相手
- **内側（S = 1）**：外側から外の辺で来た頂点
- **未到達（S = −1）**

です。外側の頂点からタイトな辺 $(u, v)$ を見つけたとき：

| $v$ の状態 | 動作 |
| --- | --- |
| 未到達 | $v$ を内側に、$v$ の相手を外側にして森を伸ばす |
| 外側・別の木 | 両方の根をつなぐ **増加路**。入れ替えてフェーズ終了 |
| 外側・同じ木 | **花** ができたので縮約する（花のラベルは 0 から） |

### 5.3. 行き詰まったら双対を動かす

タイトな辺で伸ばせなくなったら、ある値 $d > 0$ で

| 対象 | ラベルの変化 |
| --- | --- |
| 外側の頂点 | $\ell \leftarrow \ell - d$ |
| 内側の頂点 | $\ell \leftarrow \ell + d$ |
| 外側の花 | $\ell_B \leftarrow \ell_B + 2d$ |
| 内側の花 | $\ell_B \leftarrow \ell_B - 2d$ |

とします。森の辺（外側–内側）の余裕は変わらず、外側から未到達への辺の余裕は $d$、外側どうしの辺の余裕は $2d$ 減ります。$d$ は次の最小値です。

1. 外側 → 未到達の辺の余裕（0 になれば森が伸びる）
2. 外側どうしの辺の余裕 ÷ 2（0 になれば増加路か花）
3. 内側の花のラベル ÷ 2（0 になればその花を **展開** する）
4. 外側の頂点のラベル（0 になれば終わり：空いている頂点のラベルが 0 で最適）

4 が最小なら動かさずに終わりです（ライブラリでは「動かすと外側のラベルが 0 以下になるなら終了」と判定しています）。

## 6. 例で追う

4 頂点、辺 0–1（重み 4）、1–2（5）、0–2（3）、2–3（2）。0, 1, 2 は三角形です。答えは {0–1, 2–3} の 6（{1–2} だけの 5 より大きい）です。辺の余裕は $\ell_u + \ell_v - 2w$。

**初期状態。** $W = 5$ なので $\ell = (5, 5, 5, 5)$。

| 辺 | 0–1 | 1–2 | 0–2 | 2–3 |
| --- | --- | --- | --- | --- |
| 余裕 | 2 | **0** | 4 | 6 |

**フェーズ 1。** 全頂点が空いていて外側（別々の木）。タイトな辺 1–2 は外側どうし・別の木なので **増加**。マッチング {1–2}。

**フェーズ 2。** 空いているのは 0, 3（外側）。1, 2 は未到達。タイトな辺がないので双対を動かします。

| 双対ステップ | $d$ の候補 | $d$ | 動かした後の $\ell$（0, 1, 2, 3） | 新しくタイトになった辺 |
| --- | --- | --- | --- | --- |
| 1 | 外→未到達：0–1 の 2、0–2 の 4、3–2 の 6 | 2 | 3, 5, 5, 3 | 0–1 |

0–1 がタイトになり、1 が内側、1 の相手 2 が外側になります（木：0 → 1 → 2）。次に 2 から辺を見ると、2–0 は外側どうし（余裕 $5 + 3 - 6 = 2$）、2–3 も外側どうし（余裕 $5 + 3 - 4 = 4$）でタイトではありません。

| 双対ステップ | $d$ の候補 | $d$ | 動かした後の $\ell$（0, 1, 2, 3） | 新しくタイトになった辺 |
| --- | --- | --- | --- | --- |
| 2 | 外どうし：2–0 の 2/2、2–3 の 4/2 | 1 | 2, **6**, 4, 2 | 0–2 |

内側の 1 だけラベルが増えています。0–2 は外側どうし・同じ木（共通祖先 0）なので **花** $B = \{0, 1, 2\}$ ができ、$\ell_B = 0$、$B$ 全体が外側になります。

| 双対ステップ | $d$ の候補 | $d$ | 動かした後の $\ell$（0, 1, 2, 3） | $\ell_B$ | 新しくタイトになった辺 |
| --- | --- | --- | --- | --- | --- |
| 3 | 外どうし：2–3 の $(4 + 2 - 4)/2$ | 1 | 1, 5, 3, 1 | 2 | 2–3 |

花の中の頂点は全部「外側」なので、1 も 1 減っています。2–3 は外側どうし・別の木（$B$ と 3）なので **増加**。増加路は「3 – 2、花の中を 2 → 1 → 0（根）」で、入れ替えると {0–1, 2–3} になります。

**フェーズ 3。** 空いている頂点がないので終わり。重みの和は $4 + 2 = 6$（ライブラリの出力と一致）。

**最適性の確認。** $y = \ell / 2 = (0.5, 2.5, 1.5, 0.5)$、$z_B = 1$。

| 辺 | $y_u + y_v + z$ | 重み |
| --- | --- | --- |
| 0–1（$B$ の中） | $0.5 + 2.5 + 1 = 4$ | 4（タイト・マッチ） |
| 1–2（$B$ の中） | $2.5 + 1.5 + 1 = 5$ | 5 |
| 0–2（$B$ の中） | $0.5 + 1.5 + 1 = 3$ | 3 |
| 2–3 | $1.5 + 0.5 = 2$ | 2（タイト・マッチ） |

双対の値は $\sum y + \lfloor 3/2 \rfloor z_B = 5 + 1 = 6$ で、マッチングの重み 6 と一致します。

## 7. 高速化：余裕の最小値を覚えておく

### 7.1. 素朴な実装

双対を動かすたびに全ての辺を見て $d$ を計算すると、1 回 $O(n^2)$ です。1 回の増加までに双対ステップは $O(n)$ 回、増加は $O(n)$ 回なので、全体 $O(n^4)$ になります。

### 7.2. slack 配列

各頂点（花）$x$ について「外側の頂点から $x$ への辺のうち余裕が最小のもの」`slack[x]` を覚えておきます。

- 外側の頂点が増えたとき、その頂点からの辺で `slack` を更新する（1 頂点 $O(n)$）。
- $d$ の計算は `slack` を見るだけで $O(n)$。
- 動かした後、余裕が 0 になった `slack[x]` の辺だけを処理する。

これで双対ステップが $O(n)$ になり、全体 $O(n^3)$ です。

```cpp
W d = numeric_limits<W>::max();
for (int b = n + 1; b <= nx; b++)                                  // 3. 内側の花
    if (st[b] == b && S[b] == 1) d = min(d, lab[b] / 2);
for (int x = 1; x <= nx; x++)
    if (st[x] == x && slack[x]) {
        if (S[x] == -1) d = min(d, e_delta(g[slack[x]][x]));       // 1. 外側 → 未到達
        else if (S[x] == 0) d = min(d, e_delta(g[slack[x]][x]) / 2); // 2. 外側どうし
    }
for (int u = 1; u <= n; u++)                                       // 4. 外側のラベルが 0 に
    if (S[st[u]] == 0 && lab[u] <= d) return false;
for (int u = 1; u <= n; u++) {
    if (S[st[u]] == 0) lab[u] -= d;
    else if (S[st[u]] == 1) lab[u] += d;
}
for (int b = n + 1; b <= nx; b++)
    if (st[b] == b) {
        if (S[st[b]] == 0) lab[b] += d * 2;
        else if (S[st[b]] == 1) lab[b] -= d * 2;
    }
```

`st[x]` は「頂点 $x$ を含む一番外側の花」で、花には $n+1$ 以降の番号を振っています。

## 8. 正しさ・計算量

- **正しさ**：双対の条件（余裕 ≥ 0、$y \ge 0$、$z \ge 0$）とマッチングの辺がタイトであることを保ち、終了時には空いている頂点のラベルが 0（条件 2）、ラベルが正の花はいっぱい（条件 3）になっているので、4.2 節から最適です。
- **計算量**：増加は高々 $n/2$ 回。1 回の増加までに、双対ステップのたびに森が伸びる・花ができる・花が展開されるのどれかが起き、それぞれ $O(n)$ 回なので双対ステップは $O(n)$ 回、各 $O(n)$。辺を見るのは外側になった頂点ごとに $O(n)$。全体 $O(n^3)$ です。メモリは隣接行列で $O(n^2)$。

## 9. 問題

【問題 1】は `GeneralWeightedMatching` に辺を入れて `solve()` と `matching_edges()` で解けます。

【問題 2】$n$（偶数）人を 2 人ずつのペアに分けます。$i$ と $j$ がペアになると満足度 $s_{ij}$ が得られます。全員をペアにするときの満足度の和の最大値を求めてください。
（ヒント：「完全マッチングの中で重み最大」です。全ての重みに十分大きい定数 $C$ を足すと、辺の本数が多いほど得になるので、最大重みマッチングが完全マッチングになります。答えから $C \cdot n/2$ を引きます。）

【問題 3】中国人郵便配達問題：無向グラフの全ての辺を 1 回以上通って戻ってくる最短の閉路の長さを求めてください。
（ヒント：次数が奇数の頂点どうしを、最短距離を重みとして **最小重み完全マッチング** で組み、その道を重ねて全頂点の次数を偶数にします。最小化は重みを $C - d$ にして最大化します。）

## 10. まとめ

- 頂点と花に双対変数（ラベル）を持ち、「辺の両端のラベル ≥ 重み」を保つ。
- タイトな辺だけで交互森を伸ばし、増加路が見つかれば増加、同じ木の外側どうしなら花を縮約。
- 行き詰まったら双対を $d$ だけ動かす（外側 −、内側 +、外側の花 +2、内側の花 −2）。内側の花のラベルが 0 になったら展開、空いている頂点のラベルが 0 になったら終了。
- 各頂点への最小の余裕を覚えておくと $O(n^3)$。
