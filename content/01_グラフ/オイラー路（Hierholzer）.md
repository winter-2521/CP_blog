#グラフ #DFS #オイラー路

ライブラリ：[eulerian_trail.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/eulerian_trail.hpp)

## 1. 概要

本記事では、グラフの **全ての辺をちょうど 1 回ずつ通る路**（オイラー路、一筆書き）があるかを判定し、あれば 1 つ求める方法を解説します。Hierholzer の方法で $O(n + m)$ です。有向グラフ・無向グラフの両方を扱います。

>[!問題] 問題 1：Eulerian Trail (Directed)（Library Checker）
>$N$ 頂点 $M$ 辺の有向グラフのオイラー路を、頂点の列と辺の列で出力してください。なければ `No`。（テストケース数 $T$、$\sum N, \sum M \le 2 \times 10^5$）

## 2. 前提知識

- 深さ優先探索（DFS）
- 頂点の次数（有向グラフでは入次数・出次数）

## 3. 存在条件

- **有向グラフ**：全ての頂点で（出次数）=（入次数）か、または（出 − 入 = 1 の頂点）と（入 − 出 = 1 の頂点）がちょうど 1 つずつ。さらに、辺を持つ頂点が（向きを無視して）全部つながっている。前者なら始点と終点が同じ（閉路）、後者なら出 − 入 = 1 の頂点が始点。
- **無向グラフ**：次数が奇数の頂点が 0 個か 2 個で、辺を持つ頂点が全部つながっている。2 個なら、その片方が始点。

途中の頂点では「入った回数 = 出た回数」なので、次数の条件は必要です。十分であることは、次の節の方法で実際に作れることから分かります。

## 4. 素朴な方法：Fleury の方法

始点から、「その辺を使うと残りの辺がつながらなくなる（橋になる）辺は、他に選択肢がない限り使わない」というルールで進むと、オイラー路が作れます。しかし、毎回「橋かどうか」を調べるので $O(m^2)$ 程度かかります。

## 5. Hierholzer の方法

### 5.1. 考え方

始点から、**まだ使っていない辺を適当に選んで進む** ことを、行き詰まるまで繰り返します。次数の条件があるので、行き詰まるのは終点（閉路なら始点）だけです。しかし、途中の頂点にまだ使っていない辺が残っているかもしれません。

そこで、行き詰まったら 1 つずつ戻り、**まだ使っていない辺が残っている頂点から、また同じことをして小さな閉路を作り、その場所に差し込みます**。これを全部の辺を使うまで繰り返します。

### 5.2. スタックでの実装

これはスタックを使うと簡単に書けます。

1. スタックに始点を積む。
2. スタックの一番上の頂点 $v$ に、まだ使っていない辺があれば、それを使って行き先をスタックに積む。
3. なければ、$v$ をスタックから降ろして **出力に追加** する。
4. スタックが空になるまで 2〜3 を繰り返し、最後に **出力を逆順** にする。

出力に追加されるのは「もうどこにも行けなくなった頂点」なので、逆順にすると、差し込まれた閉路が正しい位置に入った路になります。

### 5.3. 例で追う

辺 0: $0 \to 1$、1: $1 \to 2$、2: $2 \to 0$、3: $1 \to 3$、4: $3 \to 1$。頂点 1 から $1 \to 2$ を先に使うと、$0 \to 1 \to 2 \to 0$ と進んで 0 で行き詰まりますが、1 に辺 3, 4 が残っています。（実際にトレースした結果）

| 手順 | スタックの一番上 | 動作 | スタック | 出力 |
| --- | --- | --- | --- | --- |
| 1 | 0 | 辺 0 で 1 へ | [0, 1] | |
| 2 | 1 | 辺 1 で 2 へ | [0, 1, 2] | |
| 3 | 2 | 辺 2 で 0 へ | [0, 1, 2, 0] | |
| 4 | 0 | 使える辺なし → 出力 | [0, 1, 2] | 0 |
| 5 | 2 | 使える辺なし → 出力 | [0, 1] | 0, 2 |
| 6 | 1 | 辺 3 で 3 へ | [0, 1, 3] | 0, 2 |
| 7 | 3 | 辺 4 で 1 へ | [0, 1, 3, 1] | 0, 2 |
| 8 | 1 | 使える辺なし → 出力 | [0, 1, 3] | 0, 2, 1 |
| 9 | 3 | 使える辺なし → 出力 | [0, 1] | 0, 2, 1, 3 |
| 10 | 1 | 使える辺なし → 出力 | [0] | 0, 2, 1, 3, 1 |
| 11 | 0 | 使える辺なし → 出力 | [] | 0, 2, 1, 3, 1, 0 |

出力を逆順にすると $0 \to 1 \to 3 \to 1 \to 2 \to 0$（辺 0, 3, 4, 1, 2）で、確かに全ての辺を 1 回ずつ通っています（ライブラリの出力と一致）。手順 6〜7 で作った小さな閉路 $1 \to 3 \to 1$ が、最初の路の 1 の位置に差し込まれています。

### 5.4. 連結性の判定

辺を持つ頂点が全部つながっていないと、始点から行けない辺が残ります。最後に、使った辺の数が $m$ に満たなければ「オイラー路なし」とします。

## 6. 実装

```cpp
vector<pair<int, int>> stk{{s, -1}};               // (頂点, そこへ来た辺)
while (!stk.empty()) {
    auto [v, ein] = stk.back();
    int &i = it[v];                                // v の次に調べる辺
    while (i < g.start[v + 1] && used[g.elist[i]]) i++;   // 使用済み (無向で逆側から使った) を飛ばす
    if (i == g.start[v + 1]) {                     // 使える辺がない
        vs.push_back(v);
        if (ein >= 0) es.push_back(ein);
        stk.pop_back();
        continue;
    }
    int e = g.elist[i++];
    used[e] = 1;
    int to = DIRECTED ? edges[e].second : edges[e].first ^ edges[e].second ^ v;
    stk.push_back({to, e});
}
if ((int)es.size() != m) return {};                // 非連結
reverse(vs.begin(), vs.end()), reverse(es.begin(), es.end());
```

各頂点の「次に調べる辺」`it[v]` を進めていくので、各辺は高々 2 回（無向なら両端から）しか見ません。全体 $O(n + m)$ です。

## 7. 問題

【問題 1】は `eulerian_trail<true>(n, edges)` で解けます（無向なら `eulerian_trail<false>`）。

【問題 2】$0, 1, \ldots, k^n - 1$ の $n$ 桁の $k$ 進数が全部、連続する部分として 1 回ずつ現れる、最短の $k$ 進数の列（de Bruijn 列）を作ってください。
（ヒント：$n-1$ 桁の列を頂点とし、各 $n$ 桁の列を「上位 $n-1$ 桁 → 下位 $n-1$ 桁」の辺とすると、オイラー閉路が答えになります。）

## 8. まとめ

- オイラー路の存在は、次数の条件と、辺を持つ頂点の連結性で決まる。
- Hierholzer の方法：使っていない辺で進み、行き詰まったら出力して戻る。出力を逆にするとオイラー路。$O(n + m)$。
