## 1. 概要

グラフの **全域木の個数** は、**行列木定理**（Kirchhoff の定理）により、ラプラシアン行列の行列式 1 つで求まります。有向グラフの「根から全頂点に行ける有向全域木」の個数も同様です。行列式はガウスの消去法で $O(n^3)$ です。

>[!問題] 問題 1：Counting Spanning Trees (Undirected)（Library Checker）
>$N$ 頂点 $M$ 辺の無向グラフ（多重辺あり）の全域木の個数を $998244353$ で割った余りで求めてください。（$N \le 500$、$M \le 5 \times 10^5$）

>[!問題] 問題 2：Counting Spanning Trees (Directed)（Library Checker）
>$N$ 頂点 $M$ 辺の有向グラフと根 $r$ が与えられます。$r$ から全頂点へ到達できる有向全域木の個数を求めてください。（$N \le 500$、$M \le 5 \times 10^5$）

## 2. 前提知識

- 行列式（行の入れ替えで符号が変わる、ある行の定数倍を他の行に足しても変わらない）
- mod での逆元

## 3. 素朴な方法

$M$ 本の辺から $N - 1$ 本を選ぶ組合せを全部試して木かどうか調べると $\binom{M}{N-1}$ 通りで、すぐに不可能になります。

## 4. 行列木定理（無向）

### 4.1. ラプラシアン

**ラプラシアン行列** $L$ を

$$
L_{ii} = \deg(i), \qquad L_{ij} = -(\text{$i$ と $j$ を結ぶ辺の本数}) \quad (i \ne j)
$$

と定めます（自己ループは無視）。**全域木の個数 = $L$ から任意の 1 行と同じ番号の 1 列を除いた行列の行列式** です。

### 4.2. 例で追う

4 頂点、辺 0–1, 1–2, 2–3, 3–0, 0–2（四角形に対角線）。全域木は 5 本から 3 本選んで閉路がないもので、$\binom{5}{3} = 10$ 通りから三角形 {0–1, 1–2, 0–2} と {2–3, 3–0, 0–2} の 2 通りを除いた 8 個です。

$$
L = \begin{pmatrix} 3 & -1 & -1 & -1 \\ -1 & 2 & -1 & 0 \\ -1 & -1 & 3 & -1 \\ -1 & 0 & -1 & 2 \end{pmatrix}
$$

頂点 3 の行と列を除いて、ガウスの消去法で上三角にします。

$$
\begin{pmatrix} 3 & -1 & -1 \\ -1 & 2 & -1 \\ -1 & -1 & 3 \end{pmatrix}
\to \begin{pmatrix} 3 & -1 & -1 \\ 0 & 5/3 & -4/3 \\ 0 & -4/3 & 8/3 \end{pmatrix}
\to \begin{pmatrix} 3 & -1 & -1 \\ 0 & 5/3 & -4/3 \\ 0 & 0 & 8/5 \end{pmatrix}
$$

行列式は $3 \cdot \frac{5}{3} \cdot \frac{8}{5} = 8$ で、全域木の個数と一致します（ライブラリの出力も 8）。mod 素数の世界では割り算は逆元の掛け算です。

### 4.3. なぜ成り立つか（概略）

辺に適当な向きを付け、**接続行列** $B$（頂点 × 辺、辺 $e = (u \to v)$ の列は $u$ に $+1$、$v$ に $-1$）を作ると $L = B B^\top$ です。1 行除いた $B'$ について Cauchy-Binet の公式で

$$
\det(B' B'^\top) = \sum_{S:\ |S| = n - 1} \det(B'_S)^2
$$

（$S$ は辺の部分集合、$B'_S$ はその列だけ取った正方行列）で、$\det(B'_S)$ は $S$ が全域木なら $\pm 1$、そうでなければ 0 になることが示せます。

## 5. 有向版

根 $r$ から全頂点に行ける有向全域木（各頂点 $v \ne r$ に入る辺がちょうど 1 本）の個数は、

$$
L_{ii} = (\text{$i$ の入次数}), \qquad L_{ij} = -(\text{$i \to j$ の辺の本数})
$$

から $r$ の行と列を除いた行列式です。

**例**：3 頂点、辺 $0 \to 1, 0 \to 2, 1 \to 2, 2 \to 1$、根 0。頂点 1 は入る辺を {0→1, 2→1}、頂点 2 は {0→2, 1→2} から選び、閉路（1→2 と 2→1 を両方）になる 1 通りを除いて 3 個。行列は

$$
\begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}, \quad \det = 4 - 1 = 3
$$

で一致します。

## 6. 実装

### 6.1. 行列式

```cpp
template <class mint>
mint determinant(vector<vector<mint>> a) {
    int n = a.size();
    mint res = 1;
    for (int c = 0; c < n; c++) {
        int p = c;
        while (p < n && a[p][c] == mint(0)) p++;
        if (p == n) return mint(0);                  // 列が全部 0
        if (p != c) swap(a[p], a[c]), res = -res;    // 行の入れ替えで符号反転
        res *= a[c][c];
        mint inv = a[c][c].inv();                    // 逆元は列ごとに 1 回
        for (int r = c + 1; r < n; r++) {
            if (a[r][c] == mint(0)) continue;
            mint f = a[r][c] * inv;
            for (int k = c; k < n; k++) a[r][k] -= f * a[c][k];
        }
    }
    return res;
}
```

### 6.2. ラプラシアン

```cpp
for (auto [a, b] : edges) {                          // 無向 (頂点 n-1 を除く)
    if (a == b) continue;
    if (a < n - 1) L[a][a] += 1;
    if (b < n - 1) L[b][b] += 1;
    if (a < n - 1 && b < n - 1) L[a][b] -= 1, L[b][a] -= 1;
}
```

辺が $5 \times 10^5$ 本あっても、行列に足し込むだけなので $O(M)$ です。

## 7. 正しさ・計算量

- **正しさ**：行列木定理（4.3 節）によります。
- **計算量**：行列の構築 $O(N^2 + M)$、行列式 $O(N^3)$。$N = 500$ で約 $4 \times 10^7$ 回の掛け算です。

## 8. 問題

【問題 1】は `count_spanning_trees_undirected<mint>(n, edges)`、【問題 2】は `count_spanning_trees_directed<mint>(n, edges, r)` で解けます。

【問題 3】完全グラフ $K_n$ の全域木の個数を求めてください。
（ヒント：ラプラシアンの小行列式を計算すると $n^{n-2}$（Cayley の公式）になります。）

【問題 4】「$r$ に向かう」有向全域木（全頂点から $r$ へ行ける）の個数を求めてください。
（ヒント：辺を全部逆向きにして問題 2 を解きます。）

## 9. まとめ

- 全域木の個数 = ラプラシアン（次数 − 隣接）から 1 行 1 列除いた行列式（行列木定理）。
- 有向版は入次数のラプラシアンから根の行と列を除く。
- 行列式はガウスの消去法で $O(n^3)$。mod 素数なら割り算は逆元。
