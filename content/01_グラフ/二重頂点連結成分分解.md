#グラフ #DFS #lowlink #関節点

ライブラリ：[biconnected_components.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/biconnected_components.hpp)

## 1. 概要

本記事では、無向グラフを **二重頂点連結成分**（ブロック）に分解する方法を解説します。二重頂点連結成分は、「どの 1 頂点を取り除いても連結なままの、極大な部分グラフ」です。成分どうしは **関節点**（取り除くと連結成分が増える頂点）で接していて、関節点は複数の成分に属します。lowlink を使って $O(n + m)$ で求められます。

>[!問題] 問題 1：Biconnected Components（Library Checker）
>$N$ 頂点 $M$ 辺の無向グラフ（多重辺あり、自己ループなし）を二重頂点連結成分に分解し、各成分の頂点集合を出力してください。（$N, M \le 5 \times 10^5$）

## 2. 前提知識

- lowlink：[[lowlinkと二重辺連結成分分解]]

## 3. 素朴な方法

頂点を 1 つずつ取り除いて連結性を調べれば関節点は分かりますが、$O(n(n + m))$ かかります。また、成分の分け方は関節点だけからは直接分かりません（関節点がどの成分に属するかを決める必要があります）。

## 4. 辺で成分を考える

二重頂点連結成分は **辺の分割** として考えると分かりやすくなります。

> 2 本の辺が同じ成分に属する ⇔ その 2 本を両方含む単純閉路がある（または同じ辺）

各辺はちょうど 1 つの成分に属し、成分の頂点集合は、その成分の辺の端点の集合です（辺を持たない孤立点は 1 頂点だけの成分とします）。

## 5. lowlink で成分を切り出す

### 5.1. 関節点の判定

DFS 木の辺 (親 $p$, 子 $c$) について、

> $\mathrm{low}[c] \ge \mathrm{ord}[p]$ ⇔ $c$ の部分木から、$p$ を通らずに $p$ より上に行けない

このとき $p$ を取り除くと $c$ の部分木が切り離されるので、$p$ は関節点です（$p$ が根の場合は子が 2 つ以上あるとき）。二重辺連結（橋）の判定 $\mathrm{low}[c] > \mathrm{ord}[p]$ と、不等号に等号が入るかどうかだけが違います。

### 5.2. 辺のスタック

DFS で辺（木の辺と、子孫から祖先への後退辺）を通るたびにスタックに積みます。子 $c$ の探索から戻ってきて $\mathrm{low}[c] \ge \mathrm{ord}[p]$ なら、

> スタックの上から、辺 $(p, c)$ までを取り出したものが 1 つの成分

です。取り出される辺は「$c$ の部分木の中の辺と、そこから $p$ への辺」のうち、まだ他の成分として取り出されていないものです。

### 5.3. 例で追う

辺 0: $\{0,1\}$、1: $\{1,2\}$、2: $\{2,0\}$、3: $\{2,3\}$、4: $\{3,4\}$、5: $\{4,2\}$、6: $\{4,5\}$。三角形 $\{0,1,2\}$ と三角形 $\{2,3,4\}$ が頂点 2 で接し、4 に 5 がぶら下がったグラフです。

DFS は $0 \to 1 \to 2 \to 3 \to 4 \to 5$ と進みます（実際にトレースした値）。

| 頂点 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| $\mathrm{ord}$ | 0 | 1 | 2 | 3 | 4 | 5 |
| $\mathrm{low}$ | 0 | 0 | 0 | 2 | 2 | 5 |

帰りがけの判定と取り出し：

| 戻ってきた辺 $(p, c)$ | 判定 | 取り出す辺 | 成分の頂点 |
| --- | --- | --- | --- |
| (4, 5) | $\mathrm{low}[5] = 5 \ge \mathrm{ord}[4] = 4$ | 6 | {4, 5} |
| (3, 4) | $\mathrm{low}[4] = 2 < 3$ | — | — |
| (2, 3) | $\mathrm{low}[3] = 2 \ge \mathrm{ord}[2] = 2$ | 5, 4, 3 | {2, 3, 4} |
| (1, 2) | $\mathrm{low}[2] = 0 < 1$ | — | — |
| (0, 1) | $\mathrm{low}[1] = 0 \ge \mathrm{ord}[0] = 0$ | 2, 1, 0 | {0, 1, 2} |

関節点 2 と 4 が、2 つずつの成分に入っています。

## 6. 実装

```cpp
if (ord[to] < 0) {                                  // 木の辺
    estk.push_back(e);
    ...
} else if (ord[to] < ord[v]) {                      // 祖先への後退辺 (子孫側から見たときだけ積む)
    estk.push_back(e);
    low[v] = std::min(low[v], ord[to]);
}
...
// 子 v の探索から親 p に戻ったとき
low[p] = std::min(low[p], low[v]);
if (low[v] >= ord[p]) {
    while (true) {
        int e = estk.back();
        estk.pop_back();
        // e の端点を成分に加える (重複しないよう印を付ける)
        if (e == par_edge[v]) break;
    }
}
```

後退辺は、子孫側から見たとき（$\mathrm{ord}[to] < \mathrm{ord}[v]$）だけ積みます。祖先側から同じ辺を見たときにも積むと、2 回積まれてしまいます。

## 7. 問題

【問題 1】は `biconnected_components(n, edges)` で解けます。辺の分割も欲しいときは第 3 引数を渡します。

【問題 2】無向グラフの関節点を全部求めてください。
（ヒント：2 つ以上の成分に入っている頂点が関節点です。）

## 8. まとめ

- 二重頂点連結成分は「辺の分割」として考える。成分どうしは関節点で接する。
- 木の辺 $(p, c)$ で $\mathrm{low}[c] \ge \mathrm{ord}[p]$ なら、辺のスタックから $(p, c)$ までを取り出すと 1 つの成分。
