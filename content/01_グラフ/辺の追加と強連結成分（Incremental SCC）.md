#グラフ #強連結成分 #分割統治 #オフライン

ライブラリ：[incremental_scc.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/incremental_scc.hpp)

## 1. 概要

本記事では、有向グラフに辺を 1 本ずつ追加していくとき、**各時点の強連結成分** を求める方法を解説します。各辺 $i$ について

> $t_i$ ＝ 辺 $0, 1, \ldots, t-1$ を追加した時点で、辺 $i$ の両端が同じ強連結成分になる最小の $t$

を求めれば、「時点 $k$ の強連結成分」は「$t_i \le k$ の辺の両端を Union-Find でつないだもの」になります。$t_i$ は **時刻についての分割統治** で、全体 $O(m \log m)$ で求められます（辺を全部先読みする、オフラインの方法です）。

>[!問題] 問題 1：Incremental SCC（Library Checker）
>$N$ 頂点 0 辺の有向グラフと、整数 $x_0, \ldots, x_{N-1}$ があります。辺を $M$ 本順に追加し、追加するたびに $\sum_{i < j,\ i, j \text{ が同じ強連結成分}} x_i x_j \bmod 998244353$ を出力してください。（$N, M \le 5 \times 10^5$）

## 2. 前提知識

- 強連結成分分解：[[強連結成分分解（Tarjan）]]
- Union-Find
- 分割統治

## 3. 素朴な方法

辺を追加するたびに強連結成分分解をし直すと、1 回 $O(n + m)$、全体 $O(m(n + m)) = 5 \times 10^{11}$ で間に合いません。

## 4. 観察

### 4.1. 成分は併合されるだけ

辺を追加すると、強連結成分はくっつくことはあっても分かれることはありません。なので「各辺の両端がいつ同じ成分になるか」の時刻 $t_i$ が分かれば、成分の変化は全部分かります。

### 4.2. 成分の内側にならない辺は、成分の形に関係ない

ある時点で、両端が別の成分にある辺は、どの閉路にも含まれていません（閉路に含まれるなら両端は同じ成分です）。閉路に含まれない辺を取り除いても、その時点の強連結成分は変わりません。

## 5. 時刻の分割統治

### 5.1. 再帰の形

関数 `rec(l, r, ids)` を考えます。`ids` は「答え $t_i$ が $(l, r]$ にある」と分かっている辺の集合です。最初は `rec(0, m+1, 全部の辺)` です（$t_i = m + 1$ は「最後まで同じ成分にならない」を表します）。

1. $r - l = 1$ なら、`ids` の辺の答えは全部 $r$。
2. $\mathrm{mid} = (l + r) / 2$ とし、`ids` のうち番号が $\mathrm{mid}$ 未満の辺（時刻 $\mathrm{mid}$ までに追加される辺）でグラフを作って、強連結成分分解する。
3. 両端が同じ成分になった辺は、答えが $\mathrm{mid}$ 以下 → **左** `rec(l, mid, ...)` へ。
4. それ以外の辺は、答えが $\mathrm{mid}$ より大きい → **右** `rec(mid, r, ...)` へ。このとき、端点を「時刻 $\mathrm{mid}$ の成分の代表の頂点」に **書き換えて（縮約して）** 渡す。

### 5.2. なぜこれでよいか

- **左に必要な辺は左の辺だけ**：時刻 $\mathrm{mid}$ 以前の強連結成分を求めるのに、時刻 $\mathrm{mid}$ でも成分の内側にならない辺（右に行く辺）は、4.2 より関係ありません。
- **右では左の辺を縮約で表せる**：左に行った辺は、時刻 $\mathrm{mid}$ の成分の内側にあるので、縮約すると自己ループになり、関係なくなります。成分の形の情報は、右に行く辺の端点を縮約することで受け継がれます。
- **`ids` 以外の辺は関係ない**：答えが $l$ 以下の辺はすでに縮約されていて、答えが $r$ より大きい辺はこの区間では成分の内側にならないからです。

### 5.3. 計算量

各段で、各辺は左か右のどちらか 1 つにだけ行きます。段は $\log m$ 段なので、強連結成分分解の合計は $O(m \log m)$ です。頂点は、その段で使う辺の端点だけに番号を付け直して、小さいグラフで分解します。

## 6. 例で追う

4 頂点、辺 0: $0 \to 1$、1: $1 \to 2$、2: $2 \to 3$、3: $3 \to 1$、4: $2 \to 0$、5: $1 \to 3$。$m = 6$ です。（実際にトレースした結果）

| 再帰 | 使う辺（番号 < mid） | 強連結成分 | 左へ | 右へ |
| --- | --- | --- | --- | --- |
| $(0, 7]$, mid = 3 | 0, 1, 2 | {0} {1} {2} {3} | なし | 0〜5 |
| $(3, 7]$, mid = 5 | 0〜4 | {0, 1, 2, 3} | 0〜4 | 5 |
| $(5, 7]$, mid = 6 | 5（縮約で $0 \to 0$） | {0} | 5 | なし |
| $(5, 6]$ | | | | 辺 5 の答え 6 |
| $(3, 5]$, mid = 4 | 0〜3 | {0} {1, 2, 3} | 1, 2, 3 | 0, 4 |
| $(4, 5]$ | | | | 辺 0, 4 の答え 5 |
| $(3, 4]$ | | | | 辺 1, 2, 3 の答え 4 |

答えは $t = [5, 4, 4, 4, 5, 6]$ です。

- 辺 3（$3 \to 1$）を追加した時点（時刻 4）で、閉路 $1 \to 2 \to 3 \to 1$ ができ、辺 1, 2, 3 が成分の内側になります。
- 辺 4（$2 \to 0$）を追加した時点（時刻 5）で、0 も加わり、辺 0, 4 が内側になります。
- 辺 5（$1 \to 3$）は、追加した時点（時刻 6）ですでに両端が同じ成分です。

## 7. 実装

```cpp
auto rec = [&](auto self, int l, int r, vector<int> &ids) -> void {
    if (ids.empty()) return;
    if (r - l == 1) {
        for (int e : ids) ans[e] = r;
        return;
    }
    int mid = (l + r) / 2;
    // ids の辺の端点に 0, 1, ... と番号を付け直し，番号 < mid の辺で強連結成分分解
    ...
    for (int e : ids) {
        int cu = comp[id[eu[e]]], cv = comp[id[ev[e]]];
        if (e < mid && cu == cv) left.push_back(e);
        else right.push_back(e);
    }
    for (int e : right) {                 // 右へ行く辺の端点を成分の代表に書き換える
        int nu = head[comp[id[eu[e]]]], nv = head[comp[id[ev[e]]]];
        eu[e] = nu, ev[e] = nv;
    }
    self(self, mid, r, right);
    self(self, l, mid, left);
};
```

最初の実装では、各段で作ったグラフ（隣接配列）を再帰の間ずっと持っていたため、メモリが 279 MB になっていました。グラフを再帰の前に解放するようにして 43 MB になりました。

## 8. 問題 1 の答え方

$t_i$ が求まったら、時刻 $k = 1, 2, \ldots, M$ の順に、$t_i = k$ の辺の両端を Union-Find でつなぎます。成分 $A$ と $B$ をつなぐと、$\sum x_i x_j$ は $(\sum_{i \in A} x_i)(\sum_{j \in B} x_j)$ だけ増えるので、成分ごとに $x$ の和を持っておけば $O(1)$ で更新できます。

## 10. まとめ

- 強連結成分は辺の追加で併合されるだけなので、各辺が「成分の内側になる時刻」を求めればよい。
- 時刻を半分に分け、時刻 mid で内側になる辺は左へ、それ以外は端点を縮約して右へ送る分割統治で $O(m \log m)$。
