## 1. 概要

本記事では、最小費用流の一般形である **最小費用 b-flow** を解説します。各頂点 $v$ に供給 $b_v$（負なら需要）、各辺 $e$ に流量の下限 $l_e$・上限 $u_e$・単位費用 $c_e$ が与えられ、

- **流量保存**：$(\text{$v$ から出る流量}) - (\text{$v$ に入る流量}) = b_v$
- **容量制約**：$l_e \le f_e \le u_e$

を満たす流し方 $f$ のうち、費用 $\sum_e c_e f_e$ が最小のものを求めます。費用は負でもよく、負閉路があってもかまいません。

まず普通の最小費用流（逐次最短路法）から始め、下限・負の費用を扱う変換、そして流量が大きくても速い **容量スケーリング法** を説明します。最後に、最適性の証明になる **ポテンシャル（双対）** の求め方も扱います。

>[!問題] 問題 1：Minimum Cost b-flow（Library Checker）
>$N$ 頂点 $M$ 辺の有向グラフで、供給 $b_v$、各辺の $l_e, u_e, c_e$ が与えられます。実行可能なら最小費用と、ポテンシャル $p$、各辺の流量を出力してください。不可能なら infeasible と出力してください。（$N \le 100$、$M \le 1000$、容量・費用の絶対値は $10^9$ 以下）

## 2. 前提知識

- 最大流（残余グラフ、逆辺）
- 最小費用流の逐次最短路法（最短路に沿って流す）
- Dijkstra 法・Bellman-Ford 法
- [[割当問題（Hungarian法）]]（ポテンシャルと被約費用）

## 3. 素朴な方法：逐次最短路法

### 3.1. 普通の最小費用流

始点 $s$ から終点 $t$ へ $F$ 流す最小費用流は、

1. 残余グラフで $s$ から $t$ への最短路（費用の和が最小の道）を求める
2. その道に流せるだけ流す

を繰り返せば求まります（**逐次最短路法**）。残余グラフでは、流した辺の逆向きに「費用 $-c_e$、容量 = 流した量」の逆辺ができます。

逆辺の費用は負になるので Bellman-Ford（$O(nm)$）が必要ですが、各頂点に **ポテンシャル** $p_v$ を持ち、**被約費用** $c_e + p_{\mathrm{from}} - p_{\mathrm{to}}$ が常に非負になるようにしておけば Dijkstra が使えます。最短路を求めたら $p_v \mathrel{+}= \mathrm{dist}_v$ とすると、この性質が保たれます。

### 3.2. b-flow に直す

供給・需要が複数あっても、「超始点 $S$ から供給のある頂点へ容量 $b_v$ の辺」「需要のある頂点から超終点 $T$ へ容量 $-b_v$ の辺」を足せば、$S$ から $T$ への最小費用流になります。

### 3.3. なぜ遅いか

逐次最短路法は、1 回の最短路で流せる量（道の容量の最小値）が 1 しかないこともあり、最悪 **流量の総和** 回だけ最短路を求めます。容量が $10^9$ だと $10^9$ 回になり得て、間に合いません。また、負の費用の閉路があると「最短路」がうまく定義できません。

## 4. 下限と負の費用を消す

### 4.1. 下限

辺 $e = (u \to v)$ に下限 $l_e$ があるときは、**先に $l_e$ だけ流したことにします**。$u$ からは $l_e$ 出ていき、$v$ には $l_e$ 入るので、供給を $b_u \mathrel{-}= l_e$、$b_v \mathrel{+}= l_e$ と直し、辺の容量を $u_e - l_e$（下限 0）にします。

### 4.2. 負の費用

ポテンシャルで見た被約費用が負の辺は、**容量いっぱいまで先に流してしまいます**（飽和）。すると残余グラフには逆辺（被約費用が正）だけが残ります。流した分は始点の供給を減らし、終点の供給を増やして帳尻を合わせます。こうすると負閉路があっても問題ありません。

## 5. 容量スケーリング法

### 5.1. アイデア

$\Delta = 2^k, 2^{k-1}, \dots, 1$ の順に（$2^k$ は容量・供給の最大値以下で最大の 2 冪）、

1. 残余容量が $\Delta$ 以上の辺だけを考える。その中で被約費用が負の辺は飽和させる（4.2 節）。
2. **超過**（まだ出したい量）が $\Delta$ 以上の頂点から、**不足**（まだ受け取りたい量）が $\Delta$ 以上の頂点へ、残余容量 $\Delta$ 以上の辺だけを使って最短路を求め、**ちょうど $\Delta$ 流す**。これをできなくなるまで繰り返す。

1 回の最短路で必ず $\Delta$ 流れるので、各段階で最短路を求める回数は $O(m)$ 回に抑えられます（一段前の $2\Delta$ の段階が終わった時点で、超過・不足の合計が $O(m \Delta)$ になっているため）。段階は $O(\log U)$ 個です。

### 5.2. 多始点の Dijkstra

超過が $\Delta$ 以上の頂点を **全部距離 0 で** キューに入れて Dijkstra をし、不足が $\Delta$ 以上の頂点を最初に取り出したところで止めます。その距離を $d_t$ として、ポテンシャルを $p_v \mathrel{+}= \min(\mathrm{dist}_v, d_t)$ と更新すると、被約費用の非負性が保たれます。

## 6. 例で追う

4 頂点、$b = (4, 0, 0, -4)$ で、辺は次の 5 本です。

| 辺 | 向き | 下限 | 上限 | 費用 |
| --- | --- | --- | --- | --- |
| e0 | 0 → 1 | 0 | 3 | 1 |
| e1 | 0 → 2 | **1** | 4 | 3 |
| e2 | 1 → 2 | 0 | 2 | **−1** |
| e3 | 1 → 3 | 0 | 2 | 4 |
| e4 | 2 → 3 | 0 | 4 | 2 |

**下限の処理。** e1 に 1 だけ先に流し、e1 の容量を 3 にします。超過は

| 頂点 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 超過 | 3 | 0 | 1 | −4 |

**$\Delta = 4$。** 容量 4 以上で被約費用が負の辺はなく、超過 4 以上の頂点もないので何もしません。

**$\Delta = 2$。**

| 手順 | 動作 | 超過（0, 1, 2, 3） | ポテンシャル $p$ |
| --- | --- | --- | --- |
| 1 | e2（被約費用 −1、容量 2）を飽和：1 → 2 に 2 | 3, −2, 3, −4 | 0, 0, 0, 0 |
| 2 | 始点 {0, 2} から Dijkstra。不足 2 以上の頂点で最初に着くのは 1（距離 1、道 0 → 1）。2 流す | 1, 0, 3, −4 | 0, 1, 0, 1 |
| 3 | 始点 {2} から。最初に着く不足の頂点は 3（被約費用で距離 1、道 2 → 3）。2 流す | 1, 0, 1, −2 | 0, 1, 0, 2 |
| 4 | 超過 2 以上の頂点がないので次の段階へ | | |

手順 2 のポテンシャル更新は、$\mathrm{dist} = (0, 1, 0, 2)$、$d_t = 1$ なので $p \mathrel{+}= (0, 1, 0, 1)$ です。

**$\Delta = 1$。**

| 手順 | 動作 | 超過（0, 1, 2, 3） | ポテンシャル $p$ |
| --- | --- | --- | --- |
| 1 | 飽和させる辺はなし。始点 {0, 2} から。2 → 3 の被約費用 $2 + 0 - 2 = 0$ で 3 に距離 0。1 流す | 1, 0, 0, −1 | 0, 1, 0, 2 |
| 2 | 始点 {0} から。0 → 1 → 3（被約費用 $0 + 3$）と 0 → 2 → 3（$3 + 0$）が同じ 3。先に見つかった 0 → 1 → 3 に 1 流す | 0, 0, 0, 0 | 0, 1, 3, 5 |

全ての超過が 0 になったので実行可能です。各辺の流量は

| 辺 | e0 | e1 | e2 | e3 | e4 |
| --- | --- | --- | --- | --- | --- |
| 流量 | 3 | 1 | 2 | 1 | 3 |

で、費用は $3 \cdot 1 + 1 \cdot 3 + 2 \cdot (-1) + 1 \cdot 4 + 3 \cdot 2 = 14$ です（ライブラリの出力と一致）。

## 7. 双対（ポテンシャル）を求める

最適性の証明として、残余グラフの全ての辺 $e$ で

$$
c_e + p_{\mathrm{from}} - p_{\mathrm{to}} \ge 0
$$

を満たすポテンシャル $p$ を出力します（残余グラフに負閉路がない ⇔ 最適）。最後に残余グラフで **全頂点を距離 0 から始める Bellman-Ford** をすると、その距離がそのまま条件を満たす $p$ になります。

例では $p = (-5, -4, -2, 0)$ になりました。確かめると

| 残余辺 | 費用 | $c + p_{\mathrm{from}} - p_{\mathrm{to}}$ |
| --- | --- | --- |
| 1 → 0（e0 の逆、e0 は満杯） | −1 | $-1 - 4 + 5 = 0$ |
| 0 → 2（e1 の残り） | 3 | $3 - 5 + 2 = 0$ |
| 2 → 1（e2 の逆、e2 は満杯） | 1 | $1 - 2 + 4 = 3$ |
| 1 → 3（e3 の残り） | 4 | $4 - 4 + 0 = 0$ |
| 2 → 3（e4 の残り） | 2 | $2 - 2 + 0 = 0$ |

（流れている辺の逆辺は上の表以外にもありますが、どれも 0 以上です。）

## 8. 実装

```cpp
for (; delta >= 1; delta /= 2) {
    // 残余容量 delta 以上で被約費用が負の辺を飽和させる
    for (int v = 0; v < n; v++)
        for (auto &a : g[v])
            if (a.cap >= delta && a.cost + pot[v] - pot[a.to] < 0) {
                Cap f = a.cap;
                a.cap -= f, g[a.to][a.rev].cap += f;
                ex[v] -= f, ex[a.to] += f;
            }
    while (true) {
        // 超過 >= delta の頂点を全部始点にした Dijkstra．不足 >= delta の頂点で止める
        ...
        if (t < 0) break;
        for (int v = 0; v < n; v++) pot[v] += min(dist[v], dt);   // ポテンシャル更新
        for (int v = t; pv[v] >= 0; v = pv[v]) {                  // delta 流す
            auto &a = g[pv[v]][pe[v]];
            a.cap -= delta, g[v][a.rev].cap += delta;
        }
        ex[s] -= delta, ex[t] += delta;
    }
}
// 超過が残っていれば実行不可能．そうでなければ Bellman-Ford で双対を求める
```

費用の合計は $10^9 \times 10^9 \times 1000$ 程度になり得るので `__int128` で返しています。

## 9. 正しさ・計算量

- **正しさ**：各段階の終わりに「残余容量 $\Delta$ 以上の辺の被約費用は非負」が保たれ、最後の $\Delta = 1$ では全ての残余辺で非負になるので、残余グラフに負閉路がなく最適です。超過が残れば、流し方が存在しない（実行不可能）ことも分かります。
- **計算量**：段階は $O(\log U)$ 個、各段階で最短路は $O(m)$ 回、Dijkstra は $O((n + m) \log n)$ なので、$O(m \log U \cdot (n + m) \log n)$。最後の Bellman-Ford が $O(nm)$ です。逐次最短路法と違い、流量の大きさに（対数でしか）依存しません。

## 11. まとめ

- 下限は先に流して供給を調整、負の費用の辺は先に飽和させる。これで一般の b-flow を扱える。
- 逐次最短路法は流量に比例して遅い。容量スケーリング法は $\Delta$ ずつ流すことで最短路の回数を $O(m \log U)$ に抑える。
- 被約費用が非負になるポテンシャルを保てば Dijkstra が使え、最後に Bellman-Ford で求めた距離が最適性の証明（双対）になる。
