## 1. 概要

有向グラフの **オイラー閉路**（全ての辺をちょうど 1 回ずつ通って戻ってくる閉路）の個数は、**BEST 定理** により「有向全域木の個数 × 階乗の積」で求まります。有向全域木の個数は [[全域木の数え上げ（行列木定理）]] の行列式で求めるので、全体 $O(n^3 + m)$ です。

>[!問題] 問題 1：Counting Eulerian Circuits（Library Checker）
>$N$ 頂点 $M$ 辺の有向グラフのオイラー閉路の個数（巡回シフトで一致するものは同じとみなす = 辺 0 から始まるものの個数）を $998244353$ で割った余りで求めてください。（$N \le 500$、$M \le 2 \times 10^5$）

## 2. 前提知識

- [[オイラー路（Hierholzer）]]（存在条件：全頂点で入次数 = 出次数、辺のある頂点が連結）
- [[全域木の数え上げ（行列木定理）]]

## 3. 素朴な方法

辺 0 から始めて、まだ使っていない辺を DFS で全部試すと、閉路の個数だけ（指数的に）時間がかかります。

## 4. BEST 定理

### 4.1. 定理

オイラー閉路を持つ有向グラフ $G$ と頂点 $w$ について

$$
\mathrm{ec}(G) = t_w(G) \prod_{v} (\mathrm{outdeg}(v) - 1)!
$$

です。$t_w(G)$ は **$w$ に向かう有向全域木**（各頂点 $v \ne w$ が出ていく辺を 1 本ずつ選び、どの頂点からも $w$ に行けるもの）の個数です（$w$ によらず同じ値になります）。

### 4.2. なぜ成り立つか（概略）

辺 0 から始まるオイラー閉路を 1 つ取り、$w$ を辺 0 の始点とします。各頂点 $v \ne w$ について「$v$ から **最後に** 出ていく辺」を集めると、$w$ に向かう有向全域木になります（最後に出た後は二度と戻ってこないので、閉路ができない）。

逆に、$w$ に向かう有向全域木を 1 つ決め、各頂点で「木の辺以外の出ていく辺を使う順番」（$w$ では辺 0 以外の順番）を決めると、「各頂点で、まだ使っていない辺を決めた順に使い、木の辺は最後に使う」という歩き方でオイラー閉路がちょうど 1 つ決まります。順番の決め方は各頂点で $(\mathrm{outdeg}(v) - 1)!$ 通りです。

### 4.3. $t_w$ を行列式で

$w$ に向かう有向全域木は、辺を全部逆向きにすると「$w$ から出る有向全域木」になるので、[[全域木の数え上げ（行列木定理）]] の有向版で求まります。辺のない頂点は除いて考えます。

### 4.4. 例

3 頂点で、辺 0→1, 0→1, 1→2, 1→2, 2→0, 2→0（各辺が 2 本ずつ）。各頂点の出次数は 2 なので $\prod (2-1)! = 1$。頂点 0 に向かう有向全域木は「1 が 1→2 のどちらか（2 通り）」×「2 が 2→0 のどちらか（2 通り）」で 4 個。よってオイラー閉路は 4 個です（ライブラリの出力も 4）。

実際、辺 0 を 0→1 の 1 本目とすると、閉路は「0→1, 1→2(どちらか), 2→0(どちらか), 0→1(2 本目), 1→2(残り), 2→0(残り)」で $2 \times 2 = 4$ 通りです。

## 5. 実装

```cpp
template <class mint>
mint count_eulerian_circuits(int n, const vector<pair<int, int>> &edges) {
    // 入次数 ≠ 出次数なら 0
    ...
    // 辺のある頂点に詰め，辺を逆向きにして「0 から出る有向全域木」を数える
    vector<pair<int, int>> rev(m);
    for (int i = 0; i < m; i++) rev[i] = {id[edges[i].second], id[edges[i].first]};
    mint res = count_spanning_trees_directed<mint>(k, rev, 0);   // 非連結なら 0
    for (int v = 0; v < n; v++)
        if (outdeg[v] > 0) res *= fact[outdeg[v] - 1];
    return res;
}
```

入次数 = 出次数のグラフでは「弱連結 ⇔ 強連結」なので、連結でなければ有向全域木の個数が 0 になり、特別扱いは要りません。

## 6. 正しさ・計算量

- **正しさ**：4.2 節の対応（オイラー閉路 ↔ 有向全域木と各頂点の辺の順番）が全単射であることによります。
- **計算量**：行列式 $O(n^3)$、階乗 $O(m)$。

## 7. 問題

【問題 1】は `count_eulerian_circuits<mint>(n, edges)` で解けます。

【問題 2】de Bruijn 列（長さ $k^n$ の巡回列で、長さ $n$ の全ての文字列がちょうど 1 回ずつ現れるもの）の個数を求めてください。
（ヒント：長さ $n-1$ の文字列を頂点とする de Bruijn グラフのオイラー閉路の個数です。答えは $(k!)^{k^{n-1}} / k^n$ として知られています。）

## 8. まとめ

- オイラー閉路の個数 = （ある頂点に向かう有向全域木の個数）× $\prod (\mathrm{outdeg} - 1)!$（BEST 定理）。
- 「各頂点から最後に出ていく辺」が有向全域木になり、残りの辺の順番は自由。
- 有向全域木の個数は辺を逆にして行列木定理で $O(n^3)$。
