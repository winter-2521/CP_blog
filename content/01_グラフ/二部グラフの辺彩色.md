ライブラリ：[bipartite_edge_coloring.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/bipartite_edge_coloring.hpp)

## 1. 概要

本記事では、二部グラフの辺に色を塗り、**同じ頂点に接する辺どうしは必ず違う色** にする（**辺彩色**）方法を解説します。二部グラフでは、最大次数を $\Delta$ とすると **ちょうど $\Delta$ 色で塗れる**（Kőnig の辺彩色定理）ことが知られています。

1. 交互路を入れ替えながら 1 本ずつ塗る方法（$O(nm)$）
2. オイラー閉路で辺を半分に分ける分割統治（$O(m\sqrt{n}\log\Delta)$）

の順に説明します。

>[!問題] 問題 1：Edge Coloring of Bipartite Graph（Library Checker）
>左 $L$ 頂点・右 $R$ 頂点、$M$ 辺の二部グラフの辺を、最小の色数で塗り分けてください。（$L, R, M \le 10^5$）

## 2. 前提知識

- [[二部マッチング（Hopcroft-Karp）]]
- [[オイラー路（Hierholzer）]]

## 3. 色数の下限と、貪欲の失敗

次数 $\Delta$ の頂点には $\Delta$ 本の辺が接していて全部違う色が必要なので、$\Delta$ 色は必要です。

「辺を順に、両端でまだ使っていない最小の色で塗る」貪欲は、$\Delta$ 色で足りないことがあります。例えば $\Delta = 2$ で、

| 順 | 辺 | 左で使用済み | 右で使用済み | 塗る色 |
| --- | --- | --- | --- | --- |
| 1 | L0–R0 | なし | なし | 0 |
| 2 | L1–R1 | なし | なし | 0 |
| 3 | L1–R2 | 0 | なし | 1 |
| 4 | L0–R2 | 0 | 1 | **2** |

と 3 色目が必要になります。貪欲だと最悪 $2\Delta - 1$ 色かかります。

## 4. 素朴な方法：交互路の入れ替え

### 4.1. アイデア

辺 $(u, v)$ を塗るとき、$u$ で空いている色 $a$、$v$ で空いている色 $b$ を選びます（どちらも $\Delta$ 本未満しか塗られていないので必ずあります）。

- $a$ が $v$ でも空いていれば $a$ で塗る。
- そうでなければ、$v$ から「色 $a$ の辺、色 $b$ の辺、色 $a$ の辺、…」と交互にたどる道を作り、その道の色 $a$ と $b$ を **入れ替えます**。すると $v$ で $a$ が空き、$u$ と $v$ の両方で空いている $a$ で塗れます。

この道は $u$ には着きません。二部グラフでは、$v$（右）から出た道が左の頂点に着くのは奇数本目の辺、つまり色 $a$ の辺で着くときですが、$u$ では $a$ が空いているからです。

### 4.2. 例で追う

$\Delta = 3$ の二部グラフ（辺 E0: L0–R0、E1: L0–R1、E2: L1–R0、E3: L1–R1、E4: L1–R2、E5: L2–R2）を、色 0, 1, 2 で順に塗ります。「空き」は空いている最小の色です。

| 辺 | 左の空き $a$ | 右の空き $b$ | 動作 | 色 |
| --- | --- | --- | --- | --- |
| E0 (L0–R0) | 0 | 0 | そのまま | 0 |
| E1 (L0–R1) | 1 | 0 | R1 で 1 は空き | 1 |
| E2 (L1–R0) | 0 | 1 | R0 で 0 は使用中（E0）。R0 から 0/1 交互の道 E0 (0), E1 (1) を入れ替え → E0 = 1, E1 = 0 | 0 |
| E3 (L1–R1) | 1 | 1 | そのまま | 1 |
| E4 (L1–R2) | 2 | 0 | R2 で 2 は空き | 2 |
| E5 (L2–R2) | 0 | 0 | そのまま | 0 |

結果は E0〜E5 の色が $1, 0, 0, 1, 2, 0$ で、3 色で塗れました。

### 4.3. なぜ遅いか

交互の道は最長 $O(n)$ で、辺 1 本ごとにたどるので全体 $O(nm)$ です。$n, m = 10^5$ の意地悪なケースでは間に合いません。

## 5. 高速化：オイラー分割による分割統治

### 5.1. 正則グラフにする

全ての頂点の次数が $\Delta$ の二部グラフ（**$\Delta$-正則**）にすると扱いやすくなります。

1. 同じ側の頂点を、次数の和が $\Delta$ を超えないように順にまとめて 1 頂点にします（まとめた頂点の辺どうしが違う色なら、元の頂点でも違う色）。例えば左の次数が $1, 1, 3$（$\Delta = 3$）なら、最初の 2 頂点をまとめて「次数 2 の頂点」と「次数 3 の頂点」にします。順にまとめているので、隣り合う 2 つのまとまりの次数の和は必ず $\Delta$ を超え、まとめた後の頂点数は各側 $2m / \Delta + 1$ 以下になります。
2. 左右の頂点数をそろえ、次数が足りない頂点どうしをダミーの辺で結んで、全員の次数を $\Delta$ にします（多重辺になってもよい）。

### 5.2. $\Delta$ が偶数：オイラー分割

$\Delta$ が偶数なら全ての頂点の次数が偶数なので、各連結成分にオイラー閉路があります。閉路に沿って辺を **交互に** グループ A, B に分けると、閉路が頂点を通過するたびに「入る辺」と「出る辺」が別のグループになるので、**各頂点でちょうど半分ずつ** に分かれます（二部グラフの閉路は偶数長なので、始点でも交互が崩れません）。

A, B はどちらも $\Delta/2$-正則なので、それぞれ色 $0 \sim \Delta/2 - 1$、$\Delta/2 \sim \Delta - 1$ で再帰的に塗ります。

### 5.3. $\Delta$ が奇数：完全マッチングを 1 色で

$\Delta$-正則な二部グラフには **完全マッチング** が必ずあります（Hall の定理）。[[二部マッチング（Hopcroft-Karp）]] で求めて 1 色で塗り、取り除くと $(\Delta - 1)$-正則、つまり偶数になります。

### 5.4. 例で追う（高速版）

4.2 節と同じグラフで、ライブラリが実際に行う手順です。

**正則化。** 左の次数 $2, 3, 1$、右の次数 $2, 2, 2$、$\Delta = 3$。まとめられる頂点はなく（$2 + 3 > 3$ など）、ダミーの辺を 3 本足して 3-正則にします。

| 辺 | E0 | E1 | E2 | E3 | E4 | E5 | E6 | E7 | E8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 両端 | L0–R0 | L0–R1 | L1–R0 | L1–R1 | L1–R2 | L2–R2 | L0–R0 | L2–R1 | L2–R2 |
| | | | | | | | ダミー | ダミー | ダミー |

**$\Delta = 3$（奇数）。** 完全マッチング {E0, E3, E5} を色 2 で塗り、残りは 2-正則。

**$\Delta = 2$（偶数）。** 残り {E1, E2, E4, E6, E7, E8} のオイラー閉路は

$$
\mathrm{L0} \xrightarrow{E1} \mathrm{R1} \xrightarrow{E7} \mathrm{L2} \xrightarrow{E8} \mathrm{R2} \xrightarrow{E4} \mathrm{L1} \xrightarrow{E2} \mathrm{R0} \xrightarrow{E6} \mathrm{L0}
$$

で、交互に A = {E1, E8, E2}、B = {E7, E4, E6} に分けます。A を色 0、B を色 1 で塗ります（どちらも 1-正則 = 完全マッチングなので 1 色で塗れる）。

元の辺 E0〜E5 の色は $2, 0, 0, 2, 1, 2$ です（ライブラリの出力と一致）。各頂点で色が重複していないことが確かめられます。

## 6. 実装

再帰は明示的なスタックで行い、各タスクは「辺の集合・次数・使う色の先頭」を持ちます。

```cpp
if (t.deg & 1) {
    // 完全マッチングを 1 色 (base + deg - 1) で塗る
    BipartiteMatching bm(k, k);
    for (int e : t.es) bm.add_edge(E[e].first, E[e].second);
    bm.solve();
    // マッチした組 (左, 右) ごとに辺を 1 本選んで塗る．残りは次数 deg - 1
    ...
    stk.push_back({rest, t.deg - 1, t.base});
} else {
    // オイラー閉路 (Hierholzer，非再帰) を作り，閉路の順に交互に A, B へ
    for (size_t j = 0; j < circuit.size(); j++) (j & 1 ? B : A).push_back(t.es[circuit[j]]);
    stk.push_back({A, t.deg / 2, t.base});
    stk.push_back({B, t.deg / 2, t.base + t.deg / 2});
}
```

## 7. 正しさ・計算量

- **正しさ**：オイラー分割で各頂点の次数がちょうど半分になり、奇数のときは完全マッチングが存在するので、最後まで正則のまま分割でき、$\Delta$ 色で塗れます。
- **計算量**：正則化後の辺数は $O(m)$ です。再帰の深さは $O(\log \Delta)$ で、各深さで辺の合計は $O(m)$。オイラー分割は線形、完全マッチングは $O(m\sqrt{n})$ なので、全体 $O(m \sqrt{n} \log \Delta)$ です。

## 8. 問題

【問題 1】は `bipartite_edge_coloring(L, R, edges)` の返り値（色数と各辺の色）を出力すれば解けます。

【問題 2】$n$ 人の生徒と $n$ 人の先生がいて、生徒 $i$ は先生 $j$ と $c_{ij}$ 回面談したい。1 コマに各生徒・各先生は 1 回しか面談できないとき、最小何コマで全ての面談を終えられるか、時間割とともに答えてください。
（ヒント：生徒–先生の多重辺の二部グラフの辺彩色で、色 = コマです。必要なコマ数は「生徒ごと・先生ごとの面談回数の最大値」です。）

【問題 3】全ての頂点の次数が $k$ の二部グラフ（左右 $n$ 頂点ずつ）の辺を、$k$ 個の完全マッチングに分割してください。
（ヒント：$k$ 色で辺彩色すると、各色の辺は各頂点にちょうど 1 本ずつ接するので完全マッチングです。マッチングを $k$ 回求めて取り除くより速く、$O(m\sqrt{n}\log k)$ で済みます。）

## 9. まとめ

- 二部グラフは最大次数 $\Delta$ 色で辺彩色できる（Kőnig）。貪欲では足りないことがある。
- 交互の道の色を入れ替えると 1 本ずつ塗れる（$O(nm)$）。
- 正則化して、偶数次数はオイラー閉路で半分ずつに分け、奇数次数は完全マッチングを 1 色で取る分割統治で $O(m\sqrt{n}\log\Delta)$。
