#グラフ #DFS #lowlink #辺連結

ライブラリ：[three_edge_connected_components.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/three_edge_connected_components.hpp)

## 1. 概要

本記事では、無向グラフを **三重辺連結成分** に分解する方法を解説します。2 頂点 $u, v$ が「三重辺連結」とは、**どの 2 本の辺を取り除いても $u$ と $v$ が連結なまま** であることです（辺素な道が 3 本以上ある、と同じです）。三重辺連結は同値関係なので、頂点集合が成分に分かれます。

Tsin による **パス吸収法** で、DFS 1 回、$O(n + m)$ で求められます。

>[!問題] 問題 1：Three-Edge-Connected Components（Library Checker）
>$N$ 頂点 $M$ 辺の無向グラフ（多重辺・自己ループあり）を三重辺連結成分に分解してください。（$N, M \le 2 \times 10^5$）

## 2. 前提知識

- lowlink、橋、二重辺連結成分：[[lowlinkと二重辺連結成分分解]]

## 3. 素朴な方法

全ての 2 本の辺の組を取り除いて連結成分を調べ、「どの組を取り除いても同じ連結成分にいる」頂点をまとめれば分解できます。組は $O(m^2)$ 通りあり、各 $O(n + m)$ なので、全体 $O(m^2(n + m))$ です。ライブラリの単体テストでは、この方法を小さいグラフでの正解として使っています。

## 4. 例

7 頂点、辺は次の 11 本とします。

- 完全グラフ $K_4$ ：$\{0,1\}, \{0,2\}, \{0,3\}, \{1,2\}, \{1,3\}, \{2,3\}$
- $\{3,4\}$, $\{0,5\}$（$K_4$ と残りをつなぐ 2 本）
- 三角形：$\{4,5\}, \{4,6\}, \{5,6\}$

答えは $\{0,1,2,3\}$, $\{4,5\}$, $\{6\}$ です。

- $K_4$ はどの 2 頂点の間にも辺素な道が 3 本あります。
- 辺 $\{3,4\}$ と $\{0,5\}$ の 2 本を取り除くと、$K_4$ と三角形が切り離されます（**2 辺カット**）。
- 4 と 5 の間には「直接の辺」「4-6-5」「4-3-…-0-5」の 3 本の辺素な道があるので同じ成分です。
- 6 は次数 2 なので、その 2 本を取り除けば孤立します。よって 6 は 1 頂点だけの成分です。

## 5. アイデア：成分を下から確定させる

DFS で、各頂点 $v$ について次の 2 つを管理します。

| 名前 | 意味 |
| --- | --- |
| $\mathrm{deg}[v]$ | $v$ の（今の）グループから、**祖先の方へ出ていく後退辺** の本数（DFS 木の親への辺は数えない） |
| $v$ のパス | $v$ から DFS 木を下に伸びる、「$v$ と同じ成分になるかまだ分からない」頂点の列 |

DFS の帰りがけに、子 $w$ のグループについて：

- **$w$ のパスが $w$ だけで、$\mathrm{deg}[w] \le 1$ なら**：$w$ のグループは「親への木の辺」＋「高々 1 本の後退辺」でしか外とつながっていません。この 2 本以下の辺を取り除くとグループが切り離されるので、**$w$ のグループは成分として確定** します。
- **そうでなければ**：$w$ のパスと $v$ のパスのうち、より上（low が小さい方）に届く方を $v$ のパスとして残し、もう一方を $v$ のグループに **吸収**（同じ成分として併合）します。

また、$v$ に **子孫 $u$ からの後退辺** が来たとき（$v$ 側から見たとき）、$v$ のパス上で $u$ を部分木に含む頂点を全部 $v$ に吸収します。その後退辺と木の道で閉路ができるので、2 本の辺では切り離せなくなるからです。

$\mathrm{deg}$ は、祖先への後退辺を見たら $+1$、子孫からの後退辺を見たら $-1$（その辺は子孫側で $+1$ されていて、吸収で足し込まれる分を打ち消す）、吸収したらそのグループの $\mathrm{deg}$ を足します。

## 6. 例で追う

4 節の例を、頂点 0 から DFS します（隣接は入力順）。実際にトレースした結果です。

| 手順 | 出来事 | 状態 |
| --- | --- | --- |
| 1 | 0, 1, 2 を訪問 | |
| 2 | 2 から祖先 0 への後退辺 | $\mathrm{deg}[2] = 1$, $\mathrm{low}[2] = 0$ |
| 3 | 3 を訪問。3 から 0, 1 への後退辺 | $\mathrm{deg}[3] = 2$, $\mathrm{low}[3] = 0$ |
| 4 | 4, 5 を訪問。5 から 0 への後退辺 | $\mathrm{deg}[5] = 1$, $\mathrm{low}[5] = 0$ |
| 5 | 6 を訪問。6 から 4 への後退辺 | $\mathrm{deg}[6] = 1$, $\mathrm{low}[6] = 4$ |
| 6 | 6 の帰りがけ：パスは [6]、$\mathrm{deg}[6] = 1 \le 1$ | **{6} が成分として確定** |
| 7 | 5 の帰りがけ：$\mathrm{deg}[5] = 2$ なので確定しない。$\mathrm{low}[5] = 0 < \mathrm{low}[4]$ なので 4 のパスを [4, 5] にする | |
| 8 | 4 が子孫 6 からの後退辺を見る：$\mathrm{deg}[4] = -1$。パス上で 6 を部分木に含む 5 を吸収 | グループ {4, 5}、$\mathrm{deg}[4] = 1$ |
| 9 | 4 の帰りがけ：パスは [4]、$\mathrm{deg}[4] = 1 \le 1$ | **{4, 5} が成分として確定** |
| 10 | 3 の帰りがけ：$\mathrm{deg}[3] = 3$（5 からの分が足された）。2 に吸収 | グループ {2, 3} |
| 11 | 2 の帰りがけ：1 のパスを [1, 2] にし、子孫 3 からの後退辺で {2, 3} を 1 に吸収 | グループ {1, 2, 3} |
| 12 | 1 の帰りがけ：0 のパスを [0, 1] にし、子孫からの後退辺で {1, 2, 3} を 0 に吸収 | グループ {0, 1, 2, 3} |

最終的に $\{0,1,2,3\}$, $\{4,5\}$, $\{6\}$ になり、4 節の答えと一致します。

手順 9 では、4 のグループ {4, 5} から外へ出る辺は「4 の親 3 への木の辺」と「5 から 0 への後退辺」の 2 本だけで、これがちょうど 2 辺カット $\{3,4\}, \{0,5\}$ になっています。

## 7. 実装

吸収した頂点の集合は、**巡回リスト**（`nxt[v]` で次の頂点を指し、1 周するとグループ全体）で持つと、`swap(nxt[v], nxt[w])` だけで 2 つのグループを $O(1)$ で併合できます。

```cpp
auto absorb = [&](int v, int w) { swap(nxt[v], nxt[w]), deg[v] += deg[w]; };

// 子孫 w からの後退辺を v から見たとき
deg[v]--;
int u = path[v];
while (u != NONE && in[u] <= in[w] && in[w] < out[u]) {   // u の部分木に w がある
    absorb(v, u);
    u = path[u];
}
path[v] = u;

// 子 w の探索が終わって親 p に戻ったとき
if (path[w] == NONE && deg[w] <= 1) {     // w のグループは成分として確定
    deg[p] += deg[w];
    low[p] = std::min(low[p], low[w]);
    continue;
} else if (deg[w] == 0) {
    w = path[w];                          // w 自身は確定 (橋)，その下のパスだけ残す
}
if (low[w] < low[p]) {
    low[p] = low[w];
    swap(w, path[p]);                     // より上に届くパスを p のパスに
}
while (w != NONE) { absorb(p, w); w = path[w]; }   // 残った方を吸収
```

`in[u] <= in[w] < out[u]` は「$w$ が $u$ の部分木にある」の判定です（$\mathrm{in}$ は訪問順、$\mathrm{out}$ は部分木を出たときの訪問カウンタ）。

## 8. 計算量

各頂点は高々 1 回吸収され、パスをたどる操作は吸収か、パスの付け替え 1 回で終わるので、全体 $O(n + m)$ です。

## 10. まとめ

- DFS の帰りがけに、子のグループが「親への辺 + 高々 1 本」でしか外とつながらなければ、2 辺以下で切り離せるので成分として確定する。
- そうでなければ、より上に届くパスを残してもう一方を吸収する。子孫からの後退辺でも、閉路になる部分を吸収する。
- グループは巡回リストで持てば $O(1)$ で併合できる。
