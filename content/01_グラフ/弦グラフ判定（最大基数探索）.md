#グラフ #弦グラフ #完全消去順序

ライブラリ：[chordal_graph.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/chordal_graph.hpp)

## 1. 概要

**弦グラフ**（chordal graph）とは、長さ 4 以上の **誘導閉路**（閉路上の頂点どうしを結ぶ余分な辺＝弦がない閉路）を持たないグラフです。木や区間グラフなどを含み、最大クリーク・彩色などが多項式時間で解ける重要なクラスです。

本記事では、**最大基数探索（MCS）** で頂点を並べ、その順序が「完全消去順序」になっているかを線形時間で検査する方法を解説します。弦グラフでなければ、長さ 4 以上の誘導閉路を 1 つ見つけます。

>[!問題] 問題 1：Chordal Graph Recognition（Library Checker）
>$N$ 頂点 $M$ 辺の単純無向グラフが弦グラフなら完全消去順序を、そうでなければ長さ 4 以上の誘導閉路を出力してください。（$N, M \le 2 \times 10^5$）

## 2. 前提知識

- BFS
- クリーク（どの 2 頂点も隣接する頂点集合）

## 3. 完全消去順序

頂点の並び $v_1, v_2, \dots, v_n$ が **完全消去順序**（PEO）であるとは、各 $v_i$ について「$v_i$ と、$v_i$ より **後ろ** にある $v_i$ の隣」がクリークになることです。

**グラフが弦グラフ ⇔ 完全消去順序がある** ことが知られています（弦グラフには必ず「隣がクリークになる頂点（単体的頂点）」があり、それを消しても弦グラフのまま）。

### 3.1. 素朴な方法

「隣がクリークになっている頂点」を探して消す、を繰り返すと完全消去順序が作れます。ただし毎回、各頂点の隣がクリークかを調べると $O(nm)$ 以上かかります。

## 4. 最大基数探索（MCS）

### 4.1. 手順

次の規則で頂点を 1 つずつ **訪問** します。

- まだ訪問していない頂点のうち、「**訪問済みの隣の数**（重み）」が最大のものを次に訪問する。

弦グラフなら、**訪問順の逆** が完全消去順序になります（Tarjan-Yannakakis）。重みごとに頂点を連結リスト（バケット）で持てば、重みの増加は「バケットを 1 つ移す」だけなので全体 $O(n + m)$ です。

### 4.2. 例（弦グラフ）

6 頂点、辺 0–1, 0–2, 1–2, 1–3, 2–3, 2–4, 3–4, 3–5（三角形 {0,1,2}, {1,2,3}, {2,3,4} とぶら下がり 5）。

| 訪問順 | 訪問する頂点（重み） | 訪問前の他の頂点の重み |
| --- | --- | --- |
| 1 | 0（0） | 全部 0 |
| 2 | 2（1） | 1: 1、他 0 |
| 3 | 1（2） | 3: 1、4: 1、5: 0 |
| 4 | 3（2） | 4: 1、5: 0 |
| 5 | 4（2） | 5: 1 |
| 6 | 5（1） | |

逆順 5, 4, 3, 1, 2, 0 が完全消去順序です（ライブラリの出力と一致）。例えば 3 の後ろにある隣は 1, 2 で、1–2 は隣接しています。

## 5. 検査

### 5.1. 完全消去順序かを線形時間で調べる

訪問順で、頂点 $x$ の「先に訪問した隣」（完全消去順序では後ろの隣）のうち **最後に訪問したもの** を $x$ の親 $z$ とします。完全消去順序であることは、

- $x$ の先に訪問した他の隣 $y$ が、全て $z$ と隣接している

ことと同値です（$z$ の「先に訪問した隣」も同じ条件を満たすので、帰納的にクリークになる）。

素朴に $x$ ごとに $z$ の隣を調べると遅いので、要求「$y$ は $z$ と隣接」を $z$ ごとにまとめ、$z$ の隣に 1 回だけ印を付けて全部調べます。これで $O(n + m)$ です。

### 5.2. 誘導閉路を見つける

検査に失敗した、つまり $y - x - z$ で $y$ と $z$ が隣接しないとき、

- $x$ と、$x$ の隣（$z$ 以外）を通らずに $y$ から $z$ へ行く **最短路** を BFS で求める

と、その道と $x$ を合わせた閉路は誘導閉路です。

- 道の途中の頂点は $x$ と隣接しない（通らないようにしたので）。
- 最短路なので、道の途中どうしに弦はない。
- $y$ と $z$ は隣接しない。

なので長さは 4 以上です（そのような道が必ずあることは MCS の性質から示されます）。

### 5.3. 例（弦グラフでない）

6 頂点、辺 0–1, 0–2, 1–2, 1–3, 2–4, 3–4, 3–5, 4–5。閉路 1–2–4–3 は弦（1–4 も 2–3 も）がない長さ 4 の誘導閉路です。

MCS の訪問順は 0, 2, 1, 3, 4, 5。頂点 4 の先に訪問した隣は 2, 3 で、親は最後の 3。2 と 3 は隣接しないので検査に失敗します（$x = 4, y = 2, z = 3$）。4 と 4 の隣（3 以外：2, 5）を避けて 2 から 3 へ BFS すると 2 → 1 → 3 が見つかり、閉路 3, 1, 2, 4 を得ます（ライブラリの出力と一致）。

## 6. 実装

MCS のバケット部分です。

```cpp
// 重み w のバケットを双方向連結リストで持つ
for (int v = n - 1; v >= 0; v--) ins(v);
int mx = 0;
for (int it = 0; it < n; it++) {
    while (head[mx] < 0) mx--;                 // 空でない最大の重み
    int v = head[mx];
    era(v);
    idx[v] = ord.size(), ord.push_back(v);
    for (int u : g[v]) {
        if (idx[u] >= 0) continue;
        era(u), w[u]++, ins(u);                // 重みを 1 増やしてバケットを移す
        if (w[u] > mx) mx = w[u];
    }
}
```

`mx` は 1 回の訪問で高々 1 しか増えず、減るのも合計で増えた分以下なので、`while` の合計は $O(n)$ です。

## 7. 正しさ・計算量

- **正しさ**：「弦グラフなら MCS の逆順が完全消去順序」と、5.1 節の検査の同値性は Tarjan-Yannakakis の結果です。
- **計算量**：MCS・検査・BFS とも $O(n + m)$。

## 9. まとめ

- 弦グラフ ⇔ 完全消去順序（各頂点と後ろの隣がクリーク）がある。
- 最大基数探索（訪問済みの隣が最も多い頂点を次に訪問）の逆順は、弦グラフなら完全消去順序。バケットで $O(n + m)$。
- 「親 $z$ と隣接するか」の検査を $z$ ごとにまとめて線形時間。失敗したら BFS で誘導閉路を作る。
