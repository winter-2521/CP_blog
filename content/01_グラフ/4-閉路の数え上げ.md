## 1. 概要

無向グラフの各辺について、その辺を含む **4-閉路**（4 つの相異なる頂点を一周する閉路、$C_4$）の個数を求めます。[[三角形・クリークの列挙（次数順の向き付け）]] と同じく頂点を次数で順位付けすることで、$O(m\sqrt{m})$ になります。多重辺も扱えます。

>[!問題] 問題 1：Counting $C_4$'s（Library Checker）
>$N$ 頂点 $M$ 辺の無向グラフ（多重辺あり、自己ループなし）が与えられます。各辺 $i$ について、辺 $i$ と他の 3 本の辺で $C_4$ になる組の数を求めてください。（$N, M \le 3 \times 10^5$）

## 2. 前提知識

- [[三角形・クリークの列挙（次数順の向き付け）]]（次数での順位付け）

## 3. 素朴な方法

4-閉路 $u - v - w - x - u$ は、**対角の 2 頂点** $\{u, w\}$ と、その **共通の隣** 2 つ $\{v, x\}$ で決まります。だから各頂点 $v$ について隣の頂点の組 $(u, w)$ を全部列挙して $\mathrm{cnt}[u][w]$ を数えれば、$\{u, w\}$ を対角とする閉路は $\binom{\mathrm{cnt}[u][w]}{2}$ 個です。

ところが隣の組の列挙は $\sum_v \deg(v)^2$ で、1 頂点が全頂点とつながる「星」のようなグラフでは $O(n^2)$、一般には $O(nm)$ になり、$3 \times 10^5$ では間に合いません。

## 4. 順位最大の頂点で分類する

### 4.1. アイデア

頂点を (次数, 番号) で順位付けし、閉路の中で **順位最大の頂点 $u$** と、その **対角の頂点 $w$** で閉路を分類します。$u$ から 2 歩の道 $u - v - w$ で、$v, w$ の順位が $u$ より小さいものだけを列挙します。

- 道の数え方：$u$ ごとに「$u$ より順位の小さい隣 $v$」→「$u$ より順位の小さい $v$ の隣 $w$」。順位で並べた隣接リストを途中で打ち切れます。
- 計算量：$v$ の隣で $u$ より順位が小さいものを見る回数は、$v$ の次数が大きければ（$\sqrt{m}$ 以上）そういう $u$ は少なく、小さければ 1 回 $\sqrt{m}$ 以下。合計 $O(m\sqrt{m})$ です。

### 4.2. 各辺の個数

1 回目の列挙で $\mathrm{cnt}[w]$（$u$ から $w$ への道の数）を数えます。2 回目に同じ道 $u - v - w$ を列挙し、**この道を含む閉路の数** $\mathrm{cnt}[w] - 1$（もう一方の道 $u - x - w$ の選び方）を、辺 $uv$ と辺 $vw$ に足します。閉路の残り 2 辺（$ux$, $xw$）は、道 $u - x - w$ を列挙したときに足されるので、各閉路の 4 辺に 1 ずつ足されます。

### 4.3. 多重辺

多重辺は単純グラフの辺にまとめ、本数 $c(e)$ を重みとします。道 $u - v - w$ の数は $c(uv)\,c(vw)$、道を含む閉路の数は「もう一方の道」の重みの和 $\mathrm{cnt}[w] - c(uv)c(vw)$ です。元の辺 1 本あたりでは、閉路の他の 3 辺の本数の積を数えるので、

- 辺 $uv$ に $c(vw) \times (\mathrm{cnt}[w] - c(uv)c(vw))$
- 辺 $vw$ に $c(uv) \times (\mathrm{cnt}[w] - c(uv)c(vw))$

を足します。

### 4.4. 例で追う

4 頂点、辺 e0: 0–1, e1: 1–2, e2: 2–3, e3: 3–0, e4: 0–2, e5: 1–2（e1 と e5 は多重辺）。まとめると 1–2 の本数が 2、他は 1 本です。

| 頂点 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| （単純グラフの）次数 | 3 | 2 | 3 | 2 |
| 順位 | 2 | 0 | 3 | 1 |

閉路は 0–1–2–3 だけで、順位最大は 2、対角は 0 です。$u = 2$ からの道（$v, w$ の順位 < 3）：

| 道 | 重み $c(uv)c(vw)$ |
| --- | --- |
| 2 – 1 – 0 | $2 \times 1 = 2$ |
| 2 – 3 – 0 | $1 \times 1 = 1$ |
| 2 – 0 – 1 | $1 \times 1 = 1$ |
| 2 – 0 – 3 | $1 \times 1 = 1$ |

$\mathrm{cnt}[0] = 3$、$\mathrm{cnt}[1] = 1$、$\mathrm{cnt}[3] = 1$。2 回目：

| 道 | 道を含む閉路 $\mathrm{cnt}[w] - c\,c$ | 辺 $uv$ に足す | 辺 $vw$ に足す |
| --- | --- | --- | --- |
| 2 – 1 – 0 | $3 - 2 = 1$ | 1–2 に $1 \times 1 = 1$ | 0–1 に $2 \times 1 = 2$ |
| 2 – 3 – 0 | $3 - 1 = 2$ | 2–3 に $1 \times 2 = 2$ | 0–3 に $1 \times 2 = 2$ |
| 2 – 0 – 1 | $1 - 1 = 0$ | | |
| 2 – 0 – 3 | $1 - 1 = 0$ | | |

$u = 0$（順位 2）からは、順位 2 未満の隣 1, 3 の先に順位 2 未満の頂点がないので道はありません。結果は e0〜e5 で $2, 1, 2, 2, 0, 1$ です（ライブラリの出力と一致）。実際、閉路は「0–1–2–3 で 1–2 を e1 か e5 のどちらにするか」の 2 個で、e0, e2, e3 は両方に、e1, e5 は 1 個ずつに含まれます。

## 5. 実装

```cpp
for (int ru = 0; ru < n; ru++) {                  // 順位の小さい順に u を見る
    int u = byrank[ru];
    for (int pass = 0; pass < 2; pass++)
        for (int i = start[u]; i < start[u + 1] && adj[i].first < ru; i++) {
            int v = byrank[adj[i].first], e1 = adj[i].second;
            for (int j = start[v]; j < start[v + 1] && adj[j].first < ru; j++) {
                int w = adj[j].first, e2 = adj[j].second;
                if (pass == 0) cnt[w] += mult[e1] * mult[e2];
                else {
                    long long other = cnt[w] - mult[e1] * mult[e2];
                    res[e1] += mult[e2] * other, res[e2] += mult[e1] * other;
                }
            }
        }
    // cnt を戻す (触った w だけ)
}
```

隣接リストは (相手の順位, 辺番号) を順位の昇順に並べておき、$u$ の順位以上になったら打ち切ります。

## 6. 正しさ・計算量

- **正しさ**：各閉路は順位最大の頂点 $u$ と対角 $w$ で一意に分類され、その 2 本の道の列挙で 4 辺に 1 回ずつ足されます。
- **計算量**：多重辺のまとめにソート $O(m \log m)$、列挙は $O(m\sqrt{m})$ です。

## 8. まとめ

- 4-閉路は「対角の 2 頂点」と「その共通の隣 2 つ」で決まる。
- 順位最大の頂点 $u$ から、$u$ より順位の小さい頂点だけを通る 2 歩の道を列挙すると $O(m\sqrt{m})$。
- 道 $u - v - w$ を含む閉路の数 $\mathrm{cnt}[w] - (\text{自分})$ を 2 辺に足すと、各辺の個数が求まる。多重辺は本数を重みにする。
