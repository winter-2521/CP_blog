#グラフ #最小全域木 #最短路

ライブラリ：[minimum_diameter_spanning_tree.hpp](https://github.com/winter-2521/cp-library/blob/main/graph/minimum_diameter_spanning_tree.hpp)

## 1. 概要

本記事では、重み付き無向グラフの全域木のうち **直径**（木の上で最も遠い 2 頂点の距離）が最小のもの（**最小直径全域木**）を求める方法を解説します。

鍵になるのは **絶対 1-中心**：辺の途中の点も含めて「最も遠い頂点までの距離」が最小になる点です。そこからの最短路木を作ると直径が最小になります。全点対最短路 $O(nm \log n)$ と、辺ごとの $O(n)$ の走査で求まります。

>[!問題] 問題 1：Minimum Diameter Spanning Tree（Library Checker）
>$N$ 頂点 $M$ 辺の連結な重み付き無向グラフの最小直径全域木の直径と、使う辺を出力してください。（$N, M \le 2000$、重みは $0$ 以上 $10^9$ 以下）

## 2. 前提知識

- Dijkstra 法、最短路木（始点からの最短路を全部集めた木）
- 木の直径

## 3. 素朴な方法

### 3.1. 全ての全域木を試す

全域木を全部列挙して直径を測れば答えは出ますが、全域木は指数個あります。

### 3.2. 頂点を中心にした最短路木

木の直径 $D$ の「真ん中」の点 $c$ を考えると、全ての頂点は $c$ から $D/2$ 以内にあります。そこで「最も遠い頂点までの距離（**離心率**）が最小の頂点」から最短路木を作ればよさそうです。ところが、真ん中の点は **辺の途中** にあることがあり、頂点だけを候補にすると最適になりません。

| 辺 | e0 | e1 | e2 | e3 | e4 | e5 |
| --- | --- | --- | --- | --- | --- | --- |
| 両端 | 0–1 | 0–2 | 0–3 | 1–2 | 1–3 | 2–3 |
| 重み | 2 | 6 | 6 | 5 | 6 | 3 |

このグラフでは全ての頂点の離心率が 6 で、どの頂点からの最短路木も直径は 11 以上です。ところが道 $0 - 1 - 2 - 3$（辺 e0, e3, e5）は直径 $2 + 5 + 3 = 10$ です。この木の真ん中は辺 1–2 の上、頂点 1 から 3 の点です（ライブラリの出力も直径 10、辺 e0, e5, e3）。

## 4. 絶対 1-中心

### 4.1. 定義と性質

グラフの辺の途中の点も含めた点 $c$ について、離心率 $\mathrm{ecc}(c) = \max_v d(c, v)$ が最小の点を **絶対 1-中心** と呼びます。

- **下限**：どの全域木 $T$ でも、その直径の真ん中の点 $c_T$ から全頂点は木の上で $D/2$ 以内、つまりグラフでも $D/2$ 以内なので、$D \ge 2\,\mathrm{ecc}(c_T) \ge 2 \min_c \mathrm{ecc}(c)$。
- **達成**：絶対 1-中心 $c$ からの最短路木では、どの 2 頂点も $c$ を経由して $2\,\mathrm{ecc}(c)$ 以内でつながるので、直径は $2\,\mathrm{ecc}(c)$ 以下。

よって **最小の直径 = $2 \min_c \mathrm{ecc}(c)$** で、絶対 1-中心からの最短路木が答えです。

### 4.2. 辺の上の点の離心率

辺 $(u, v)$（重み $w$）の上で、$u$ から $x$ の点の離心率は

$$
f(x) = \max_k \min\bigl(d(u, k) + x,\ d(v, k) + w - x\bigr) \quad (0 \le x \le w)
$$

です。$k$ ごとに「$u$ 経由」と「$v$ 経由」の短い方を取り、全部の最大を取ります。

素朴に、全ての折れ点を試すと辺 1 本 $O(n^2)$、全体 $O(mn^2)$ で、$n = m = 2000$ では $8 \times 10^9$ になり間に合いません。

## 5. Kariv-Hakimi の走査

### 5.1. アイデア

最適な $x$ では、「$d(u, k)$ が大きい頂点は $v$ 経由、小さい頂点は $u$ 経由」と分かれます。そこで頂点を $d(u, k)$ の **降順** に並べ、

- 先頭からいくつかを $v$ 経由（その中で $d(v, \cdot)$ が最大の頂点を $p$）
- 残りを $u$ 経由（その中で $d(u, \cdot)$ が最大の頂点 = 境目の次の頂点 $k$）

とすると、離心率は $\max(d(u, k) + x,\ d(v, p) + w - x)$ で、両者が等しくなる

$$
x = \frac{d(v, p) + w - d(u, k)}{2}, \qquad 2\,\mathrm{ecc} = d(u, k) + d(v, p) + w
$$

が最適です（$0 \le x \le w$ のときだけ有効）。境目は、$d(v, \cdot)$ の最大値が更新されるところだけ調べれば十分です。$d(u, \cdot)$ の降順の並びは頂点 $u$ ごとに 1 回ソートしておけば、辺ごとの走査は $O(n)$ です。

### 5.2. 例で追う

3.2 節の例で全点対の距離は

| | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| $d(1, \cdot)$ | 2 | 0 | 5 | 6 |
| $d(2, \cdot)$ | 6 | 5 | 0 | 3 |

です。辺 $(u, v) = (1, 2)$、$w = 5$ を調べます。$d(1, \cdot)$ の降順は 3, 2, 0, 1。

| 境目の次 $k$ | $v$ 経由の側 | $p$（$d(2,\cdot)$ 最大） | 判定 | $2\,\mathrm{ecc}$ | $x$ |
| --- | --- | --- | --- | --- | --- |
| （開始） | {3} | 3（$d = 3$） | | | |
| 2 | — | — | $d(2,2) = 0 \le 3$ なので飛ばす | | |
| 0 | {3, 2} | 3 | $d(2, 0) = 6 > 3$ → 候補 | $d(1,0) + d(2,3) + 5 = 2 + 3 + 5 = 10$ | $(3 + 5 - 2)/2 = 3$ |
| 1 | — | — | $d(2, 1) = 5 \le 6$ なので飛ばす | | |

辺 1–2 の、頂点 1 から 3 の点で離心率 5、直径 10 です。頂点を中心にした場合（離心率 6、$2 \times 6 = 12$）より小さくなっています。

### 5.3. 最短路木を作る

中心が辺の途中なら、中心を仮の頂点として「$u$ へ重み $x$、$v$ へ重み $w - x$」の辺を張って Dijkstra をし、最短路木を作ります。仮の頂点に直接つながる頂点が $u$ と $v$ の 2 つなら、木の辺として辺 $(u, v)$ を使います。$x$ が半整数になることがあるので、重みを全部 2 倍して計算します。

例では、中心から 1 へ 3、2 へ 2、0 へ（1 経由）5、3 へ（2 経由）5 で、木は辺 1–2, 0–1, 2–3 です。

## 6. 実装

辺ごとの走査です（`ord[u]` は $d(u, \cdot)$ の降順）。

```cpp
for (int i = 0; i < m; i++) {
    auto &[u, v, w] = edges[i];
    const auto &du = d[u], &dv = d[v];
    int p = ord[u][0];                    // v 経由の側で d[v] が最大の頂点
    for (int j = 1; j < n; j++) {
        int k = ord[u][j];
        if (dv[k] <= dv[p]) continue;     // 最大値が変わらない境目は調べなくてよい
        T cand = du[k] + dv[p] + w;       // 2 * 離心率
        T x2 = dv[p] + w - du[k];         // 2 * x
        if (0 <= x2 && x2 <= 2 * w && cand < best) best = cand, be = i, bx2 = x2;
        p = k;
    }
}
```

ソートは (距離, 頂点番号) を 1 つの 64 bit 整数に詰めて行うと、間接参照の比較より速くなります。

## 7. 正しさ・計算量

- **正しさ**：4.1 節より、直径の最小値は $2 \min_c \mathrm{ecc}(c)$ で、5.1 節の走査は各辺で最小の離心率を正しく求めます（頂点自体も候補に入れます）。
- **計算量**：Dijkstra を $n$ 回で $O(nm \log n)$、ソート $O(n^2 \log n)$、辺ごとの走査 $O(nm)$。メモリは全点対の距離で $O(n^2)$ です。

## 9. まとめ

- 最小直径 = 絶対 1-中心の離心率 × 2。中心からの最短路木が答え。
- 中心は辺の途中にあることがあるので、頂点だけ調べるのでは足りない。
- 辺上の離心率は、頂点を $d(u,\cdot)$ の降順に並べて「先頭は $v$ 経由、残りは $u$ 経由」の境目を走査すれば辺 1 本 $O(n)$ で最小化できる。
