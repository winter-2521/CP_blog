## 1. 概要

本記事では **割当問題**：$n \times n$ の行列 $a$ について、各行に相異なる列を 1 つずつ割り当て（つまり順列 $p$ を選び）、$\sum_i a_{i, p_i}$ を最小にする問題を解く **Hungarian 法**（ハンガリアン法）を解説します。

行を 1 つずつ追加し、「ポテンシャル」（双対変数）を使った Dijkstra 風の探索で最短の増加路を見つけます。$O(n^3)$ です。

>[!問題] 問題 1：Assignment Problem（Library Checker）
>$N \times N$ の整数行列 $a$ が与えられます。順列 $p$ で $\sum_i a_{i, p_i}$ を最小にし、最小値と $p$ を出力してください。（$N \le 500$、$|a_{ij}| \le 10^9$）

## 2. 前提知識

- [[二部マッチング（Hopcroft-Karp）]]（増加路）
- Dijkstra 法

## 3. 素朴な方法

### 3.1. 全探索

順列を全部試すと $O(n! \cdot n)$ で、$n = 12$ くらいが限界です。

### 3.2. 最小費用流として解く

行を左、列を右とする二部グラフで、行 $i$ から列 $j$ への辺の費用を $a_{ij}$ とし、「始点 → 各行（容量 1）」「各列 → 終点（容量 1）」を足して、流量 $n$ の最小費用流を求めれば答えです。

最小費用流の標準的な方法（最短路を求めて 1 だけ流す、を $n$ 回）で、最短路をポテンシャル付き Dijkstra（ヒープ）で求めると、辺が $n^2$ 本あるので 1 回 $O(n^2 \log n)$、全体 $O(n^3 \log n)$ です。グラフを辺のリストで持つ分の定数倍も重くなります。

Hungarian 法は、これを **割当問題専用に** 書き直したもので、

- グラフを作らず行列を直接見る
- 密なグラフなのでヒープを使わず、「各列への暫定距離」の配列で Dijkstra をする（1 回 $O(n^2)$）

ことで $O(n^3)$ にします。

## 4. ポテンシャル（双対変数）

### 4.1. 条件

各行 $i$ に値 $u_i$、各列 $j$ に値 $v_j$ を持ち、常に

$$
a_{ij} - u_i - v_j \ge 0 \quad (\text{全ての } i, j)
$$

を保ちます。左辺を **被約費用** と呼びます。さらに、割り当てた組 $(i, p_i)$ では被約費用が $0$（**タイト**）になるようにします。

### 4.2. 最適性の証明になる

全ての行が割り当て済みで上の条件が成り立てば、どんな順列 $q$ についても

$$
\sum_i a_{i, q_i} = \sum_i (a_{i, q_i} - u_i - v_{q_i}) + \sum_i u_i + \sum_j v_j \ge \sum_i u_i + \sum_j v_j
$$

で、$q = p$ のときは被約費用が全部 0 なので等号が成り立ちます。つまり $p$ が最適で、最小値は $\sum u + \sum v$ です。

## 5. 行を 1 つずつ追加する

### 5.1. 手順

行 $i$ を追加するとき、行 $i$ を始点として、

1. まだ使っていない各列 $j$ について「そこまでの最短の被約費用」`minv[j]` を持つ。
2. その中で最小の列 $j_1$ を選ぶ（その値を $\delta$ とする）。これまでに通った行の $u$ に $\delta$ を足し、通った列の $v$ から $\delta$ を引く（被約費用が非負のまま、$j_1$ への辺がタイトになる）。
3. $j_1$ が空いていれば、通ってきた道（`way`）をたどって割当を入れ替えて終わり。$j_1$ がすでに行 $i_0$ に割り当てられていれば、$i_0$ から 1. に戻る。

Dijkstra 法そのものです（距離の代わりにポテンシャルを動かしている）。

### 5.2. 例で追う

$$
a = \begin{pmatrix} 4 & 1 & 3 \\ 2 & 0 & 5 \\ 3 & 2 & 2 \end{pmatrix}
$$

最初は $u = v = 0$、何も割り当てていません。

**行 0 を追加。** 被約費用は $4, 1, 3$。最小は列 1 の $1$ なので $\delta = 1$、$u_0 = 1$。列 1 は空いているので 行 0 → 列 1。

| | 列 0 | 列 1 | 列 2 | $u$ |
| --- | --- | --- | --- | --- |
| 行 0 | 3 | **0** | 2 | 1 |
| $v$ | 0 | 0 | 0 | |

（表の中身は被約費用 $a_{ij} - u_i - v_j$。太字が割り当てた組。）

**行 1 を追加。** 被約費用は $2, 0, 5$。

| 段階 | 今いる行 | `minv`（列 0, 1, 2） | 最小 | 動作 |
| --- | --- | --- | --- | --- |
| 1 | 行 1 | 2, **0**, 5 | 列 1（$\delta = 0$） | 列 1 は行 0 が使っている → 行 0 へ |
| 2 | 行 0 | 2, –, 2 | 列 0（$\delta = 2$） | 列 0 は空き → 入れ替え |

段階 2 で、行 0 から見た列 0, 2 の被約費用は $3, 2$ で、行 1 からの $2, 5$ と比べて小さい方が `minv` です。列 0 には行 1 から直接（`way` = 行 1）、列 2 には行 0 経由で、どちらも 2。小さい番号の列 0 を選びます。$\delta = 2$ で、通った行 0, 1 の $u$ に 2 を足し、通った列 1 の $v$ から 2 を引きます。

| | 列 0 | 列 1 | 列 2 | $u$ |
| --- | --- | --- | --- | --- |
| 行 0 | 1 | **0** | 0 | 3 |
| 行 1 | **0** | 0 | 3 | 2 |
| $v$ | 0 | −2 | 0 | |

列 0 には行 1 から直接来たので、行 1 → 列 0 を追加するだけです（行 0 は列 1 のまま）。ここまでの費用は $1 + 2 = 3 = \sum u + \sum v = 3 + 2 + 0 - 2 + 0$ です。

**行 2 を追加。** 被約費用は $3 - 0 - 0 = 3$、$2 - 0 + 2 = 4$、$2 - 0 - 0 = 2$。最小は列 2（空き）で $\delta = 2$、$u_2 = 2$。

| | 列 0 | 列 1 | 列 2 | $u$ |
| --- | --- | --- | --- | --- |
| 行 0 | 1 | **0** | 0 | 3 |
| 行 1 | **0** | 0 | 3 | 2 |
| 行 2 | 1 | 2 | **0** | 2 |
| $v$ | 0 | −2 | 0 | |

全ての被約費用が 0 以上で、割り当てた組は 0 です。答えは $p = (1, 0, 2)$、最小値 $1 + 2 + 2 = 5 = \sum u + \sum v$（ライブラリの出力と一致）。

## 6. 実装

```cpp
// 1-indexed．列 0 は「いま追加している行」を置く仮の列
vector<T> u(n + 1, 0), v(m + 1, 0), minv(m + 1);
vector<int> p(m + 1, 0), way(m + 1, 0);       // p[j]: 列 j に割り当てた行
vector<char> used(m + 1);
for (int i = 1; i <= n; i++) {
    p[0] = i;
    int j0 = 0;
    fill(minv.begin(), minv.end(), INF);
    fill(used.begin(), used.end(), 0);
    do {
        used[j0] = 1;
        int i0 = p[j0], j1 = 0;
        T delta = INF;
        for (int j = 1; j <= m; j++) {
            if (used[j]) continue;
            T cur = a[i0 - 1][j - 1] - u[i0] - v[j];   // 被約費用
            if (cur < minv[j]) minv[j] = cur, way[j] = j0;
            if (minv[j] < delta) delta = minv[j], j1 = j;
        }
        for (int j = 0; j <= m; j++) {                 // ポテンシャルを δ 動かす
            if (used[j]) u[p[j]] += delta, v[j] -= delta;
            else minv[j] -= delta;
        }
        j0 = j1;
    } while (p[j0] != 0);                              // 空いている列に着くまで
    do {                                               // way をたどって入れ替え
        int j1 = way[j0];
        p[j0] = p[j1];
        j0 = j1;
    } while (j0);
}
```

- 「仮の列 0」に今の行を置くことで、始点を列と同じように扱えます。
- `minv` から $\delta$ を引いておくのは、「ポテンシャルを動かしたぶん距離もずらす」ためです。

## 7. 正しさ・計算量

- **正しさ**：各段階で被約費用が非負・割り当てた組はタイト、を保つので、4.2 節より最後に最適です。各行の追加は「被約費用での最短路を流す」ことに当たり、最小費用流の逐次最短路法と同じです。
- **計算量**：1 行の追加で `do` ループは高々 $m$ 回、1 回 $O(m)$ なので $O(m^2)$。$n$ 行で $O(n m^2)$、正方行列なら $O(n^3)$ です。（ライブラリは $n \le m$ の長方形にも対応しています。）

## 9. まとめ

- 割当問題は二部グラフの最小費用完全マッチング。最小費用流でも解けるが、Hungarian 法は行列を直接見る専用版で $O(n^3)$。
- 行・列のポテンシャル $u, v$ で被約費用 $a_{ij} - u_i - v_j \ge 0$ を保ち、割り当てた組をタイトにすると最適性が保証される。
- 行を 1 つずつ足し、被約費用での Dijkstra（配列版）で最短の増加路を見つけて入れ替える。
